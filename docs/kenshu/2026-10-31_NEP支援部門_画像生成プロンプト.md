# スライド用 画像・図の一覧と GPT 生成プロンプト

## 使い方

- 下の「共通スタイル」を、各プロンプトの最後に必ず付けて生成する（全スライドの絵柄がそろう）
- **画像の中に文字は入れない**。ラベルや見出しは Canva で上から載せる（生成画像の日本語は崩れやすいため）
- サイズの目安：全面背景＝16:9（1792×1024）、半面＝縦長（1024×1536）か正方形（1024×1024）
- 図（概念図・フロー）は、Canva の図形で組む方がきれいで直しやすい。生成画像は「背景・挿絵」として使い、ラベルは Canva で付ける
- 実際のアプリ画面があるスライド（④⑨）は、生成画像よりも**本物のスクリーンショット**を推奨（生徒名などは伏せる）

### 共通スタイル（毎回、末尾に付ける）

```
スタイル：明るく清潔感のある、やわらかいセミリアルなイラスト。白と淡い水色を基調に、濃紺（#13294B）をアクセント。余白を広く取り、ビジネス資料に合う落ち着いた雰囲気。人物は日本人、スーツやオフィスカジュアル。画像内に文字・ロゴ・数字は入れない。
```

（参考：「AI活用の取り組み紹介」資料の表紙の絵柄＝青空・佐世保の島々・光のライン・開いた本）

## 生成プロンプト

### 1. 表紙（イメージ画像・16:9）

```
長崎県佐世保市の九十九島が見える明るい青空の海辺を背景に、学習塾の職員2〜3人がタブレットとノートPCを囲んで笑顔で話している。画面からやわらかい光のラインが伸び、本のページや資料のアイコンのような形が空へ広がっていく。左側1/3は空と余白にして、タイトル文字を置けるようにする。16:9。
```

### 2. 一本の軸と3本の柱（概念図・正方形）

```
3重の同心円の概念図イラスト。中心の小さな円に「学習塾の校舎と職員」、真ん中の円に「建設会社・工場・商店などの地域の企業」、外側の円に「多様な国籍の人々と街並み・行政の建物・学校」を小さなアイコン風に配置。中心から外へ光の波紋が広がる。中心は青、真ん中は緑、外側はオレンジの淡い色分け。正方形。
```

※ 円の名前（社内／地域の企業／地域社会）は Canva で付ける

### 3. 01 区切り：智翔館ナレッジ開発（イメージ画像・16:9）

```
開いた大きな本から光の粒が立ちのぼり、書類・グラフ・チャットの吹き出し・校舎のアイコンが一つの光の球に集まっていく抽象的なイラスト。背景は白から淡い青のグラデーション。右半分に絵、左半分は余白。16:9。
```

### 4. データは「点在」している（フロー＋挿絵）

**4-a 変遷の3コマ（横長 3:1 相当、またはそれぞれ正方形で3枚）**

```
左から右へ並ぶ3つの場面のイラスト。①机の上に積まれた紙の書類とWordやExcelのような画面の古いPC、②クラウドのアイコンの下に表計算と文書の画面が並ぶノートPC、③空に浮かぶたくさんの小さなクラウドに、バラバラの書類やフォルダが散らばり、職員が困った顔で見上げている。場面の間に右向きの矢印。横長。
```

**4-b 散らばったファイル（右半分用・縦長）**

```
いくつものクラウドの上に、色や形がバラバラのフォルダ・表計算・文書のアイコンが散らばって浮かんでいる。似た書類が重複してあちこちにあり、どれが最新かわからない様子。下で職員が一人、虫眼鏡で探している。縦長。
```

### 5. 智翔館アプリ（スクリーンショット推奨）

本物の画面を使う：会議DXのダッシュボード、問合せ管理（今日の注意点）、門配管理の3枚程度。
生成する場合のプロンプト：

```
ノートPCとタブレットが並び、どちらの画面にも同じシンプルなダッシュボード（カード型の数値、棒グラフ、カレンダー、一覧表）が表示されている。ばらばらの書類のアイコンが画面の中へ吸い込まれ、1つにまとまっていく。白い机の上、明るいオフィス。画面内に文字は入れない。横長。
```

### 6. 普段使いのAI と 智翔館AI の対比（挿絵・2枚）

**6-a 普段使いのAI**

```
グレーの単色で描かれたシンプルなチャット画面と、どこにでもある一般的な本やグラフのアイコン。少し味気なく、ぼんやりした印象。正方形。
```

**6-b 智翔館AI**

```
濃紺と青のチャット画面から、佐世保の地図・学校の校舎・チラシ・グラフ・入試の資料のアイコンが整然と並んで出てくる。明るく、的確で頼もしい印象。正方形。
```

### 7. 智翔館ナレッジのイメージ（概念図・16:9）

```
左から右へ流れる概念図イラスト。左に3つの箱：上は青い本の箱（理念・方針・要項を表す本とテンプレート）、中は緑のデータベースの円柱、下は灰色の点線で囲まれた散らばったクラウドとファイル。3つから光の線が中央の濃紺の大きなAIのコア（光る球体）に集まり、右側へ4本の線が分かれて、チラシ、グラフ付きのアドバイス資料、保護者向けセミナーのスライド、会議と面談の資料のアイコンへつながる。白背景、余白多め。16:9。画像内に文字は入れない。
```

※ 「智翔館ナレッジ／DB／クラウドデータ／智翔館AI」などのラベルは Canva で載せる
※ 図の中身は、現在のスライド（Claude で作った版）の6枚目と同じ構成

### 8. 02 区切り：支援ノウハウの他社販売（イメージ画像・16:9）

```
建設現場の事務所で、ヘルメットを置いた作業着の社員たちがノートPCを囲み、講師役のスーツの人物が画面を指して説明している。窓の外に建設中の建物とクレーン。明るく前向きな雰囲気。左側に余白。16:9。
```

### 9. ノウハウの5段階（アイコン5点・各正方形、または横一列1枚）

```
同じタッチの線画アイコンを5つ横一列に並べる（濃紺の線、背景は白、各アイコンは淡い緑の丸の中）。①虫眼鏡で業務の流れ図を見る、②チェックリストに印を付ける、③スマホとPCの画面にアプリの部品が組み上がる、④AIの光る脳と歯車、⑤人が現場でタブレットを持ち上向き矢印。横長。
```

### 10. 研修の販売モデル（イメージ画像・縦長）

```
研修室で、作業着やオフィスカジュアルの社会人5〜6人がノートPCに向かい、前でスーツの講師がスクリーンにアプリ画面の図を映して教えている。受講者は自分で画面を操作して楽しそうに作っている。明るく清潔な研修室。縦長。
```

### 11. これからのチャレンジ（任意の挿絵・正方形）

```
4段の階段を一歩ずつ上る人物のシルエット。階段の上には地域の街並みと、さまざまな業種の建物（建設会社、工場、商店）が広がっている。緑のアクセント。正方形。
```

### 12. 03 区切り：多文化共生支援（イメージ画像・16:9）

```
佐世保の港町の明るい通りで、さまざまな国籍の若者（東南アジア、南アジア、ヨーロッパ系など）と日本人の職員が、スマートフォンを見ながら笑顔で話している。背景に海と島々。あたたかいオレンジのアクセント。左側に余白。16:9。
```

### 13. 行政・学校・企業の三位一体（概念図・正方形）

```
正三角形の頂点に3つのアイコン：上に市役所の建物、左下に学校の校舎、右下に工場とオフィスビル。三角形の中央に、さまざまな国籍の人々が手をつないで立っている。3つの頂点から中央へやわらかいオレンジの光の線。白背景。正方形。画像内に文字は入れない。
```

※ 「行政／学校／企業」「コンソーシアム」のラベルは Canva で載せる

### 14. 外国人向け支援アプリ（画面イメージ・縦長）

「AI活用の取り組み紹介」資料 p.4 の多言語AIチャットの画面を流用するのが一番早い。生成する場合：

```
スマートフォンの画面に、やさしい配色のチャットアプリが表示されている。上部に地球儀と言語切り替えのアイコン、吹き出しが交互に並び、下に「スタッフにつなぐ」ボタンのような丸いボタン。スマホを持つ外国人の手元、背景はぼかした街並み。縦長。画面内の文字は入れない。
```

### 15. まとめ（イメージ画像・16:9）

```
夕暮れから朝焼けに変わる佐世保の海と九十九島。手前の学習塾の校舎から3本の光の道（青・緑・オレンジ）がのび、街並み、企業の建物、さまざまな国の人々が集う広場へと広がっていく。前向きで希望のある雰囲気。上半分は余白。16:9。
```
