# 操作マニュアルへの反映待ち：v0.17.0 ヘルプデスク

v0.17.0 で、要項QAと「ご意見・不具合の報告」を会議DXの左メニューから外し、
総合メニュー（智翔館アプリのメニュー画面）の新しいアプリ「ヘルプデスク」へ移した。
作成中の「会議DX 操作マニュアル」（`docs/manual/meeting-dx-manual.html`・PDF・Web版）は v0.16.1 の画面で書いているので、
下の箇所を直す。**直し終えたら、このファイルは消してよい。**

- マニュアルの最新の原稿はブランチ `claude/festive-hamilton-fe7fmx` にある（`claude/pensive-gauss-f2rizh` の続き）。
  マニュアルの作業を再開するときは、先に `develop`（v0.17.0 が入ったもの）を取り込み、v0.17.0 の画面で撮影する
- 画面の仕様は README.md の「ヘルプデスク（要項QA・ご意見・不具合の報告）」の節と CHANGELOG.md の [0.17.0]

## 何が変わったか（マニュアルに関係するところ）

| | v0.16.1 まで | v0.17.0 から |
|---|---|---|
| 要項QAの開き方 | 会議DXの左メニュー「AIに聞く › 要項QA」 | メニュー画面の「ヘルプデスク」を押す（最初に要項QAが開く）。ダッシュボードの「要項QAで聞く」からも開ける |
| ご意見・不具合の報告の開き方 | 会議DXの左メニューの下（ログアウトの上） | メニュー画面の「ヘルプデスク」→ 上のタブ「ご意見・不具合の報告」 |
| 要項QAの画面の枠 | 左メニューつき（会議DXの中） | 上に紺色のヘッダ（← メニュー／ヘルプデスク／タブ「要項QA」「ご意見・不具合の報告」／部門と名前・ログアウト）。左メニューは無い |
| URL | `/yoko-qa`・`/inquiry` | `/helpdesk`・`/helpdesk/feedback`（古い URL を開いても新しい場所へ移る） |
| ダッシュボードの「実施期間中の要項」 | あり | **変わらずある**（カードの中身も同じ。「要項QAで聞く」の行き先だけがヘルプデスクになった） |

要項QAの画面の中身（要項カード・回答に使える要項・未確定の要項・質問の例・入力欄）と答え方は変わっていない。

- 冒頭の「左メニューの「要項QA」を押して開きます。」→

  ヘッダの「← メニュー」でメニュー画面へ戻ること、タブで「ご意見・不具合の報告」へ切り替えられることも書く
- 図18〜の写真（`images/30_yq_top.png`・`30b_yq_bottom.png`・`31_yq_card.png`・`32_yq_pending.png`・`33_yq_answer.png`）は

- （任意）「ご意見・不具合の報告」の使い方（種別・内容・画像を添えて送る、管理部門の回答が同じ画面に出る）を 3-6 として足す
