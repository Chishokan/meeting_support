動画「ログインの使い方（給与アプリを使わない社員向け）」ナレーション台本（音読さん用）
1枚ずつ、【】の下の文を音読さんに貼り付けて読み上げ、mp3 を「保存名」の名前で保存してください。
声・速さ・高さは、すべて同じにしてください。
作るのは 5 枚（約416字）です。

【1】保存名：01_title.mp3
智翔館アプリ、動画マニュアル。新しいログインの使い方を説明します。

【2】保存名：02_flow.mp3
変わるところは、ログインのしかただけです。これまでの、事業部とお名前を選ぶ入り方から、メールアドレスとパスワードで入る形になります。パスワードは、管理者から届くメールのリンクを開いて、ご自身で決めます。ログインしたあとのメニューや、会議ディーエックスなどの使い方は、これまでと同じです。

【3】保存名：03_mail.mp3
はじめに、パスワードを決めます。管理者から、パスワードの設定のお願いというメールが届きます。メールの、パスワードを決める、のリンクを開いてください。リンクは7日間、一度だけ使えます。

【4】保存名：04_setup.mp3　→ 作成不要（共通ログインの動画の音声を使います）
新しいパスワードを、確認のため2回入れます。8文字以上で、英字と数字を、両方含めてください。入れたら、「このパスワードにする」を押します。

【5】保存名：05_done.mp3　→ 作成不要（共通ログインの動画の音声を使います）
「パスワードを設定しました」と出たら完了です。「智翔館アプリへ」を押すと、そのままログイン画面に進めます。

【6】保存名：06_forgot.mp3　→ 作成不要（共通ログインの動画の音声を使います）
メールが届いていないときや、パスワードを忘れたときは、ログイン画面の、パスワードを忘れた方、から、自分で再設定のメールを頼めます。メールアドレスを入れて、「再設定のメールを送る」を押してください。届いたメールのリンクは、2時間有効です。

【7】保存名：07_login.mp3　→ 作成不要（共通ログインの動画の音声を使います）
次に、ログインです。智翔館アプリを開いて、メールアドレスとパスワードを入れ、「ログイン」を押します。一度ログインすると、同じ端末では12時間、ログインしたままになります。

【8】保存名：08_dept.mp3　→ 作成不要（共通ログインの動画の音声を使います）
複数の部門を兼務している人は、ログインのあとに、使う部門を選びます。会議ディーエックスなどは、ここで選んだ部門の内容になります。

【9】保存名：09_portal.mp3
ログインすると、これまでと同じメニューが開きます。右上に、部門とお名前が出ていることを確かめてください。会議ディーエックスなどの使い方は、これまでと変わりません。

【10】保存名：10_wrong.mp3　→ 作成不要（共通ログインの動画の音声を使います）
うまく入れないときです。メールアドレスまたはパスワードが違います、と出たら、入力を確かめてください。分からなければ、パスワードを決め直しましょう。15分の間に10回まちがえると、しばらくログインできなくなります。

【11】保存名：11_legacy.mp3　→ 作成不要（共通ログインの動画の音声を使います）
切り替えてから約2週間は、ログイン画面の下のリンクから、これまでどおり、事業部とお名前を選んで入ることもできます。期間が終わるまでに、メールアドレスで入れることを確かめておいてください。

【12】保存名：12_end.mp3
くわしくは、ヘルプデスクのマニュアルタブにある、ログイン利用マニュアルをご覧ください。困ったときは、ヘルプデスクから、お知らせください。
