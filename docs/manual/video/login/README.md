# 動画「共通ログインの使い方」の作り方

共通ログイン（v1.0.0）の使い方を、画面写真に強調の枠と字幕をのせたスライド動画（1920×1080・約3分）にする。
ナレーションは**音読さん**（Web の読み上げサービス）で作った mp3 を使う。しくみは部門会議の動画（`../src/`）と同じ。

| ファイル | 中身 |
|---|---|
| `storyboard.mjs` | 台本。スライド1枚ごとの字幕と読み上げ原稿（say） |
| `台本_音読さん用.txt` | 読み上げ原稿だけを並べたもの。音読さんに1枚ずつ貼る（storyboard.mjs から作る。下の「原稿を直したら」） |
| `slides.html` | スライドの見た目 |
| `shots/` | 画面写真（2倍の解像度）と、強調する枠の位置（CSS px の JSON） |
| `render.mjs` | コマ撮りして `out/login.mp4` と `out/poster.jpg` を作る |
| `audio/` | 音読さんで作った mp3（`01_title.mp3` … `14_end.mp3`） |

`out/` `frames/` `data.js` は作業用（git に入れない）。

## ナレーションを作る（音読さん）

1. `台本_音読さん用.txt` を開き、【1】から順に、本文を音読さんに貼り付けて読み上げる
   - 声・話す速さ・高さは、14枚すべて同じにする（途中で変えると、つないだときに不自然になる）
   - 「智翔館」が「ちしょうかん」と読まれないときは、音読さんの読み方の指定で直すか、原稿をひらがなにする
2. mp3 をダウンロードし、【】に書いた「保存名」（例 `01_title.mp3`）にして `audio/` に置く
3. 動画を作る

   ```sh
   cd docs/manual/video/login
   node render.mjs            # 読み上げの長さに合わせて各スライドの表示時間が決まる
   node render.mjs --silent   # ナレーションなし（字幕だけ）
   ```

4. `out/login.mp4` を `public/manual/login.mp4` に、`out/poster.jpg` を `public/manual/login-poster.jpg` に置き、
   `lib/manuals.ts` に動画の1件を足す（長さ・大きさを `meta` に書く）

## 原稿を直したら

- 字幕や読み上げは `storyboard.mjs` だけを直す。`say` を変えたスライドの mp3 は音読さんで作り直す
  （`render.mjs` は mp3 の中身までは見分けられないので、作り直し忘れに注意）
- `台本_音読さん用.txt` は次で作り直す

  ```sh
  node -e 'import("./storyboard.mjs").then(({SLIDES})=>{let t="動画「共通ログインの使い方」ナレーション台本（音読さん用）\n1枚ずつ、【】の下の文を音読さんに貼り付けて読み上げ、mp3 を「保存名」の名前で保存してください。\n\n";SLIDES.forEach((s,i)=>{t+=`【${i+1}】保存名：${String(i+1).padStart(2,"0")}_${s.id}.mp3\n${s.say}\n\n`});require("fs").writeFileSync("台本_音読さん用.txt",t)})'
  ```

- 画面写真は、智翔館アプリと給与アプリを手元で起動し、架空の職員（智翔 太郎）で撮った。枠の位置は撮るときに画面の部品から測っている
- 給与アプリ側の写真のロゴは、手元では本物を読めないため画面の写真から切り出したもので代用（帯の写真はボタンの部分だけを切り出している）

## 台本（14枚・約1,100字）

| # | 保存名 | 読み上げ原稿 |
|---|---|---|
| 1 | `01_title.mp3` | 智翔館アプリ、動画マニュアル。共通ログインの使い方を説明します。 |
| 2 | `02_flow.mp3` | 変わるところは3つです。1つ目、ログインは、メールアドレスとパスワードで行います。2つ目、アカウントは給与アプリと同じです。3つ目、給与アプリとの間を、ログインしたまま行き来できます。なお、智翔館アプリに入れるのは社員だけです。講師やアルバイトのスタッフの方は、これまでどおり給与アプリに直接ログインしてください。 |
| 3 | `03_know.mp3` | はじめに、パスワードです。給与アプリのパスワードを知っている人は、そのメールアドレスとパスワードで、智翔館アプリにも入れます。新しく決める必要はありません。 |
| 4 | `04_mail.mp3` | パスワードが分からない人には、管理者から、パスワードの設定のお願いというメールが届きます。メールの、パスワードを決める、のリンクを開いてください。リンクは7日間、一度だけ使えます。 |
| 5 | `05_setup.mp3` | 新しいパスワードを、確認のため2回入れます。8文字以上で、英字と数字を、両方含めてください。入れたら、「このパスワードにする」を押します。 |
| 6 | `06_done.mp3` | 「パスワードを設定しました」と出たら完了です。「智翔館アプリへ」を押すと、そのままログイン画面に進めます。 |
| 7 | `07_forgot.mp3` | メールが届いていないときや、パスワードを忘れたときは、ログイン画面の、パスワードを忘れた方、から、自分で再設定のメールを頼めます。メールアドレスを入れて、「再設定のメールを送る」を押してください。届いたメールのリンクは、2時間有効です。 |
| 8 | `08_login.mp3` | 次に、ログインです。智翔館アプリを開いて、メールアドレスとパスワードを入れ、「ログイン」を押します。一度ログインすると、同じ端末では12時間、ログインしたままになります。 |
| 9 | `09_dept.mp3` | 複数の部門を兼務している人は、ログインのあとに、使う部門を選びます。会議ディーエックスなどは、ここで選んだ部門の内容になります。 |
| 10 | `10_portal.mp3` | ログインすると、メニューが開きます。下の段の、給与・シフト、または、講師育成のカードを押すと、給与アプリが、ログインしたまま新しいタブで開きます。 |
| 11 | `11_back.mp3` | 給与アプリから戻るときは、上の帯の、「智翔館アプリへ」を押します。こちらも、ログインしたまま開きます。 |
| 12 | `12_wrong.mp3` | うまく入れないときです。メールアドレスまたはパスワードが違います、と出たら、入力を確かめてください。分からなければ、パスワードを決め直しましょう。15分の間に10回まちがえると、しばらくログインできなくなります。 |
| 13 | `13_legacy.mp3` | 切り替えてから約2週間は、ログイン画面の下のリンクから、これまでどおり、事業部とお名前を選んで入ることもできます。期間が終わるまでに、メールアドレスで入れることを確かめておいてください。 |
| 14 | `14_end.mp3` | くわしくは、ヘルプデスクのマニュアルタブにある、共通ログイン利用マニュアルをご覧ください。困ったときは、ヘルプデスクから、お知らせください。 |
