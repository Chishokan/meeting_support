# 智翔館の広報デザインの基本

## 前提

- claude.ai の「Design System」アーティファクト（https://claude.ai/artifact/3LQufnh4ZC7vbXXupAQig1）は、この作業のツールでは中身を読めなかった〔要確認：正式なトークンがあればこの文書を差し替える〕。
- 以下は2026年9〜10月の制作物（確定チラシ、LP、スライド、NEPサイト案）から採った値。チラシの色は画像からの採取で幅がある。

## 1. 色の考え方（全媒体共通）

| 役割 | 色 | 使い方 |
|---|---|---|
| 土台 | 白 | 背景の基本。余白を十分に取る |
| ブランドの主色 | 濃紺 | 帯見出し、最下部のCTA帯、大見出し、大きな数字 |
| アクセント | 明るいブルー | ラベル、番号、アイコン、強調したい数字、ボタン |
| 強調（少量） | 赤 | 対象ラベル、日付・曜日、締切、特典のタグ、前年割れの数字 |
| 強調（ごく少量） | 黄 | マーカー風の下線、バッジ、締切、特典ボックスの薄い地。「絶対に見てほしい一語」だけ |

- 赤と黄は1紙面・1スライドで数か所まで。
- 講座ごとに色を分けたいときは主色（濃紺）だけを差し替え、赤・黄・ラベルは共通のままにする（冬期講習の例：中3＝濃紺、中1・2＝青緑 #0E7C6B、県中＝深い紫 #4A2C82）。

- 暗くなりすぎないこと。中学生向けは「明るい・前向き・活気がある・清潔感がある」印象を優先する。図形は単色・フラットにする。
- 〔要確認〕制作担当の作業ルール（2026年8月、docs/04-design.md）では、アクセントを「オレンジ／ゴールド／朱色／水色／白を案件に応じて使う」としている。現行（この文書・2026年11月）は黄・赤が基本で、スライドではオレンジを使わない、チラシではオレンジは1か所まで。新しい方（この文書）を優先する。
- 例外：RED個別の教室販促物は赤が主色になることがある（2026年10月 RED西海大島教室のBOXティッシュは天面を赤一色、配色は赤・白・黄。REDのポケットティッシュに合わせた）。〔要確認：REDの販促物の配色ルール〕

| 置き場 | 中身 | 備考 |

## 3. 書体

| 媒体 | 見出し | 本文 | 補足 |
|---|---|---|---|
| チラシ（画像生成） | くっきりした太いゴシック体 | ゴシック体 | 滲み・ぼやけ・疑似文字は禁止。担当のメッセージは手書き風の書体にした例あり |
| 既存サイト | ヒラギノ角ゴ W7 | ヒラギノ角ゴ W4（16px） | — |

| NEPサイト・AI活用LP | Zen Kaku Gothic New 900 | Noto Sans JP | 本文16px・行間1.8 |
| アイキャッチ（落ち着いた版） | 明朝体 | — | 生成りの地＋実写＋くすんだアクセント |

## 3-2. 情報階層（全媒体共通）

情報量より「一瞬で何の広告か分かること」を優先する。特にポスター・サイネージ・バナー・LPのヒーローで重要。すべての文字を同じ強さで見せない。

| レベル | 内容 |
|---|---|
| LEVEL 1 | 最も伝えたいタイトル・商品名 |
| LEVEL 2 | メインコピー |
| LEVEL 3 | メリット・成果 |
| LEVEL 4 | 日程・対象・料金 |
| LEVEL 5 | CTA・QR・問い合わせ |

- よくある失敗：本来のタイトルよりコピーの方が目立つ。例：おはよう勉強会の広告なら、「朝の1時間で、未来が変わる。」より「おはよう勉強会」という活動名を最も認識しやすくする。
- 印刷物で特に見やすくする要素：日付、料金、対象、QRコード、会場。

## 3-3. よく使うサイズ

| 媒体 | サイズ | 解像度 |
|---|---|---|
| 配布チラシ | A4縦、B4 | 300dpi想定 |
| 掲示ポスター | A2縦、A1縦 | 300dpi想定 |
| デジタルサイネージ | 1920×1080（フルHD、16:9） | — |
| BOXティッシュ（入稿型 com_b40w、コンパクト40W Bタイプ、製品165×115×30mm） | Canva の A4縦（794×1123px）に型を載せて作る | 入稿基準350dpi |

## 3-4. 既存デザインを直すときの順番

全面的に作り直す前に、次の順で確かめる。

1. 情報階層 → 2. タイトルの大きさ → 3. コピー → 4. 余白 → 5. 写真 → 6. 色 → 7. CTA → 8. QR → 9. 視線の流れ

## 4. 共通の部品（チラシ・ポスター・サイネージ）

| 部品 | 形 |
|---|---|
| 帯見出し | 濃紺の帯に白文字 |
| 対象ラベル | 赤「中学◯年生 対象」＋青「塾生以外も受験OK」を並べる |
| 大見出し | 濃紺の極太。黄色マーカー（必要なら白フチ） |
| バッジ | 黄色の丸（無料講座の「参加無料」）／赤の横長リボン（早割など）／日めくり型の日付カード。有料講座で「参加無料」の丸バッジは使わない |
| POINT | 横3カード／縦3段（説明が1行を超えるとき）／左に濃紺ボックス＋右に黄色チェック |
| 料金表 | 列＝塾生・一般生。すすめたい行だけ薄い黄色、金額は赤の太字。行ラベルに中身 |
| 特典ボックス | 薄い黄色の地、赤のタグ。中身と結果を大きく、条件は小さく |
| CTA帯 | 最下部の濃紺帯：左にロゴ用白枠、中央に「一般生のお申込みはWEBから」「申込締切」（黄）、電話番号（大きく黄）、右にQR用の白い正方形と「WEBからのお申し込みはこちら」 |
| 写真 | リアルな日本の教育現場。自然光、大人は入れない、メイン1点。端まで広げず上・右に余白 |

## 4-2. 媒体別メモ：BOXティッシュ（2026年10月 RED西海大島教室で確立）

| 手順 | 内容 |
|---|---|
| 1 過去データを集める | Canva（「BOXティッシュ」「ボックスティシュ」で検索）と `library/05_広告制作/` の .ai・PNG |
| 2 型を残して複製 | Canva の過去デザインを複製し、型（展開図）だけ残す。型の画像はロックされた最背面の要素。元デザインは触らない |
| 3 面ごとに確認 | 天面 → 裏面 → 側面の順。一面ずつ確認をもらう |
| 4 分担 | 写真・イラストは ChatGPT、ロゴ・QR・地図・電話番号・料金は Canva |
| 5 案の管理 | 複製して「_案1」「_案2」。前の案を消さない |

型の座標（Canva のページpx。1mm＝約3.014px）

| 面 | 左 | 上 | 幅 | 高さ |
|---|---|---|---|---|
| 天面 | 149.4 | 148 | 497.4 | 346.6 |
| 側面1（手前・天面と裏面の間） | 149.4 | 494.6 | 497.4 | 90.4 |
| 裏面（底面） | 149.4 | 585 | 497.4 | 346.6 |
| 側面2（奥。上下逆に配置） | 149.4 | 60.6 | 497.4 | 87.4 |
| 側面3（左の短辺。90度回転） | 62 | 148 | 87.4 | 346.6 |
| 側面4（右の短辺。−90度回転） | 646.8 | 148 | 87.4 | 346.6 |

- 取り出し口は天面の中央（横 215.7〜580.5px、縦 271.6〜366.8px＝面の上から41〜73mm）。文字・顔・QRを置かない。
- 裏面の左右は糊しろ（斜線部分）。デザインを置かず、裏面の画像は面の幅ぴったりに収める。
- 側面3・4の外側は塗り足しとして約3mm（9px）はみ出させる。仕上がり線から3mm以内に文字を置かない。
- デザインの方向：過去デザインの踏襲より一新。写真1枚＋コピー1本＋余白。天面は対象（小・中・高）を限定せず、小学生向けの詳細は裏面か天面の下半分へ。情報は白い枠にまとめ、強調は黄色。
- 教室名の表記は「RED西海大島教室」。
- 案件の記録：`work/2026-10_BOXティッシュ_RED西海大島/` の README（制作担当のPC）。

## 5. 使わない表現

- 過度な光沢、メタリック表現、反射光、ギラギラした装飾（docs/04-design.md）。
- 過剰なグラデーション、大量のドロップシャドウ、ネオンカラー、3Dアイコン、過剰な角丸、不自然な光彩・文字のグロー、情報が紙面全体に散らばるレイアウト。
- 画風を変える案（線画・設計図風、写真なし、文字だけ、斜め分割）は不採用（2026-10-08）。
- イラスト調の人物は原則使わない（本番レベル模試は比較のうえ例外的に採用）。スライドは逆に青一色のフラットなイラストにそろえる。
- 外部連携の企画（例：長崎国際大学薬学部とのセミナー）は緑 #057B40 ＋黄 #F2E64E ＋明朝体のチラシを作った例がある〔要確認：ブランド外の配色を認める条件〕。
