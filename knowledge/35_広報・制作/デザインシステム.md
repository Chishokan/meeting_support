# 智翔館の広報デザインの基本

## 前提

- claude.ai の「Design System」アーティファクト（https://claude.ai/artifact/3LQufnh4ZC7vbXXupAQig1）は、この作業のツールでは中身を読めなかった〔要確認：正式なトークンがあればこの文書を差し替える〕。
- 以下は2026年9〜10月の制作物（確定チラシ、LP、スライド、NEPサイト案）から採った値。チラシの色は画像からの採取で幅がある。

## 1. 色の考え方（全媒体共通）

| 役割 | 色 | 使い方 |
|---|---|---|
| 土台 | 白 | 背景の基本。余白を十分に取る |
| ブランドの主色 | 濃紺 | 帯見出し、最下部のCTA帯、大見出し、大きな数字 |
| アクセント | 明るいブルー | ラベル、番号、アイコン、強調したい数字、ボタン |
| 強調（少量） | 赤 | 対象ラベル、日付・曜日、締切、特典のタグ、前年割れの数字 |
| 強調（ごく少量） | 黄 | マーカー風の下線、バッジ、締切、特典ボックスの薄い地。「絶対に見てほしい一語」だけ |

- 赤と黄は1紙面・1スライドで数か所まで。
- 講座ごとに色を分けたいときは主色（濃紺）だけを差し替え、赤・黄・ラベルは共通のままにする（冬期講習の例：中3＝濃紺、中1・2＝青緑 #0E7C6B、県中＝深い紫 #4A2C82）。

| 赤 | #E3000B 前後 | #D8343F | —（前年割れは赤） | — |

- 既存サイト（chishokan.co.jp）：アクセント #0571D5、本文 #333333、申込ボタンはオレンジ #FF6900・角丸6px（既存LP共通）。新しいLPのボタンはブルー。

## 3. 書体

| 媒体 | 見出し | 本文 | 補足 |
|---|---|---|---|
| チラシ（画像生成） | くっきりした太いゴシック体 | ゴシック体 | 滲み・ぼやけ・疑似文字は禁止。担当のメッセージは手書き風の書体にした例あり |
| 既存サイト | ヒラギノ角ゴ W7 | ヒラギノ角ゴ W4（16px） | — |
| 講座LP（カスタムHTML） | Noto Sans JP 900 | Noto Sans JP 400〜700 | 担当メッセージは Klee One、手書きの一言は Yomogi |
| NEPサイト・AI活用LP | Zen Kaku Gothic New 900 | Noto Sans JP | 本文16px・行間1.8 |
| アイキャッチ（落ち着いた版） | 明朝体 | — | 生成りの地＋実写＋くすんだアクセント |

## 4. 共通の部品（チラシ・ポスター・サイネージ）

| 部品 | 形 |
|---|---|
| 帯見出し | 濃紺の帯に白文字 |
| 対象ラベル | 赤「中学◯年生 対象」＋青「塾生以外も受験OK」を並べる |
| 大見出し | 濃紺の極太。黄色マーカー（必要なら白フチ） |
| バッジ | 黄色の丸（無料講座の「参加無料」）／赤の横長リボン（早割など）／日めくり型の日付カード。有料講座で「参加無料」の丸バッジは使わない |
| POINT | 横3カード／縦3段（説明が1行を超えるとき）／左に濃紺ボックス＋右に黄色チェック |
| 料金表 | 列＝塾生・一般生。すすめたい行だけ薄い黄色、金額は赤の太字。行ラベルに中身 |
| 特典ボックス | 薄い黄色の地、赤のタグ。中身と結果を大きく、条件は小さく |
| CTA帯 | 最下部の濃紺帯：左にロゴ用白枠、中央に「一般生のお申込みはWEBから」「申込締切」（黄）、電話番号（大きく黄）、右にQR用の白い正方形と「WEBからのお申し込みはこちら」 |
| 写真 | リアルな日本の教育現場。自然光、大人は入れない、メイン1点。端まで広げず上・右に余白 |

## 5. 使わない表現

- 過剰なグラデーション、大量のドロップシャドウ、ネオンカラー、3Dアイコン、過剰な角丸、不自然な光彩・文字のグロー、情報が紙面全体に散らばるレイアウト。
- 画風を変える案（線画・設計図風、写真なし、文字だけ、斜め分割）は不採用（2026-10-08）。
- イラスト調の人物は原則使わない（本番レベル模試は比較のうえ例外的に採用）。スライドは逆に青一色のフラットなイラストにそろえる。
- 外部連携の企画（例：長崎国際大学薬学部とのセミナー）は緑 #057B40 ＋黄 #F2E64E ＋明朝体のチラシを作った例がある〔要確認：ブランド外の配色を認める条件〕。
