# 広告・コピーの考え方

出典は制作担当の作業ルール（docs/03-marketing.md、2026年8〜9月）。
見た目のルールは `デザインシステム.md`・`チラシ制作/10_デザインルール.md`、理念・募集の考え方は `10_理念・方針/COMPANY.md` を見る。ここではコピーと情報の選び方だけを扱う。

## 1. 基本の考え方

- 広告の目的は「塾の特徴を説明すること」ではない。
- 読んだ生徒・保護者が次の状態になることを目指す。

| 状態 | 確かめること |
|---|---|
| 自分に関係がある | 対象（学年・学校・時期）がすぐ分かるか |
| 今行動する理由がある | 日程・締切・今やる意味が書いてあるか |
| 参加するメリットが分かる | 受けた後に何ができるようになるか |
| 不安が解消される | 料金・日程・サポート体制が分かるか |

### 広告の構造

```
課題 → 解決策 → 根拠 → 行動
```

- 根拠は数字・実績・具体的な中身。行動は申込・問い合わせ・体験。

## 2. ターゲット

- 主な読み手：小学生／中学生／高校生／保護者。
- 中等部の案件は、中学生本人と保護者の**両方**に向けて書く。

| 読み手 | 重視する感覚・明確にすること |
|---|---|
| 中学生 | 分かりやすい、楽しそう、仲間がいる、成績が上がりそう、自分でもできそう |
| 保護者 | 成果、安心感、指導内容、学習習慣、料金、日程、サポート体制 |

## 3. コピーの書き方

- 抽象的な教育コピーだけで終わらせない。
  - 弱い例：「未来を切り拓く力を育てる」（これだけでは何の広告か分からない）
- **具体的な成果／数字／行動／時期／対象**を組み合わせる。
- ブランドコピーを使うときも、具体情報で補う。

| ブランドコピー | 補う具体情報（おはよう勉強会の例） |
|---|---|
| 「朝の1時間で、未来が変わる。」 | 朝6時から、Zoomで参加、学習習慣、総学習時間、成績の成果 |

- 数字・実績は確定したものだけを使う（推測で埋めない）。
- 学校・他塾との比較、不安をあおる表現、要項にない割引・特典は使わない（`チラシ制作/10_デザインルール.md` 1-1）。

## 4. 導線の設計

単発の広告ではなく、**認知 → 興味 → 体験 → 入会**の流れで考える。

| 媒体 | 流れ |
|---|---|
| チラシ | 配布 → 認知 → QR → LP → 申込 |
| LP | 流入 → 理解 → 納得 → CTA → 問い合わせ |
| イベント | 告知 → 参加 → 体験 → 成果 → 次の商品・学習行動 |

- イベントは「参加して終わり」にしない。次の講座・入会・学習習慣につなげる設計にする（継続面談など、`COMPANY.md`「募集に対する考え方」）。
- QRとLPの作り方は `Web制作/30_LP制作.md`。

## 5. LINE公式の位置づけ

- LINE公式は保護者・生徒との重要な接点。
- 用途：問い合わせ、欠席・遅刻の連絡、成績入力、イベント案内、申込、AI診断、Q&A。
- できるだけ **LINE → LP／フォーム → 申込** の導線を短く、単純にする。
- 〔要確認〕LINE公式のアカウント（部門別か全社1つか）、運用担当、配信ルール。生徒用の「智翔館LINEアプリ」（マイページ）との関係は `30_部門/教務運営.md` を参照。

## 6. 情報を削る判断

- すべての情報を載せる必要はない。特に**ポスター・サイネージ・バナー・LPのヒーロー**は、詳しい情報をLPに送り、その媒体で必要なものだけ残す。
- 判断基準：

> この情報がなくても、読み手は次の行動を取れるか？　→ YES なら削る候補

| 媒体 | 残すもの（目安） | LPに送るもの |
|---|---|---|
| ポスター・サイネージ・バナー | 商品名、メインコピー、対象、日程、QR | カリキュラム、料金の内訳、FAQ、持ち物 |
| チラシ | 上記＋メリット、料金、締切、問い合わせ | 細かい注意事項、声、FAQ |
| LPのヒーロー | 誰向けか、何の商品か、最大のメリット、CTA | 中段以降で説明する |

- 文字を小さくして詰め込むのではなく、情報そのものを削る（`チラシ制作/10_デザインルール.md` 7）。

## 7. 地域・教室の広告で気をつけること

2026年10月、RED西海大島教室のBOXティッシュ制作で確認した判断。

- 地域を否定する言い方をしない。前向きな表現だけにする（例：「小学生のうちに、英語を。」）。
- 営業色を強くしない。成績アップ率、生徒数No.1、月額料金の比較などの数字は使わない。
- 細かい説明を詰め込まず、写真1枚＋コピー1本＋余白でイメージを伝える方向が好まれた。
