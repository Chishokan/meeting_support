# 講座LP（申込ページ）の作り方

## 1. LPの位置づけ

- チラシ・ポスター・サイネージのQRから、スマホで開かれる前提。読む人は生徒本人と保護者（塾生以外の一般生を含む）。
- 役割は「申込を受けること」。講座の価値・日時・料金・締切・申込方法・問い合わせが、最初の画面とページ末尾で分かるようにする。
- 価格を他と比べて選ぶ商品ではない。比較表は使わない（2026-10の判断）。
- チラシと同じ配色・同じキャッチでシリーズに見せる。

## 2. 作り方の流れ

| 工程 | やること | 担当の目安 |
|---|---|---|
| 1 要項確認 | 講座名、対象、日時（校舎別）、会場、料金（塾生／一般生）、申込方法・期限、特典、持ち物、問い合わせ。埋まらない項目は「未定」 | 制作 |
| 2 下書き作成 | 前回の同種LPを複製して下書きを作る（またはREST APIで作成）。投稿タイプ `campaign`、URLは /campaign/スラッグ/ | 制作 |
| 3 設定 | タイトル、スラッグ、メイン画像、アイキャッチ、AIOSEO（説明文・キーフレーズ）、カテゴリ。佐世保向けはタイトルに「佐世保」 | 制作 |
| 4 本文 | 構成の型（3章）で書く。要項にない文言は一覧にして担当確認へ | 制作→講座担当 |
| 5 フォーム | 既存フォームを管理画面で複製し、今回用に直す（4章） | 複製は本人、書き換えは制作 |
| 6 担当確認 | パスワード保護で公開して確認してもらう | 講座担当 |
| 7 公開 | 保護を外して通常公開。QRからスマホで開けるか確認 | 本人 |
| 8 送信テスト | 本人が人の手で送信。件名・台帳の校舎・Googleシート | 本人 |

ページタイトルの例：「【佐世保の中学3年生向け】公立高校・高専 本番レベル模試＋LAST LAP BELL セミナー｜11/22（日）開催・成績優秀者は授業料免除」（【地域＋対象】講座名｜日付・最大の利点）。

## 3. 構成の型

### 3-1. 簡易版（無料・単日。3セクション）

定期テスト対策（2026秋）で採用。

1. ファーストビュー：チラシと同じキャッチ・サブ、「参加無料」、申込フォームへ飛ぶボタン
2. 内容・日程：ポイント3つ、校舎別の日程表、持ち物、申込締切
3. 申込フォーム＋問い合わせ：フリーダイヤルと各校舎の電話

### 3-2. 標準版（有料・単日のイベント）

本番レベル模試・特待生選抜テスト（2026秋、カスタムHTML版）の並び。

| 順 | セクション | 中身 |
|---|---|---|
| 1 | ヒーロー | 対象ラベル（「中学3年生対象｜塾生以外も受験可」）、講座名（H1）、サブ（黄色マーカー）、1行リード、日時・会場（アイコン付き）、申込ボタン、赤枠の「一般生申込締切 ◯月◯日（◯）」、右に写真またはイラスト |
| 2 | 担当からのメッセージ | 講座担当が指定したリード文（手書き風書体 Klee One） |
| 3 | このページでわかること | 4つのカード（イベントの価値／当日のプログラム／受験料・特典／申込方法）でページ内リンク |
| 4 | この1日で、できること | 3枚のカード（アイコン＋見出し＋1行） |
| 5 | 当日のプログラム | 第1部・第2部を縦のタイムライン |
| 6 | 受けたあとに得られること | 3枚のカード |
| 7 | 受験料・特典 | 塾生／一般生の金額ボックス＋赤タグ「成績優秀者特典」の薄い黄色ボックス（条件は小さく、中身を大きく） |
| 8 | 開催概要 | 表（対象・日時・会場・内容・締切・問い合わせ・受付時間）。締切は赤 |
| 9 | 申込の流れ | 3ステップ（フォーム入力→内容確認→申込完了） |
| 10 | 申込フォーム | Contact Form 7 のショートコード |
| 11 | フッター | 濃紺帯に電話・受付時間・運営 |

### 3-3. 季節講習版（複数コース）

冬期講習LPのフレーム案（2026-10-13、A4確認用PDF・12ページ）の並び。

- ヒーロー（学年別のキャッチ「中学1・2年生 受験対策のスタートダッシュ」「中学3年生 合格へのラストスパート」）、申込ボタン（メール／LINE）、早割バッジ、入試までのカウントダウン
- 成績の変化（合格者の偏差値・順位の伸び）〔要確認：個人が特定されない表記か〕
- 学年別のプログラム（各プログラムに「Point」）、参加者の声
- 合格までのロードマップ（月別）
- 関連講座（高専攻略講座など）への誘導
- コース概要（日程・時間・受講料・割引）→「このコースに申し込む」
- カレンダー、申込方法（塾生／一般生）、オンライン受講、FAQ、締めのCTA
- 注意：フレーム案の段階では受付時間が「9:30〜22:00」、FAQに別講座の文言、カレンダーの説明文に「9月・10月」など前回の残りがあった。複製元の文言は必ず全部読み直す

### 構成で効いた工夫（参考サイトの調査、2026-10-19）

| 工夫 | 参考 |
|---|---|
| 受ける前と受けた後（BEFORE／AFTER） | 体験を売るサイト（RIZAP） |
| 「できること」を動詞で分ける（聴く・解く・知る・決める） | 星野リゾート 界、キッザニア |
| 締切・カウントダウンで今決める理由を作る | 東京マラソン、キッザニア |
| 申込ボタンを最初の画面とページ末尾に置く | Netflix、Spotify |
| 「保護者の方へ」の入口 | Nintendo Switch Online |

## 4. 申込フォーム（Contact Form 7）

- 新規作成はREST APIで保存されない。管理画面で前回のフォームを「複製」→タイトルを「講座名_実施日」に（例「特待生選抜テスト_2026年11月22日」）。
- 直す項目

| タブ | 直すところ |
|---|---|
| フォーム | 学年の選択肢を対象に合わせる。希望日程・コース（ラジオボタン）。会場が1校なら hidden で `your-campus` に固定（例「駅前校」）。同意文・reCAPTCHAはそのまま |
| メール（スタッフ宛て） | 件名「【智翔館HP】講座名（日付）お申し込み」。本文の項目名を今回用に |
| メール(2)（自動返信） | 前回の項目（使わない選択肢など）が残っていないか |
| Webhook | URL末尾の `form=講座名` を今回の講座名に（問い合わせ管理台帳で講座が分かる） |

- LPの本文（カスタムHTMLの中でも可）に `[contact-form-7 id="新しいid" title="フォーム名"]` を入れる。
- 実例：前回フォームを仮置きしたら受験希望日程が「7月6日（日）」、件名が「お問い合わせ（中学生）」のままだった→必ず今回用に複製して直す。

## 5. 画像

| 種類 | サイズ | 作り方 |
|---|---|---|
| LPメイン（ヒーロー・アイキャッチ） | 1672×941（16:9） | サイネージ画像からQR枠を消しロゴを入れる、またはLP専用に生成 |
| ヒーローの写真部分 | 例 476×778 | サイネージの人物部分を切り出す |
| 本文のイメージ | 1448×1086 | 生成。文字なし。「※画像はイメージです」を添える |
| アイキャッチ（一覧カード用） | 16:9 | 1.85:1で中央が切り抜かれる。文字は内側に。派手すぎると「騒がしい」と言われた→生成りの地＋明朝体＋実写の生徒＋くすんだアクセントで作り直した例 |

生成しないもの：セミナーの話し手の写真、受験者・保護者の声（実在の人と実際の声が必要）。

## 6. QRコード

- URLに `utm_source`（媒体：flyer／poster／signage と校舎）、`utm_medium=qr`、`utm_campaign`（短い名前。例 hl26、ts26）を付ける。
- A4で18mm角以上。チラシを4倍に拡大して白枠に重ねる。合成後に位置を目で確かめる。
- パソコン上の読み取り確認に加え、スマホでの読み取りを本人が確認する。
- LPが下書き・パスワード保護の間は、QRを読んでもページが見えない（パスワード画面になる）。配布開始日までに公開する。

## 7. 公開前チェック

- [ ] 日付・曜日・時間・料金・締切・電話番号がチラシと要項に一致
- [ ] 受付時間が全部門共通の表記
- [ ] 赤字の制作メモ（【確認中】【素材待ち】）が消えている
- [ ] 申込フォームが今回用（学年・日程・件名・Webhook）
- [ ] AIOSEO の説明文・キーフレーズ、アイキャッチ
- [ ] PCで本文が左に寄らない（テーマが子要素に最大幅を付ける。カスタムHTMLは幅960pxで中央に）
- [ ] スマホで最初の画面に講座名・日時・申込ボタンが入る
- [ ] QRからスマホで開ける
- [ ] 本人による送信テスト（自動返信・台帳・Googleシート・サンクスページ）

## 8. カスタムHTMLで作る場合

- 本番レベル模試・特待生選抜テストは、ChatGPTに「商品の情報と読む人だけ」を渡してスマホの縦長1枚のLP案を作らせ（構成やデザインの指示はしない）、それをHTMLで再現した。
- CSSは `#cks-lp` の中だけに効くようにし、テーマの見出し装飾（::before／::after、枠線）を打ち消す。
- 元のHTMLは `05_広告制作/20261019_LP_HTML/src/`、WordPress用は `wp/`。作り直しは src を直して `src/build_wp.py` を実行。
- ブロック版にあった【確認中】【素材待ち】の項目（結果の返し方、話し手、受験者の声、保護者の方へ）はHTML版に入っていない。

## 10. 要項にない文言の扱い

制作側で書いた文言（キャッチ、カードの説明、受ける前と後、締めの一言、FAQの回答）は、公開前に一覧にして講座担当の確認を取る。確認が取れないものは載せない。
