# Web制作 ナレッジの使い方

## ファイル構成

| ファイル | 開く場面 |
|---|---|
| `10_サイト構成.md` | どのサイト・どのページを直すかを特定したい。URL、CMS、サーバー、ページの分類 |
| `20_更新・修正の手順.md` | 既存ページの文言・画像・バナーを直す。WordPressやプラグインを更新する。不具合が出た |
| `30_LP制作.md` | 講座・イベントの申込ページ（LP）と申込フォームを新しく作る、前回のLPを今回用に直す |
| `../デザインシステム.md` | 色・書体・ボタンなど見た目をそろえたい |
| `../チラシ制作/` | LPと同じ講座のチラシ・QRの扱い |

## 依頼の受け方（AIへの聞き方の例）

| 依頼 | AIが最初に確かめること |
|---|---|
| 「◯◯校のページの電話番号を直したい」 | 対象URL（10）、公開中か、誰が確認するか |
| 「冬期講習のLPを作りたい」 | 要項（講座名・対象・日程・料金・申込方法・期限）、前回の同種LP、フォームの要否（30） |
| 「トップのスライダーのバナーを替えたい」 | 差し替える画像とリンク先、スライダーの枚数（20） |
| 「サイトが表示されない」 | 直前に何を変えたか、どのURLか、管理画面に入れるか（20 のトラブル表） |

## 守ること

- パスワード・アプリケーションパスワード・サーバーのログイン情報は、AIに渡さない・書かない・チャットに貼らない。ログインは本人が行う。
- 公開中ページの変更は、明らかな誤り（受付時間、選択肢の不足など）以外は案を出して了承を得てから。
- 受付時間は全部門共通「月〜土 13:00〜21:30（日・祝を除く）」、フリーダイヤル 0120-41-1976。古いページに別の時間（9:30〜22:00 など）が残っていれば直す対象。
- 生徒の個人名は載せない。実績は「学校名＋学年＋教科＋点数」。体験談は名前を出さない。
- 申込フォームの送信テストは本人（人の手）で行う。自動入力のテストは弾かれることがある。
- 変更前に画面を保存（スクリーンショット）し、変更後と見比べる。
