# 画像生成AIの使い方

A4チラシのプロンプト・修正・チェックは `チラシ制作/`（00〜51）に一式ある。ここには、それ以外の媒体にも共通する使い方と、2026年8〜10月の制作で分かった制約だけを書く。
出典：制作担当の作業ルール（docs/05-image-generation.md・04-design.md・13-environment.md）。

## 1. ツールの役割分担

| ツール | 役割 | 使わないこと |
|---|---|---|
| Claude | 企画、コピー、画像生成プロンプトの作成 | — |
| ChatGPT（画像生成） | 写真・イラスト・背景の生成 | ロゴ、QR、電話番号・料金・時間などの正確な数字 |
| Canva | 文字組み、ロゴ・QR・地図・電話番号・料金の配置、微調整、書き出し | — |

### 制作の流れ

1. Claude でプロンプトを作る（このファイルと `チラシ制作/10_デザインルール.md` を適用）。
2. ChatGPT に渡して画像を生成する。保存したら、すぐ案件の制作フォルダへ入れる（Downloads に残さない。`60_規程・手続き/ファイル管理とドライブのルール.md`）。
3. Canva で文字・ロゴ・QRを載せ、調整する。
4. 書き出して納品フォルダに置き、Drive の `05_広告制作` に上げて LINE WORKS で共有する。

- Canva のブランドキットに智翔館の色を登録しておく。〔要確認〕2026年8月時点で色のHEX値が未登録で、ChatGPT のプロンプトと Canva の色がずれるおそれがあった。登録する値は `デザインシステム.md` の値と合わせる。

## 2. プロンプトで必ず指定する項目

イメージの説明だけでなく、**レイアウトまで**書く。

| 項目 | 例 |
|---|---|
| サイズ・縦横比 | A2縦（420×594mm）、1:1.414、300dpi想定 |
| 使用目的 | 校舎掲示、配布、サイネージ |
| ターゲット | 中学3年生本人＋保護者 |
| メインタイトル（LEVEL1） | 商品名・講座名。いちばん大きく |
| コピー（LEVEL2） | メインコピー |
| 情報階層 | 上部／中央／下部に何を置くか |
| 写真の位置 | 中央に写真枠など |
| QRの位置 | 右下にQR用の白い余白 |
| ロゴの位置 | 下部など（ロゴは描かせない） |
| 配色 | `デザインシステム.md` の配色 |
| フォントの傾向 | 太めのゴシック、読みやすさ優先 |
| NG表現 | メタリック、強い光沢、反射光、3D、ギラギラした装飾、存在しない文字、読めない日本語 |

情報階層（LEVEL1〜5）の考え方は `デザインシステム.md` に追記した節を参照。

## 3. ポスター用の雛形（情報階層つき）

```
【用途】〇〇（例：A2縦ポスター／校舎掲示）
【サイズ】A2縦（420×594mm）／縦横比 1:1.414／300dpi想定
【ターゲット】中学3年生本人＋保護者
【メインタイトル｜LEVEL1】〇〇（最も大きく、一瞬で認識できること）
【メインコピー｜LEVEL2】〇〇
【メリット・成果｜LEVEL3】〇〇
【日程・対象・料金｜LEVEL4】〇〇
【CTA・QR｜LEVEL5】右下にQRコード用の白余白 40×40mm
【レイアウト】
 上部：タイトル＋コピー
 中央：写真枠（人物差し替え用の余白のみ）
 下部：日程・対象・料金／CTA・QR／ロゴ
【配色】ベース＝深いネイビー。アクセントは デザインシステム.md に合わせる。暗くなりすぎない。
【フォント傾向】太めのゴシック。可読性最優先。
【NG表現】メタリック、強い光沢、反射光、3Dエフェクト、ギラギラした装飾、
 実在しない文字情報の生成、判読不能な日本語の描き込み
```

- 元の雛形はアクセントを「オレンジ／白」としていた。現行ルール（2026年11月）は黄色＋赤が基本で、オレンジは1か所まで〔要確認：ポスターでオレンジを使ってよいか〕。

## 4. 人物を後から差し替えるとき

- 実写の写真に差し替える前提なら、AIに人物を描かせず、**人物用の余白・写真枠だけ**を確保させる。
- 実写は Dropbox の写真データを使う。
- 〔要確認〕制作担当のルール（2026年8月）は「生成で人物を描かせない」だが、2026年秋のチラシでは生徒1人の写真を生成して採用している（`チラシ制作/10_デザインルール.md` 4・`51_制作実例_2026秋.md`）。どちらを原則にするか、媒体で分けるかは未整理。

## 5. 数字・ロゴを描かせない

- 日程・料金・実績などの**数字は生成画像に描き込ませない**。後から Canva でテキストとして載せる（誤字防止と、後で直せるようにするため）。
- ChatGPT は短い日本語コピーなら正確に描けることが多いが、電話番号・料金・時間は Canva で打つ。
- ロゴは生成させない。正式データ（`assets/logo/`、または支給されたSVG）を置く。白抜きはSVGの塗りを入れ替えて作る。

## 6. ChatGPT で分かっている制約（2026年10月時点）

| 制約 | 対処 |
|---|---|
| 「写真風の小学生」はコンテンツポリシーで断られる | イラスト調を指定する |
| 出力の最大は 1536×1024px（3:2） | 165mm幅の印刷で約230dpi。入稿基準350dpiには届かない。大きく使う面は余白・単色の地にして、写真は小さめに |
| 細長い面（帯）を直接作れない | 「3:2の画像の中央に帯を1本だけ置き、上下は白い余白」と指定し、帯だけ切り出す |
| 帯の中に項目を並べると文字が小さい | 4項目なら横一列より2列×2段にする |

- A4チラシの解像度の目安は `チラシ制作/40_チェックリスト.md` 3。

## 7. 進め方のコツ（2026年10月 BOXティッシュ制作から）

- 一度に全部を作らず、面（部分）ごとに作ってその都度確認をもらう。
- 案を変えるときは複製して「_案1」「_案2」と名前を付け、前の案を消さない。
- 担当者が Canva で直接直した箇所（位置・色・書体・文言）は、次の編集で元に戻さない。編集前に必ず今の状態を確かめる。
- 指示は短く一つずつ出されることが多い。大きく作り込む前に、小さく反映して見せる。
- 既存チラシにある部品（帯、見出しとカードなど）は、作り直すより切り出して使うほうが好まれた。ただし数字や時刻は画像にせずテキストにする。
