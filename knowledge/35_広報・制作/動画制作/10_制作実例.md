## 1. RED 中3 冬期講習 説明動画

| 項目 | 内容 |
|---|---|
| 目的 | RED個別部門の中3生と保護者に、冬期講習の内容・教科と授業数の決め方・申込書の書き方を伝える。三者面談（10月末〜）の前に見てもらう |
| 形式 | スライド形式 16:9（1920×1080）。AI音声のナレーション。申込書はPowerPointのデータをそのまま画像にして使う |
| 色 | REDの赤 #D13C18（ロゴSVGから取得）＋白、強調に黄を少量 |
| 構成 | 台本10章（`00_使い方.md` 6章の表）。画面は写真6枚（冬の教室／個別指導／カンヅメ合宿／過去問の手元／三者面談／前を向く横顔）、図解（G01〜G29）、申込書の各欄 |

| 秒数の見積もり | 1秒5.5文字で見積もった（音声なし仮動画 約10分） |

未了（README記載）
- 申込書の新版データ待ち。届いたら日程・項目を図解と台本に突き合わせる。
- 県一斉模試の実施日が案内面に無い〔要確認〕。
- 台本に「冬のカンヅメ合宿」のチェック欄の説明がない（図解には入れた）。

学び
- 「冗長」は画面を細かく切り替えて解消する。1画面平均7秒・最長20秒。
- Canvaで秒数を手で合わせるとずれる。PowerPointの自動めくり＋埋め込み音声で書き出すと正確。
- 修正は「画面だけ」と「台本＝音声の取り直し」に分ける。画面だけ直した版（v7）では画面と読み上げの文言が一時的に食い違う → 次の版で台本も直した。
- 削除したい音声の一部は、無音の位置で切り取れる（取り直さずに済む）。
- 申込書の表記揺れ・割引の削除は、元のpptxではなくコピーで直す。

## 2. ネクスタ 中3 冬期講習 説明動画（RED版の派生）

| 項目 | 内容 |
|---|---|
| 目的 | ネクスタ内部生の中3生と保護者に、RED版と同じ内容をネクスタの講習・申込書で伝える |
| 色 | ネクスタの紺 #24318F、淡い青 #EAEDF8、黄 #FFEB38（ロゴのバナーから取得） |
| 原稿 | 担当作成のGoogleドキュメント。受け取ったまま `00_資料/` に控える |
| 申込書 | Word版（10/21）を正とした。同名の PDF・HTML（10/9版）とはパックの回数・金額が違っていた |
| 掲載 | WordPress 固定ページ（パスワード付き予定） |

作り分けの手順
1. 原稿とRED版の音声の文を1行ずつ照合し、「流用」「切り取って流用」「新規」に分ける（全17本中、流用8本（うち切り取り3本）・新規9本）。
2. 流用分はスクリプトでRED版から作る（切り取り位置は無音の中央）。
3. 図解はRED版のスクリプトを写して色とロゴを変え、内容の違う図解だけ作り直す（61枚）。
4. 安藤さんの判断で、RED版に合わせて外す章（2章）、統一する名称（「県一斉模試」。申込書も修正）、原稿どおり残す言い回しを決める → 新規音声は8本・1,447文字に。
5. 音読さんはRED版と同じ設定（声色値も同じ）で、新しいアカウントで生成。

版の推移

| 版 | 日付 | 変えたこと |
|---|---|---|
| v1 | 10/28 | 16本をつないで9分10秒、77画面（平均7.2秒、最長18.6秒）。図解の言い回しがRED短縮版のまま残っていた箇所を原稿どおりに直した |
| v2 | 10/28 | 切り替えが早い箇所を4秒遅らせた／図解の名称を「4教科パックコース」に（音声は原稿どおり）／RED版音声の切り取り位置の誤りで「対象となる方は」が2回 → 正しい無音で切り直し |
| v3 | 10/28 | 担当が台本を修正（3か所）→ 該当3本を取り直し、時間割の画面を段階表示に（79画面） |
| v4 | 10/29 | 三者面談の開始「10月末から」→「11月から」で1本取り直し、写真の小文字と図解も変更。話の切り替え2か所に1秒の無音 |

Web掲載：v4 を変換（40.8MB、9分15秒）。9分を超えたため前後に分けて変換してつないだ（RED版の手順では最後の約12秒が消えた）。固定ページ下書きに差し込み、プレビューで長さ・最後の画面を確認。

学び
- 派生版は「原稿と元の音声の1行ずつの照合」から始め、取り直す本数を最小にする。
- 流用音声の切り取りは、無音の中央で切ってもつなぎ目の確認が要る（「対象となる方は」の重複）。
- 申込書が複数形式（Word・PDF・HTML）で食い違うときは、更新日の新しい方を正として明記し、確認する。
- 9分を超える動画は Web 用の変換で末尾が切れることがある。変換後に最後の画面まで再生して確かめる。

## 4. おはよう勉強会 イメージ映像（試作）

| 項目 | 内容 |
|---|---|
| 目的 | おはよう勉強会の雰囲気を伝えるイメージ映像（YouTube、校舎サイネージなど） |
| 仕様 | 横16:9・フルHD・約30秒・5カット。ナレーションなし |
| メッセージ案 | 朝の1時間の積み重ねが、自分で学ぶ力になる |
| トーン | 明るい朝に爽やかに学習。画面越しの仲間と楽しく学習に臨む |
| CTA | 「参加したい人は校舎スタッフへ」（申込URLが未確定のため） |

構成（制作提案 v3）

| 秒 | カット | 映像 | 音 | テロップ（後乗せ） |
|---|---|---|---|---|
| 0〜7 | ⓪ おはよう！ | 朝のリビング。母が朝食の準備 → 廊下から足音 → 主人公が自分から笑顔で「おはよう！」→ 母も笑顔 | 足音・「おはよう！」（このカットだけ音声生成オン、BGMなし指定） | おはよう！ |
| 7〜13 | ② みんなとスタート | PCを開く → 肩越しに画面の仲間 → 片手で手を振る | BGM | 朝6:00〜7:00｜Zoomで、自宅から参加 |
| 13〜20 | ③ 集中 | ノートに書く手元と、画面の中で勉強する仲間 | BGM | 画面の向こうに、いっしょに頑張る仲間。 |
| 20〜25 | ④ できた！ | 解けてうなずき、笑顔 | BGM | 朝の1時間を、自分の習慣に。 |
| 25〜30 | ⑤ エンド | 伸びをして窓の外を見る。右半分は文字用に空ける | BGM | おはよう勉強会／ロゴ／参加したい人は校舎スタッフへ |

- 冒頭は「起こされるのではなく自分で起きてきた」を足音と笑顔で見せる（理念「自立型人間」・教育方針「学習習慣」）。起床カット・カーテンのカットは外した。
- サイネージ版（音なし）は、母が足音に気づいて顔を上げる動き＋テロップで伝える。
- BGMは著作権フリー音源を Premiere で付ける。

試作の結果

| 試作 | ツール | 結果 | 判断 |
|---|---|---|---|
| 参照画像 R1〜R3 | Higgsfield（無料プランで使える画像モデル） | 主人公・部屋は採用可。オンライン画面は制服風のベスト・ネクタイ、全員同じ背景でNG（作り直しは2回とも失敗） | 上位の画像モデルは有料プランが必要だった |
| 試作1（7秒・720p相当） | Dreamina | 主人公・部屋は良い。PCの画面がカメラ側を向く、PCが急に動く、手を振り続けて大げさ、画面の仲間の顔が崩れる・大人に見える・意味のない文字。ウォーターマークあり → 公開に使えない | 画面の中身はAIに一緒に描かせず、主人公カット（画面は白く光るだけ）と仲間の映像を別に作って編集ではめ込む |
| 試作2（20秒・720p） | Higgsfield | 0〜6秒は良い（PCを開く→肩越しに画面→片手で手を振る）。画面の仲間は静止画のまま動かず、ネクタイの生徒が残る。部屋が暗め。7〜20秒は顔のアップが続くだけ | 0〜6秒をカット②に、7〜9秒の笑顔をカット④に流用候補。部屋は Premiere で補正 |

- 動画生成の本番（1080p・30秒）は有料プランかクレジット購入が必要で、ユーザー判断で無料枠のサービスで試した。seadance.io は規約で「ByteDance非公式」と明記され、運営会社・ウォーターマーク・商用利用の記載がない → **本番公開前に商用利用・ウォーターマーク・生成物の扱いを確認する**〔要確認〕。

学び
- 実在人物の顔は参照しない。登場人物（主人公・母・仲間）は架空の人物を画像生成する。
- 画面の中（Zoomのタイル）をAIに描かせると顔・文字が崩れる。別素材ではめ込む。
- 文字・数字・ロゴ、時刻の分かる時計は描かせない。「毎朝」「毎日」など facts に無い頻度は使わない。
- 動きの指示は「片手で1回手を振る」「自然な笑顔」など控えめに書く（大げさになりやすい）。
- 試作は短い尺・低解像度で、問題の出やすいカット（画面の仲間）から試す。
