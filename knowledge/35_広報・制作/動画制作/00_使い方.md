## 2. 動画の種類

| 種類 | 例 | 作り方 | 尺の目安 | 音 |
|---|---|---|---|---|
| 説明動画（スライド型） | 冬期講習の内容と申込書の書き方、入会手続き | 写真・図解・申込書の画面を並べ、AI音声で読み上げ。PowerPointで書き出し | 8〜9分（73〜79画面） | AI音声のナレーション |
| イメージ映像 | おはよう勉強会の雰囲気 | 動画生成AIでカットを作り、編集ソフトでつなぐ | 約30秒（5カット） | ナレーションなし。BGM＋必要なカットだけ効果音 |

## 3. 説明動画の工程

| 工程 | やること | 出力（例） |
|---|---|---|
| 1 台本と資料の照合 | 台本と申込書・案内を読み、食い違い（台本にあって申込書にない／申込書にあって台本にない）を表にして報告。構成の提案は並べ替え・重複の統合まで。直すのは明らかな誤り（文のつながり、「そして」の重複、読点の抜け）だけ | 照合表 |
| 2 画面の設計 | 台本の章ごとに画面（写真／図解／申込書）を割り当てる | `02_制作/スライド構成_v1.md` |
| 3 素材 | 写真（ChatGPT）、図解（HTML→PNG）、申込書の画像（PowerPoint→PDF→PNG） | `イメージ画像/`、`図解/`、`申込書画像/` |
| 4 音声 | 読み上げ用の台本を作り、音読さんで章ごとに生成 | `01_原稿/…_音声台本_vN.json`、`02_制作/音声/音声_00〜.mp3` |
| 5 時刻の割り出し | 音声をつなぎ、無音の位置から台本の行ごとの開始時刻を出す（`align_audio.py`） | `音声_全体.m4a`、`行ごとの時刻.json` |
| 6 組み立て・書き出し | `build_vN.py` で画面の並びと開始時刻を書き、pptx（自動めくり秒数・ノート・1枚目に音声埋め込み）を作る → PowerPointの「ムービーとして保存」でMP4 | `03_納品/YYYYMMDD_案件名_vN.mp4`、`画面別_開始と長さ_vN.csv` |
| 7 修正 | 指摘を「画面の修正」と「台本の修正（＝音声の取り直し）」に分けて対応 | vN+1 |

各工程の終わりに、何をしたか・何が未確認かを短く報告する。

## 4. 画面設計の決まり

| 項目 | 決まり |
|---|---|
| 画面 | 16:9、1920×1080 |
| 色 | 部門のコーポレートカラー。RED＝赤 #D13C18＋白（強調に黄を少量）。ネクスタ＝紺 #24318F＋淡い青 #EAEDF8＋黄 #FFEB38。色はロゴから取る |
| 画面の種類 | 写真＝生成画像の左3分の1に白い板と見出し／図解＝HTMLから書き出し／申込書＝申込書画像の上に説明 |
| 1画面の長さ | 平均7秒前後、長くても20秒以内 |
| 長い箇所の分け方 | 段階表示（読み上げに合わせて項目が1つずつ出る画面を、ページを分けて作る。アニメーション機能は使わない）／写真のあとに要点の図解を1枚足す |
| 申込書の画面 | 左に申込書の全体（元データのまま）＋赤枠、右に説明。横長で入らない欄は右側を文字で組み直す |
| 写真の見出し | 1行に入る大きさ。小さくしない（「文字が小さくなった」と指摘あり）。小さくなるなら白い板を広げる。強調行は赤字 |
| 図解 | ▽まわりの余白は詰める。料金は図解に載せず申込書の画面で見せる |
| 記入例 | 時間割の記入例は5教科すべて載せる |

「冗長」と言われたときの答えは、全体を削るより画面を細かく切り替えること（30画面→73画面）。

## 5. 素材の作り方

写真（ChatGPT）
- 共通の指定を毎回先頭に付け、同じ会話で続けて生成する。
```
16:9の横長。実写の写真風。日本の学習塾の教室。明るく清潔で、やわらかい自然光。
登場するのは日本の中学3年生（制服）。落ち着いて前向きな表情。
画像の中に文字・数字・ロゴは一切入れない。
あとで文字を重ねるので、画面の左側3分の1は物が少ない余白にする。
イラスト、線画、図面風にはしない。
```
- 場面ごとに1行足す（冬の教室、個別指導、カンヅメ合宿、過去問の手元、三者面談、前を向く横顔）。講師はスーツでなく落ち着いた服装と指定した例あり。
- 出力は1672×941px。

図解（HTML→PNG）
- `図解_html/build.py`（1枚もの）と `build_steps.py`（段階表示）。Chromeの headless で PNG に書き出す。
- `data-s="2"` を付けた要素はステップ2以降の画像にだけ出る。
- 文言は SLIDES を直して実行し直す。

申込書の画像
- PowerPoint本体で PDF にしてから `sips` で PNG にする。Quick Look（qlmanage）で画像にすると崩れる。
- PowerPoint の書き出し先は `~/Library/Group Containers/UBF8T346G9.Office/` の下（他はアクセス許可で止まる）。
- 表記の揺れ（全角・半角、「中３」「中3」）は、**元の申込書を触らず、コピーを直して**画像を作り直す。
- Word の申込書はスクリプトから PDF にできなかった（「save as」を受け付けない）→ 本人に「PDFとして保存」を頼む。

## 6. 台本と読み上げ文の型

台本の章立て（RED版で確定した10章）

| 章 | 内容 |
|---|---|
| 冒頭 | あいさつ、この動画で伝える3点（何をするか／教科・授業数の決め方／申込書の書き方）、保護者と一緒に見てほしい |
| 1 | この時期がなぜ大切か |
| 2 | 講習の基本（日程、パックのすすめ、回数コースは相談） |
| 3 | 合宿など特別企画 |
| 4 | 模試の案内（原則当日受験、受験料の扱い） |
| 5 | 教科を決める5つの視点＋例＋「大切なのは」 |
| 6 | 三者面談（いつから、確認すること、一緒に決める） |
| 7 | 申込書の書き方（コース選択、時間割、×の付け方、最終調整は教室長） |
| 8 | 教材・模試のチェック欄、記名、提出期限 |
| 9 | 講習で目指すこと |
| 10 | 最後のメッセージ（短く）と締め |

読み上げ文の作り方
- 見出し【 】は外す。箇条書きの「・」は外し、1項目ごとに「。」で区切る。箇条書きの間に短い間を入れる。
- 読み間違えやすい語は、読み上げ用の文だけ置き換える：中3生→ちゅうさんせい、智翔館→ちしょうかん、「×」→ばつ、1～2か月→1か月から2か月、何コマ→なんコマ、通塾型→つうじゅく型、一人ひとり→ひとりひとり、理社→りしゃ。
- 1本の区切りは章ごと。無料は1回400文字（改行込み）までなので、超える章は段落で分けて 03a・03b と番号を付ける。
- 台本の修正版が届いたら、これまでに決めたこと（追加・削除）が戻っていないかと担当の修正依頼を照らし合わせる。古い版から直したと思われる戻りは反映せず報告する。
- 台本にない文言・数字を画面に足したら「私が書いた文言」として報告する。日程・料金は申込書の記載だけ使う。

## 7. ツールと設定

| 用途 | ツール | 設定・注意 |
|---|---|---|
| 写真 | ChatGPT（画像生成） | 会話名を README に控える |
| 音声 | 音読さん Beta（ondoku3.com「AI音声合成【Beta】」、Gemini TTS） | 全本で同じ設定（実例：Ellis／高品質／速度1.2x／ピッチやや高い／落ち着いた）。**声色値を固定**（指定なしだと1本ごとに声が変わる）。ログインしてから生成（未ログインは合計約1,000文字で止まり、後からダウンロードできない。ログイン中は5,000文字）。読み込み直すと「高品質」が外れる・ログインしても設定が戻ることがある → 生成前に毎回確認 |
| 音声の保存 | — | アプリ内ブラウザの「ダウンロード」は効かない。生成直後のプレイヤーの音声URL（24時間有効）から取るか、本人に履歴ページの「MP3」を押してもらう。履歴番号を CSV に控えてファイル名を付ける |
| 時刻合わせ | `align_audio.py` | 文の切れ目ならほぼ1秒以内。「・」の列挙は1〜2秒ずれることがある。話の切り替えに1秒の無音（GAP）を入れた例あり |
| 組み立て | `build_vN.py`＋`build_pptx.py`（python-pptx） | 時刻は秒か `T(行番号)` で指定（音声を差し替えても追従する）。部品は photo／graphic／form |
| 書き出し | PowerPoint「ムービーとして保存」（AppleScript の save as movie） | 書き出し後に長さと音声トラックを `afinfo` で確認。見た目は PDF にして一覧で確認 |
| Canva | 使わない（原則） | 連携ツールからページの秒数を設定できず、70ページ前後を手で合わせることになる。pptx の取り込みは10MB以下、太字が外れ赤枠が消える。Canvaで仕上げるなら画面を1枚絵の画像にして差し替える |
| イメージ映像 | Higgsfield（Seedance 2.5 ほか）、Dreamina、seadance.io | 10_制作実例の4を参照。無料枠・ウォーターマーク・商用利用は公開前に必ず確認 |
| 編集 | Premiere／After Effects | 明るさ補正、画面のはめ込み、BGM・テロップ |

## 8. Web再生ページ（YouTubeを使わない場合）

- 目的：YouTubeの広告・おすすめ動画を出さないため、智翔館の WordPress に再生専用の固定ページを作る。
- 動画は 1280×720・H.264 600kbps・AACモノラル96kbps に再変換（WordPressのアップロード上限50MB。約8〜9分で33〜41MB）。
- 変換は macOS の JXA（AVAssetWriter）スクリプト。1回で映像を16384枚（30fpsで約9分）までしか読めないため、9分を超える動画は無音の位置で前後に分けて変換し、再変換せずにつなぐ。
- サムネイルは動画の2秒地点のタイトル画面。
- ページはカスタムHTMLブロック1つ（VIDEO_URL／POSTER_URL を差し替え）。`controlslist="nodownload"`・右クリック無効（完全な保存防止ではない）。
- メディアへのアップロードは本人が手で行う（ブラウザ操作からローカルファイルを送れない）。アップロード後、バイト数が手元と一致するか、プレビューで長さ・最後の画面・サムネイルを確認。
- 公開範囲（パスワード付き・検索除外・メニュー非掲載）と保護者への案内方法を決めてから公開する。ネクスタ版はパスワード付きの方針〔要確認：RED版の公開範囲の決定〕。
- 修正が入ったら、修正版から同じ設定で変換し直してからアップロードする（古い変換版はアップロードしない）。

## 9. 守ること

- ログイン（音読さん・ChatGPT・Canva・WordPress）は本人。認証情報をAIに渡さない・書かない。
- ダウンロードは了承を得てから。保存元・ファイル名・大きさを伝える。
- 元の資料（申込書の pptx・docx、受け取った台本）は直接直さない。`00_資料/` は受け取ったまま残す。
- 版は v1, v2… で残し、動画は `03_納品/YYYYMMDD_案件名_vN.mp4`。差し替えた音声は `_旧` を付けて残す。
- **AIは音声を聞けない。** 読み間違い、音声のつなぎ目、画面と声の合い具合は必ず本人に見て・聞いてもらう。
- 切り替えの指摘は「何分何秒を何分何秒に」でもらい、該当の開始時刻を直す。
- 音声の不具合は該当の1本だけ同じ設定で作り直し、`align_audio.py` をやり直す。
- 生成映像に実在の人物（生徒・保護者・職員）の顔を参照しない。登場人物は架空。実際のZoom画面も使わない。
- 文字・数字・ロゴは動画生成AIに描かせず、編集で後から乗せる。
- facts に無い表現（「毎朝」「毎日」など実施頻度、時刻の分かる時計）は使わない。
