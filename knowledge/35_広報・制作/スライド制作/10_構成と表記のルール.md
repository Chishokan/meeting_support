# スライドの構成と表記のルール

2026年9〜10月に作ったスライドの共通点から、社内の型としてまとめた。

## 1. 構成の型

### 1-1. 社内会議（数値報告・部門別発表）

| 順 | スライド | 中身 |
|---|---|---|
| 1 | 表紙 | タイトル、会議名と日付、副題1行。表紙に結論の数字を大きく1つ（例「9月末 在籍 ◯名／昨年◯名」「昨年同月比 ◯%」「前年差 +◯名」）と集計範囲の注記 |
| 2 | 全体像 | 部門ごとの表（課題テーマ／本日の発表／今月のゴール）。「本日はこの表の右端を共有することが目的」と明記 |
| 3 | スケジュール | 全部門の期日を1本の線（期日が近い順の表：期日・部門・やること） |
| 4〜 | 部門ごと1枚目＝数値 | 結論の数字＋課題テーマ＋校舎別の表＋学年別の表＋「読みどころ」3〜5行＋集計の注記 |
| 部門ごと2枚目以降＝施策 | 1施策1枚 | 「年内の目標」「課題テーマ」「ねらい（1行）」「今月やり切ること（主語・期日・場所つき）」「おさえておく数値」 |

- 部門ページは同じレイアウトに固定し、上部に「年内の目標」と「課題テーマ」を毎回繰り返す。
- 記入テンプレート型：事前の作戦会議で決めたことを各部門が埋める空欄（「・」6行＋「全体会議までに記入してください」）を用意して配る。

### 1-2. 研修・活動報告

1. 表紙（題名、副題「◯◯・◯◯・◯◯」で報告の中身を予告）
2. 「◯◯とは」の説明（知らない職員向けに、いつ・どこで・参加条件・やること・ねらい・対象を表で）
3. 報告の目次（番号付き4項目）
4. 番号ごとに1枚：結論の見出し＋根拠の数字・グラフ＋限界の注記
5. 今後の目標（数値目標の段階：現在→冬期→新年度）と打ち手

### 1-3. 保護者・生徒向けセミナー

夢・志セミナーの見直し（2026-10-26）で決めた型。

1. 表紙（日付・対象を入れる）
2. 承認（ここまでの頑張りを認める。育てた力をアイコン4つで）
3. 本日のテーマ（大きく1行）
4. 問いかけ（挙手・隣と話す時間）
5. 章の扉→中身（タイトルだけのスライドは作らない。見出しを中身のスライドに載せる）
6. データの章（表は大きな数字だけを見せ、細かい数字は小さく添える。何を読み取るかを見出しにする）
7. 定義→図→ワークの順
8. 講座・サービスの案内（1講座1枚：対象・期間・内容・料金・申込方法）
9. 「今日決めること」（面談の日にち、申込締切と次の一歩）

### 1-4. 外部発表（行政・企業向け）

外国人材受入協議会の発表（2026-10-27）の流れ：ビジョン→現状の数字→現場の課題→他地域の事例→実現したいこと→すでに始めていること→提案→協力のお願い→結び（3つのメッセージ）。章番号（01〜06）を各スライドの小見出しに付ける。

## 2. 見出しと文の書き方

| ルール | 例 |
|---|---|
| 見出しは「言いたいこと」を1文で（テーマ名で終わらせない） | ×「数字が示す佐世保の今」だけ → ○「働き続けたい人は多い。けれど、壁がある」 |
| 結論の数字を見出しに入れる | 「累計 約8,900時間の朝学習」「保護者の86%が『朝起きるきっかけ』」 |
| 前年比は「今年／昨年・◯%」の順で書く | 「◯名／昨年◯名・◯%」 |
| 増減は記号で | 「+◯」「−◯」「±0」。前年割れの学年は赤 |
| 実行事項は主語・期日・場所を入れる | 「10/26の合否判明後、◯◯先生が対象◯名へ電話し、次の級を提示する」 |
| 「ねらい」は1行 | 「高校継続の連携体制を10/22につくる」 |
| 1スライド1メッセージ | 詰め込みすぎは分割（就職の流れ→フロー図と、企業が見る点の2枚に） |
| 同じメッセージの2枚はまとめる | 「山の比喩」と「合格はゴールではない」を1枚に |
| 文章が長いものはカードに | 3枚のカード（アイコン・見出し・1行説明） |
| 日付は「10/15」形式（表・本文）、表紙は「2026年10月15日」 | — |

## 3. 数値の見せ方

| ルール | 内容 |
|---|---|
| 出典と時点 | 各スライドの注記かノートに「出典・時点・集計範囲」を書く（例「各校舎・教室の月次報告の入力値（9月末時点）」） |
| 定義 | 比率の定義を書く（「昨年比＝今年÷昨年同月」「達成率＝実施部数÷ボトム」「1人1日＝1」） |
| 含む・含まない | 合計に何を含むかを明記（「英検マンツーマンを含む／含まない」）。含めない場合の値も添える |
| 食い違い | 資料間で数字が合わないときは隠さず「未確定」と書き、理由を添える（「出典の違いによるもので、実際の減少ではありません」） |
| 因果の限界 | 効果を言うときは限界も書く（「※参加者は参加前から偏差値が約5高く、差のすべてが効果ではない」） |
| 読みどころ | 表の横に「読みどころ」3〜5行。数字の羅列で終わらせない |
| グラフ | 推移は折れ線・縦棒、比較は横棒。表は大きな数字だけを強調 |
| 個人 | 生徒名は出さない。声は学年まで（「（中2）」）。先輩事例はイニシャル |
| 外部データ | 官公庁・アンケート報告書は名称と年度を出典に（「佐世保市外国人市民アンケート報告書（令和8年10月）」） |

## 4. ノート（発表者メモ）

- 各スライドのノートに、1行目「このスライドで言うこと」、続けて【解決したい原因】【ねらいの背景】【他部門への依頼】【保留】【未確定】などの見出しで補足を書く（部門別発表の型）。
- 数字の出どころ（ファイル名・シート名・集計条件）はノートに残す。
- 決定の出どころ（「2026/10/13 中等部会議で決定」）を書く。

## 5. フッター・表記

- フッターに「会議名（日付）　資料名」（例「2026年10月15日 全体会議　10月にやり切ること」）とページ番号。
- 社内数値を含む資料は「社外秘｜2026年10月29日時点」をフッターに。
- 【未記入】【確認中】は配布前にすべて消す（「未記入の箇所」一覧で管理）。

## 6. 配色・書体・画像

| 項目 | ルール |
|---|---|
| 土台 | 白と濃紺。ブルーをアクセント、黄色はごく少量（「ここだけは絶対に見てほしい一語」） |
| 色の目安（夢・志セミナー） | 濃紺 #152B6B（見出し・大きな数字・矢印）、ブルー #1E50C8（小見出しラベル・アイコン・強調数字）、水色 #EBF2FC（カード背景）、淡い青 #D6E4F7（表紙・章扉の斜めの図形）、黄 #F5C400（ロゴの色・一語だけ）、本文 #333333。近似値〔要確認：正式コード〕 |
| 使わない色 | オレンジ、ダークグレーの面（夢・志セミナーの叩き台から変更） |
| 前年割れ | 赤で示す |
| ロゴ | 各スライドの右上に智翔館ロゴ（公式データ） |
| 背景 | 白背景の右端に淡い斜めの図形（表紙・章扉） |
| 画像 | 青一色のフラットなイラストにそろえる（写真風の生成はAIらしい不自然さが出やすい）。画像の中に文字・数字・ロゴを入れない。実在の人物は生成しない |
| 画像の比率 | 章扉・表紙 16:9（主題は右半分、左は余白）、本文用 4:3（角丸の枠に収まる構図）、全面 16:9（上下15%は単純な背景） |

## 7. 仕上げのチェックリスト

- [ ] 見出しを並べて読むと、話の筋が通る
- [ ] 1スライド1メッセージ。タイトルだけのスライドがない
- [ ] 数字に出典・時点・集計範囲。定義が必要な比率は定義つき
- [ ] 資料間の食い違いは「未確定」と明記
- [ ] 実行事項に主語・期日。最後に聞き手の次の一歩
- [ ] 社内の言葉（夢・志、自立型人間育成など）の表記が正式どおり
- [ ] 生徒・保護者の個人名なし。声は学年まで
- [ ] 社内数値を含むなら「社外秘」フッター。外部向けに社内数値が混ざっていない
- [ ] 【未記入】【確認中】がない
- [ ] 配色が白・濃紺・ブルー中心、黄色は一語だけ
- [ ] 文字が小さすぎない（細かい表は分割か大きな数字だけに）
