# 見やすいスライドの型（ブルー型）

職員が「この形が良い」と選んだスライド（Canva のひな形「時間管理術セミナー」）の見やすさを言葉にした。
この型で作り直した実例は `20_制作実例.md` の「8. 夢・志セミナー（ブルー版）」。数字は 1440×810pt のスライドの値（ふつうの 720×405pt なら半分）。

## ひとことで

**白い地に青1色。1枚に言いたいことは1つ、要素は3〜4個。上から「ラベル → 主役 → まとめの帯」の順に読める。**
文字で説明せず、形（番号つきカード・2×2・矢印・表）で見せる。

## 1. 色（5色だけ。色に役目を持たせる）

| 色 | コード | 使うところ |
|---|---|---|
| 白 | #FFFFFF | 地（ほとんどの枚） |
| ブルー（差し色） | #005DD6 | 丸いラベル、章ラベルの短い線、下の帯、番号の丸の線、キーワード、結論の一文、額縁（表紙・結び） |
| 濃紺 | #003170 | 見出し、表の見出し行の文字 |
| 本文のグレー | #444444 | 本文・箇条書き・大きな一言の黒い部分 |
| 淡い青 | #F2F7FD | まとめの帯、カードの地、要点の囲み、表の見出し行、ページ全体の地（強調したい枚だけ） |
| 濃いグレー | #737373 | 「具体例」「悩み」など、課題の面（白い文字） |

- 赤・黄・オレンジ・緑は使わない。強調は **ブルーの文字＋「」** だけ（例：「重要ではないこと」に／「時間の使い方」が課題）
- ブルーは「見てほしい所」にだけ使う。見出しは濃紺、本文はグレーで、ブルーと役目を分ける
- 写真を地に敷くときは、上に白か淡い色の板を置いて文字をのせる（写真の上に直接文字を置かない）

## 2. どの枚にもある枠

- **左上の章ラベル**：ブルーの短い線（26×14pt）＋グレーの小さな文字（30pt）。「本日のゴール」「原因①」「解決策｜今日からできる3つの工夫」のように、今どの話かを示す
- **下の帯**：ページ下端にブルーの帯（高さ26pt）。全部の枚で同じ位置
- **右上のロゴ**。暗い地の枚（問いかけ）は、ロゴが沈むので置かない
- 表紙と結びだけは枠が違う（ブルーの額縁）。問いかけの枚は暗い地にする（流れの中の「間」になる）

## 3. 1枚の組み立て（上から3段）

1. **何の話か**：丸いラベル（ブルーの地に白い文字。例「本日のゴール」「智翔館のTOP10文化」）か、濃紺の見出し1行
2. **主役**：大きな一言（1〜3行）、図、カード、表のどれか1つ
3. **まとめの帯**：淡い青の帯に、言いたいことを1〜2行。キーワードはブルーで「」付き

読む順が上から下へ1本になる。左右に読ませない。

## 4. 1枚に入れる情報の量

- 言いたいことは **1枚に1つ**
- 並べる要素は **3〜4個まで**（カード3枚、チェック4つ、箇条書き3つ、まとめ4項目）
- 1項目は **1〜2行**。1行は12〜15字ほど。カードの中の文は2行に分け、言葉の途中で折り返さない
- 文は短く切る。「〜する」「〜を決める」で終える。長い説明・話す内容は発表者ノートに入れる
- 細かい注記（申込の条件など）は表の下に小さく（26pt 以上）。本文の中に混ぜない

## 5. 文字の大きさ（1440×810pt）

| 部分 | 大きさ | 太さ |
|---|---|---|
| 章ラベル | 30pt | 標準 |
| 丸いラベル | 32pt | 標準（白） |
| 見出し | 48〜56pt | 太字（濃紺） |
| 大きな一言 | 70〜88pt | 太字 |
| カードの題 | 42〜60pt | 太字（ブルー） |
| 本文・箇条書き | 36〜46pt | 標準 |
| 表 | 28〜32pt | 見出し行と1列目は太字 |
| 注記 | 26pt 以上 | 標準 |
| 大きな数字（偏差値55 など） | 120pt 前後 | 太字（ブルー） |

本文が 30pt 台後半〜40pt 台と大きい。小さな文字で詰め込まない。

## 6. 配置

- **中央ぞろえ・左右対称**が基本（表・注記だけ左ぞろえ）
- 左右の余白は約56〜60pt。カード・帯・表・囲みの左右の端を同じ線にそろえる
- 余白を残す。文字と地の端のあいだは1文字分以上あける
- 箇条書きの行間は、文字の大きさの0.6倍ほど

## 7. 文字より形で見せる（図の型）

| 型 | 使う場面 | 作り方 |
|---|---|---|
| 2×2のチェック | 「今日考えること」「学べること」 | ブルーの ✓ ＋短い語を2列×2行。上に点線の区切りと小見出し |
| 番号つきカード 01/02/03 | 3つの力・3つの手順 | 淡い青のカードを3枚。上に番号の丸（白地・ブルーの線）、題（ブルーの太字2行）、細い線、説明（2行） |
| 課題の面＋下向き矢印＋結論 | 原因・具体例 → だから何 | 濃いグレーの面に「具体例」の白いラベルと箇条書き、下にグレーの矢印、その下にブルーの結論 |
| 2×2の図 | 比べる・分ける | 縦横の軸と4つの箱。大事な箱だけ白地にブルーの線 |
| 大きな数字の枠 | 条件・基準（偏差値55／60） | 白地にブルーの線の枠を2つ並べ、数字を大きく |
| 番号つきまとめ | 本日のまとめ | 丸いラベル＋「1.〜」「2.〜」を4行、下にまとめの帯 |
| 問いかけ | 考えさせる・話し合う | 暗い地（#24344D）に白い問い、明るい板に大きな文字。キーワードはブルー |

## 8. 並び（リズム）

- 同じ組み方を続けない。カードの枚のあとは、大きな一言・表・問いかけをはさむ
- 明るい枚が続いたら、問いかけ（暗い地）か大きな一言だけの枚を入れて「間」を作る
- 見本の並び（12枚）：表紙 → 講師紹介 → 本日のゴール（ラベル＋囲み＋2×2チェック）→ 問いかけ（暗い地）→ よくある悩み（挿絵＋まとめの帯）→ 原因①（課題の面＋矢印）→ 原因②（2×2の図）→ 解決策（番号つきカード3枚）→ 行動（箇条書き＋挿絵＋帯）→ まとめ（番号つき＋帯）→ 質疑応答（大きな一言）→ 結び

## 9. 書体

- **Noto Sans JP だけ**（2026-11-19 職員の指定「フォントは全て Noto Sans JP」）。本文は標準（Medium 500）、見出し・強調は太字（Bold 700）の2つの太さ
- 見本（Canva）は M+ の2つの太さだったが、智翔館では Noto Sans JP にそろえる。智翔館AI の Apps Script は、作ったスライドの文字をすべて Noto Sans JP にする
- Google スライドの API で太さ 700 を付けるときは、太字（bold）もオンにする（オフだと 400 に戻る）。PDF に書き出すと Medium は標準（Regular）で出る

## 10. 挿絵・写真

- 1枚に1つまで。気持ちを表す挿絵（悩む人、跳ぶ人）を文字の横に置き、文字に重ねない
- 挿絵がないときは、図の型（7）で形を作る。飾りのための画像は入れない
- **表紙と、語りかけの枚**（承認・問いかけ・結果の見方・結び）は、背景に学校・教室・風景の写真素材を**薄く**敷く（2026-11-19 職員の希望）。
  人物・文字は入れない。文字のある側ほど薄くし、地の色（白・淡い青・問いかけの紺）に寄せる。画像は NEP に作成依頼する（智翔館AI の `propose_nep_request`）

## 11. 表紙と結び

- **表紙**：ブルーの額縁（上・左・右・下の太い帯）の中に白い板。上に小さな前置き（ブルー）、タイトルの主語をブルーの箱に白抜き＋続きをブルーの大きな文字、下に副題（〜〜）、日付と話す人
- **結び**：表紙と同じ額縁。中央に一言、その下に白い板で問い合わせ先

## ひな形（Drive「15_AIスライドテンプレート」）

この型のひな形「セミナー（ブルー型・生徒・保護者向け）」（drive:1FnxOmqbu_qnB2CPbqW8oRx0l-wG7Hx0mv0KEOwMl-a0）がある。夢・志セミナー（中1・2）ブルー版の14枚をそのまま型にしたもの。
生徒・保護者向けのセミナー・説明会は、このひな形を第一に使う（from で見本の文字を書き換える。合う枚が無いときは layout）。

| 枚 | 型 | 使いどころ |
|---|---|---|
| 1 | 表紙（青い額縁・タイトルの主語を青い箱） | 表紙 |
| 2 | 承認・大きな一言（ラベル→一言→説明→帯） | 承認・語りかけ |
| 3 | テーマ＋2×2チェック | 本日のテーマ・学ぶこと |
| 4 | 問いかけ（暗い地・明るい板） | 挙手・隣と話す |
| 5 | 番号つきカード3枚 | 3つの力・3つの手順 |
| 6 | 課題の面＋下向き矢印＋結論 | 原因・流れ → だから何 |
| 7 | ワーク（書き込み欄の帯） | その場で書く・決める |
| 8 | ラベル＋一言＋囲み（要点3つ） | 考え方・方針 |
| 9 | 淡い地の大きな一言＋呼びかけ | 結果の見方・語りかけ |
| 10 | 大きな数字の枠2つ＋帯 | 条件・基準・特典 |
| 11 | 表（日程・内容・時間）＋注記 | 講座の日程 |
| 12 | 表（区分・料金・申込）＋注記 | 受講料・申込 |
| 13 | お願いの一言（ラベル→一言→帯） | 最後に頼むこと |
| 14 | 結び（額縁・一言・あいさつ・問い合わせ先） | 結び |

## 智翔館AI（layout）で作るときの対応

| 型 | layout |
|---|---|
| ラベル＋大きな一言＋囲み | message（label・title・points） |
| 番号つきカード | columns（3枚） |
| 2×2チェック・番号つきまとめ | bullets か message の points |
| 日程・料金 | table |
| 問いかけ・大きな一言だけ | message |

columns を2枚続けない、同じ組み方を3枚続けない（アプリが断る）。
