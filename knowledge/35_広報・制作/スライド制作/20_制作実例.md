## 1. 2026年9月 全体報告（全体会議）

| 項目 | 内容 |
|---|---|
| 目的 | 9月末の全社の在籍・入会・体験、学年別の動き、門配実績、問い合わせから入塾までの流れを共有する |
| 構成 | ①表紙（全社の在籍・昨年同月比・前年差を大きく）②部門別サマリー表 ③学年別・校種別の比較（前年割れは赤、「動きの大きい学年」増減3つずつ）④生徒推移（4月→7月→8月末→9月末、昨年と並べる）⑤門配実績（地区別・校種別の表、達成率の定義）⑥問い合わせ・体験・入塾（①9月の問い合わせのその後の流れ図 ②9月入塾がいつの問い合わせかの表） |
| 良かった点 | 各スライドの見出しが結論（「4月に前年を下回っていたが、夏期を経て8月末に逆転」）。比率の定義・集計範囲・データ間の不一致の理由を注記に書いた。「問い合わせから入塾まで2〜3か月。冬期の母数は10月の接点の数で決まる」と行動につながる示唆で締めた |
| 型として使える点 | 「読みどころ」欄、「＋は増・−は減」の凡例、未報告件数（実績が低く出ている可能性）の明記 |

## 2. 部門別 発表テーマと決定事項（記入テンプレート）

| 項目 | 内容 |
|---|---|
| 目的 | 全体会議の前に、部門ごとに作戦会議で決めたことを記入してもらう |
| 構成 | ①表紙（全社の状況を1文）②全体の状況と進め方（伸びている学年／細っている学年、①〜③の進め方と期日）③〜⑦部門ごと1枚（課題テーマ、学年別の数字カード、9月の報告から2行、空欄の「作戦と対策」6行） |
| 良かった点 | 部門ごとに数字を先に置き、「何を話すか」を課題テーマで固定した。フッター下に部門ごとの一言の結論 |

## 3. 10月にやり切ること 部門別（全体会議）

| 項目 | 内容 |
|---|---|
| 目的 | 5部門（高等部、RED個別・ネクスタ、小中等部、県中対策コース、英検マンツーマン）が10月に何をやり切るかを発表し共有する |
| 構成 | ①表紙 ②全体像（部門×課題テーマ×本日の発表×10月のゴール）③10月のスケジュール（全部門の期日を1本に）④以降、部門ごとに「9月末の数値」1枚＋施策1〜3枚 |
| 施策ページの型 | 年内の目標／課題テーマ／ねらい（1行）／10月にやり切ること（主語・期日・場所）／おさえておく数値。ノートに【解決したい原因】【ねらいの背景】【他部門への依頼】【保留】 |
| 良かった点 | 各部門4〜5分、合計16ページと時間配分を明記。「10月のゴール」を表の右端1行に集約。部門をまたぐ依頼をページごとに明記。本部からの提案ページは「このページは本部からの提案です」と区別した |
| 注意 | 職員の氏名が施策に入る（担当の明記のため）。社外に出さない |

## 5. 夢・志セミナー（中3・保護者向け）

| 項目 | 内容 |
|---|---|
| 目的 | 中3と保護者に、高校での成績・順位が大学入試・就職を左右することを伝え、夢・志の設計と高校での継続学習（東進・RED）につなげる |
| テーマ | 「高校での成績・順位にこだわる自分になる」 |
| 見直し（叩き台20枚） | 分割3枚（大学入試の種類、就職の流れ、先取り・スタートダッシュ講座）、図解9枚、統合（山の比喩＋「合格はゴールではない」、データ2枚を1つの章に、タイトルだけのスライドは削除）、並べ替え（定義→図→ワーク）、追加（東進とREDの役割分担の図、夢・志の設計シートのワーク、英検の重要性、先輩事例） |
| 直した理由の例 | 写真の合成が粗い→イラスト1枚に。数字が並ぶだけ→「学校によって進学・就職の割合が大きく違う」という見出し＋横棒グラフ。表の文字が細かい→割合だけ大きく。資料間で卒業生数が合わない→確認事項に |
| 配色 | 外国人材協議会の資料に合わせて作り直し（濃紺・ブルー・水色・淡い青、黄は一語だけ）。オレンジとダークグレーはやめた |
| 画像 | 生成13点（シーン12＋アイコンシート1）。すべて青一色のフラットなイラスト、文字なし。東進の講師陣・学習システムは公式素材、ロゴは公式データ、先輩事例は実例待ち（イニシャル表記） |
| 場所 | Googleスライド「2026夢・志セミナー（たたき台v2）」。claude.ai Docs「夢・志セミナー 叩き台スライド1枚ずつの見直し」「夢・志セミナー 生成画像リストと配色」。関連 Docs「夢・志セミナー 担当者向け進行ガイド」「進行案（たたき台）」〔この作業では未読〕 |

## 7. 夢・志セミナー（中1・2 特待生選抜テストのガイダンス）

| 項目 | 内容 |
|---|---|
| 目的 | 特待生選抜テスト（2026-11-22、中1・2）の受験後50分で、挑戦を認め、学習習慣・勉強体力・自学力の大切さを伝え、冬期講習と面談の約束につなげる。保護者はオンライン参加 |
| 材料 | 智翔館AI が作った台本（Google ドキュメント）、要項「中学１・２年生対象 特待生選抜テスト」「2026 中等部中１・２冬期講習会」、理念（COMPANY.md）、ひな形「中3セミナー②」 |
| 構成（14枚） | 表紙→承認（3教科に最後まで挑戦した）→本日のテーマ＋教育理念→問いかけ（将来やってみたいこと）→3つの力（カード）→図（中1・2→中3→高校）→ワーク（毎日の勉強時間を決める）→TOP10文化→結果の見方→特典（偏差値55・60と免除の表）→冬期講習の日程と内容→受講料と申込→今日決めること（番号つき3枚）→結び（指導理念・問い合わせ先） |
| 良かった点 | 見出しを言いたいこと1文にした（「夢・志は、毎日の積み重ねでできている」「一般生は11/30までの申込がいちばんお得」）。台本の「話すこと」は発表者ノートに入れ、スライドは要点だけ。特典は大きな数字（55・60）と表に分け、「冬期講習の受講料は対象外」を添えた |
| 直した点（台本から） | 台本は冬期講習の要項を読まずに書かれていた（〔要確認〕のまま）→ 要項の確定版から日程・時間・受講料・割引・申込を2枚の表にした。結果の返却日は資料に無いので「◯月◯日」で空けた。要項に「と表記する」とある兄弟割の文はそのまま使い、塾生の申込不要の長い文はノートに全文。台本の末尾に、回答の書式の「URL: ※道具の実行結果をご確認ください」が文書の本文として入っていた（アプリ側で、本文にこの行が入らないようにした） |
| 直した点（見た目） | ひな形の差し色はオレンジ（`10_構成と表記のルール.md` の「使わない色」とは違う）→ ひな形に合わせ、オレンジは各枚の一語だけにした。表紙の挿絵（脳）は話題が違うので使わず、6枚目の空を見上げる生徒の写真を表紙と結びに使った。カードの中の文は、言葉の途中で折り返さないよう改行の位置を決めた。カードが高すぎて下が空いた枚は、カードを低くした |
| 制作側で足したもの | 7枚目のワーク（「わたしの勉強時間」の書き込み）、6枚目の一言「育てるなら、中1・2の今から」。どちらもノートに「台本には無い」と書いた |
| 確認してほしいこととして残したもの | 結果の返却日、一般生が特典の条件を満たしたときの扱い、AAR の正式な表記（予察→行動→振り返り／計画→実行→振り返り） |
| 職員の評価（2026-11-19） | 見やすい：3枚目（本日のテーマ）と8枚目（TOP10文化）。小さな色のラベル→中央の大きな一言→淡い地の囲み（理念・要点）の形。8枚目の箇条書きは行間をあと少し開ける。<br>直してほしい：①似た配置を続けない（4〜7枚目にカード・箱が並ぶ枚が続いた）②背景の色がきちんと塗られていない枚がある。<br>→ 作業「スライドを作る」とこのフォルダのルールに反映し、アプリは columns の連続・同じ組み方の3連続を断るようにした。次は別のひな形（Canva）で作り直す |

## 8. 夢・志セミナー（中1・2）ブルー版（見やすいと選ばれた型で作り直し）

| 項目 | 内容 |
|---|---|
| 目的 | 7 と同じ中身を、職員が「見やすい」と選んだ Canva のひな形「時間管理術セミナー」の形で作り直す。見やすさの要素を言葉にして次から使う（`15_見やすいスライドの型.md`） |
| 作り方 | ひな形は pptx で受け取った（Drive の「15_AIスライドテンプレート」にはまだ無い）。7 のスライドをコピーし、Slides API で1枚ずつ組み直した。発表者ノートは 7 のまま |
| 構成（14枚） | 表紙（青い額縁・タイトルの一語を青い箱）→ 承認（丸いラベル＋大きな一言＋帯）→ 本日のテーマ（ラベル＋囲み＋2×2チェック）→ 問いかけ（暗い地）→ 3つの力（番号つきカード）→ 中1・2→中3→高校（課題の面＋下向き矢印＋結論）→ ワーク（書き込み欄の帯）→ TOP10文化（ラベル＋一言＋囲み）→ 結果の見方（淡い地の大きな一言）→ 特典（偏差値55・60の大きな数字の枠＋帯）→ 冬期講習の日程（表）→ 受講料と申込（表、超早割の行だけ淡い青）→ 今日決めること（番号つきカード）→ 結び（額縁＋問い合わせの板） |
| 職員の指定 | 書体はすべて Noto Sans JP（2026-11-19）。→ 本文 Medium 500・見出し Bold 700 にし、Apps Script も作ったスライドの文字をすべて Noto Sans JP にそろえるようにした |
