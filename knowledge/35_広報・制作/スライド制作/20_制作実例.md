## 1. 2026年9月 全体報告（全体会議）

| 項目 | 内容 |
|---|---|
| 目的 | 9月末の全社の在籍・入会・体験、学年別の動き、門配実績、問い合わせから入塾までの流れを共有する |
| 構成 | ①表紙（全社の在籍・昨年同月比・前年差を大きく）②部門別サマリー表 ③学年別・校種別の比較（前年割れは赤、「動きの大きい学年」増減3つずつ）④生徒推移（4月→7月→8月末→9月末、昨年と並べる）⑤門配実績（地区別・校種別の表、達成率の定義）⑥問い合わせ・体験・入塾（①9月の問い合わせのその後の流れ図 ②9月入塾がいつの問い合わせかの表） |
| 良かった点 | 各スライドの見出しが結論（「4月に前年を下回っていたが、夏期を経て8月末に逆転」）。比率の定義・集計範囲・データ間の不一致の理由を注記に書いた。「問い合わせから入塾まで2〜3か月。冬期の母数は10月の接点の数で決まる」と行動につながる示唆で締めた |
| 型として使える点 | 「読みどころ」欄、「＋は増・−は減」の凡例、未報告件数（実績が低く出ている可能性）の明記 |

## 2. 部門別 発表テーマと決定事項（記入テンプレート）

| 項目 | 内容 |
|---|---|
| 目的 | 全体会議の前に、部門ごとに作戦会議で決めたことを記入してもらう |
| 構成 | ①表紙（全社の状況を1文）②全体の状況と進め方（伸びている学年／細っている学年、①〜③の進め方と期日）③〜⑦部門ごと1枚（課題テーマ、学年別の数字カード、9月の報告から2行、空欄の「作戦と対策」6行） |
| 良かった点 | 部門ごとに数字を先に置き、「何を話すか」を課題テーマで固定した。フッター下に部門ごとの一言の結論 |

## 3. 10月にやり切ること 部門別（全体会議）

| 項目 | 内容 |
|---|---|
| 目的 | 5部門（高等部、RED個別・ネクスタ、小中等部、県中対策コース、英検マンツーマン）が10月に何をやり切るかを発表し共有する |
| 構成 | ①表紙 ②全体像（部門×課題テーマ×本日の発表×10月のゴール）③10月のスケジュール（全部門の期日を1本に）④以降、部門ごとに「9月末の数値」1枚＋施策1〜3枚 |
| 施策ページの型 | 年内の目標／課題テーマ／ねらい（1行）／10月にやり切ること（主語・期日・場所）／おさえておく数値。ノートに【解決したい原因】【ねらいの背景】【他部門への依頼】【保留】 |
| 良かった点 | 各部門4〜5分、合計16ページと時間配分を明記。「10月のゴール」を表の右端1行に集約。部門をまたぐ依頼をページごとに明記。本部からの提案ページは「このページは本部からの提案です」と区別した |
| 注意 | 職員の氏名が施策に入る（担当の明記のため）。社外に出さない |

## 5. 夢・志セミナー（中3・保護者向け）

| 項目 | 内容 |
|---|---|
| 目的 | 中3と保護者に、高校での成績・順位が大学入試・就職を左右することを伝え、夢・志の設計と高校での継続学習（東進・RED）につなげる |
| テーマ | 「高校での成績・順位にこだわる自分になる」 |
| 見直し（叩き台20枚） | 分割3枚（大学入試の種類、就職の流れ、先取り・スタートダッシュ講座）、図解9枚、統合（山の比喩＋「合格はゴールではない」、データ2枚を1つの章に、タイトルだけのスライドは削除）、並べ替え（定義→図→ワーク）、追加（東進とREDの役割分担の図、夢・志の設計シートのワーク、英検の重要性、先輩事例） |
| 直した理由の例 | 写真の合成が粗い→イラスト1枚に。数字が並ぶだけ→「学校によって進学・就職の割合が大きく違う」という見出し＋横棒グラフ。表の文字が細かい→割合だけ大きく。資料間で卒業生数が合わない→確認事項に |
| 配色 | 外国人材協議会の資料に合わせて作り直し（濃紺・ブルー・水色・淡い青、黄は一語だけ）。オレンジとダークグレーはやめた |
| 画像 | 生成13点（シーン12＋アイコンシート1）。すべて青一色のフラットなイラスト、文字なし。東進の講師陣・学習システムは公式素材、ロゴは公式データ、先輩事例は実例待ち（イニシャル表記） |
| 場所 | Googleスライド「2026夢・志セミナー（たたき台v2）」。claude.ai Docs「夢・志セミナー 叩き台スライド1枚ずつの見直し」「夢・志セミナー 生成画像リストと配色」。関連 Docs「夢・志セミナー 担当者向け進行ガイド」「進行案（たたき台）」〔この作業では未読〕 |
