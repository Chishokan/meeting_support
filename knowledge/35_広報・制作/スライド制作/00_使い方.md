# スライド制作 ナレッジの使い方

## ファイル構成

| ファイル | 開く場面 |
|---|---|
| `10_構成と表記のルール.md` | スライドを作る・直す。構成の型、見出しの書き方、数値の見せ方、配色、ノート、出典 |
| `20_制作実例.md` | 似た場面（全体会議・研修発表・保護者セミナー・外部協議会）の前例を見る |
| `../デザインシステム.md` | 色・書体を確かめる |
| 理念・方針のナレッジ（`10_理念・方針/方針チェック観点_2026.md`・`経営指針書_2026.md`） | 方針・理念の言葉を入れるとき、言い回しを確かめるとき |

## スライドの種類

| 種類 | 例 | 聞き手 | 主な目的 |
|---|---|---|---|
| 社内会議（数値報告） | 月次の全体報告、部門別発表 | 全職員 | 数値の状況を共有し、今月の実行事項を決める |
| 社内研修・発表 | 全体研修のチャレンジ発表、活動報告 | 全職員 | 取り組みと今後の目標を伝える |
| 保護者・生徒向けセミナー | 夢・志セミナー、LAST LAP BELL セミナー | 生徒・保護者 | 進路の考え方を伝え、次の行動（面談・講座申込）につなげる |
| 外部発表 | 外国人材受入協議会 | 行政・企業 | 智翔館の考えと提案を伝え、協力を得る |

## AIへの頼み方

1. 目的・聞き手・発表時間・枚数の上限を伝える。
2. 使う資料（数値の出典、要項、議事録）を渡す。数値はAIに作らせない。
3. 先に「スライドの流れと要点」（1枚ごとに見出し＝言いたいこと1文、要点、伝えたいこと、出典）を表で作らせ、合意してからスライドにする。
4. できたスライドを `10_構成と表記のルール.md` のチェックリストでレビューさせる。

## レビューで見ること（社内方針が入っているか）

| 観点 | 確かめること |
|---|---|
| 方針・理念 | 「夢・志」「自立型人間育成」など社内の言葉と考え方に沿っているか。理念の文言は正式な表記をそのまま使う〔要確認：理念ナレッジの参照先〕 |
| 行動につながるか | 最後に「誰が・いつまでに・何をするか」、聞き手の次の一歩（面談日を決める、申込）があるか |
| 数値の確かさ | 出典・時点・集計範囲が書かれているか。食い違いは「未確定」と明記しているか |
| 個人情報 | 生徒・保護者の名前、個人が特定できる成績を載せていないか（声はイニシャル・学年まで） |
| 社外秘の扱い | 社内数値を含むスライドに「社外秘」とフッターがあるか。外部発表に社内数値が混ざっていないか |
| 未記入 | 【未記入】【確認中】が残っていないか |

## 守ること

- 給与・人事評価・業績数値（売上・利益）を、目的外のスライドに入れない。
- 実在の人物（講師・生徒・社長）の画像は生成しない。公式素材か本人の写真を使う。
- 外部の公式素材（東進の講師陣・学習システムなど）はそのまま使い、加工しない。
