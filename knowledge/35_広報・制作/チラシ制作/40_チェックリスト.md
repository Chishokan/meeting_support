# チラシ・ポスター 生成前・生成後チェックリスト

## 1. 生成前（プロンプトを貼る前）

### 原稿

- [ ] 使った要項は status が「確定」のものか
- [ ] 講座名・イベント名が要項どおりか
- [ ] 対象学年、塾生／一般生の区別がチラシの対象と合っているか
- [ ] 開催日と曜日が合っているか（カレンダーで確認）
- [ ] 時間、会場、校舎名が正しいか
- [ ] 料金がカンマ付きで、税込／税抜が要項どおりか
- [ ] 電話番号（0120-41-1976）・住所が正しいか
- [ ] 要項どうしで食い違う情報（受付時間など）を載せていないか
- [ ] 制作側で作ったコピーを一覧にし、担当者に確認してもらったか

### プロンプト

- [ ] `{{ }}` が残っていないか
- [ ] 情報の優先順位（何を一番大きく見せるか）が決まっているか
- [ ] メインコピーが長すぎないか
- [ ] 原稿にない情報を足させる書き方になっていないか
- [ ] ロゴ用の余白と QR 用の白枠を指定しているか（どちらも AI に作らせない）
- [ ] 人物は生徒1人で、講師・大人を入れない指定になっているか

## 2. 生成後（画像を拡大して照合）

### 文字

- [ ] 見出し・コピーに誤字、変形文字、疑似文字がないか
- [ ] 日付と曜日が原稿どおりか（1つずつ照合）
- [ ] 時間が原稿どおりか
- [ ] 料金が原稿どおりか
- [ ] 電話番号が原稿どおりか
- [ ] 校舎名・学校名・学年が正しいか
- [ ] 指定していない文言・英語・数字が足されていないか

### デザイン

- [ ] 最初に目に入る場所が、意図したもの（大見出し・バッジ）になっているか
- [ ] 情報量が多すぎないか、余白があるか
- [ ] 色を使いすぎていないか
- [ ] 見出しと本文の大きさの差がはっきりしているか
- [ ] 写真と文字が重なって読みにくくなっていないか
- [ ] QR 用の白枠が空白のまま、十分な大きさで残っているか
- [ ] ロゴ用の余白があるか
- [ ] アイコンや装飾に乱れ（余計な図形・丸・線）がないか
- [ ] AI っぽい装飾（グロー、グラデーション、立体文字）がないか

### 人物写真

- [ ] 手・指・目が不自然でないか
- [ ] 筆記具・教材・机が不自然でないか
- [ ] カメラ目線になっていないか
- [ ] 講師・大人が入り込んでいないか
- [ ] 塾・学校らしい服装と雰囲気か

## 3. 解像度

- A4 を 300dpi で印刷するには、約 2480 × 3508px が必要
- 過去の ChatGPT の出力は 1414 × 2000px または 1055 × 1491px。**1055 × 1491px では A4 印刷には粗い**
- 小さく出力されたときは、プロンプトで大きなサイズを求めて出し直すか、印刷前に高画質化（アップスケール）する
- 掲示・サイネージ用（16:9）は 1920 × 1080px 相当

## 4. 仕上げ・印刷前

- [ ] 正式ロゴを左上の余白に配置した
- [ ] 正式な QR コードを白枠に配置し、スマホで読み取れることを確かめた
- [ ] 日時・料金・電話番号を、印刷前にもう一度原稿と照合した
- [ ] `50_制作実例.md` に記録を追記した
