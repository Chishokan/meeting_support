# チラシ原稿テンプレート（要項から原稿を作る型）

プロンプトを組む前に、**チラシに載せる文言と数字（原稿）を先に固める**ための型。
原稿が決まっていれば、誰が作ってもチラシの方向性がそろい、料金・日付の間違いも防げる。

流れ：確定した要項 → **この型で原稿を作る** → 担当者が原稿を確認 → `20_新規制作プロンプト.md` に差し込む → 生成

## 0. 共通のルール

- 原稿の事実（日付・時間・会場・料金・申込方法・電話番号）は、`status: 確定` の要項からだけ取る。言い換えない
- 日付は「12月26日（土）」の形。年をまたぐときは「2027年1月4日（月）」と年を書く
- 料金はカンマ付き・税込/税抜を要項どおりに書く（例：5,500円（税込））
- **チラシの対象を1つに決める**：一般生向け（外部募集）か、塾生向けか。料金・申込方法は対象側だけ載せる
- 制作側で作ってよいのは、メインコピー・サブコピー・POINT の見出しと説明・締めのコピー・バッジの文言。
  事実を含む言い回し（「教材費無料」など）は要項で裏付けが取れる範囲だけ
- コピーは `10_デザインルール.md` の「1-1. 伝えるメッセージ」に沿わせる（生徒の成長・変化、自立型人間、学習習慣・勉強体力。割引の上乗せや他塾との比較で訴求しない）
- 要項に無い・食い違う情報は載せずに「載せなかった情報」に書き、担当者に確認する
  （例：受付時間は要項テンプレートと全部門共通の時間が食い違っているため、2026年10月時点では載せない）

## 1. 原稿シート（全種類共通の書式）

この書式を埋めて担当者に確認してもらう。`{{ }}` が残っていたら未完成。

```markdown
# 原稿：{{講座名}}（{{一般生向け／塾生向け}}・{{A4縦チラシ／ポスター／サイネージ}}）

- 元にした要項：{{40_要項/2026/…md}}（updated: {{日付}}）
- 種類：{{講習会／無料講座／模試・テスト／紹介・キャンペーン}}
- 対象：{{学年}}（{{塾生・一般生}}）
- 配布・掲示の場所と時期：{{例）各校舎で配布、門配。11月中旬から}}

## ① ヒーロー
- 対象ラベル：「{{例）中学3年生対象　塾生以外も参加OK}}」
- 大見出し：「{{講座名（正式名称）}}」
- バッジ：「{{例）参加無料／全8日程／志望校判定付き}}」（事実だけ）
- メインコピー：「{{制作側で作る。1文}}」
- サブコピー：「{{制作側で作る。1文}}」

## ② 特長（POINT 3つ）
- 帯見出し：「{{例）冬に仕上げる 3つのPOINT}}」
- 01：「{{見出し}}」 {{説明1文}}
- 02：「{{見出し}}」 {{説明1文}}
- 03：「{{見出し}}」 {{説明1文}}

## ③ 詳細情報（要項から一字一句）
| 項目 | 内容 |
|---|---|
| 日程 | {{要項＜実施内容および日程＞の日程}} |
| 時間 | {{同 時間}} |
| 会場 | {{同 会場}} |
| 内容 | {{同 内容。長ければ要点}} |

## ④ 条件（要項から一字一句）
- 受講料：{{要項＜受講料＞のうち、対象側の金額と税込/税抜}}
- 持ち物：{{要項＜その他＞}}
- 申込期間：{{要項＜申込＞の申込開始日〜申込期限}}
- 申込方法：{{要項＜申込＞のうち、対象側の方法}}
- 定員・締切：{{要項＜定員・締切＞。無ければ載せない}}

## ⑤ CTA
- 締めのコピー：「{{制作側で作る}}」
- 電話：「0120-41-1976」
- QR：「WEBからのお申し込みはこちら」（QR コードは後から貼る）

## 制作側で作ったコピー（担当者の確認が必要）
- {{一覧}}

- {{例）受付時間：要項どうしで食い違うため}}
```

## 2. 種類ごとの型

### 2-1. 講習会（春期・夏期・冬期。有料講座）

元の要項：`_TEMPLATE_有料講座.md` の形。

| チラシのエリア | 要項の欄 | 書き方 |
|---|---|---|
| ① 大見出し | ＜基本情報＞講座名 | 正式名称。年度の「2026」は小さくてよい |
| ① メインコピー | ＜実施概要＞ | 「この期間に何を変えられるか」を1文で。例：「冬休みで、入試本番の得点力を仕上げる。」 |
| ② 特長 | ＜実施概要＞＋＜実施内容および日程＞の内容 | 講習でできることを3つ。例：苦手単元の総復習／学習習慣（おはよう勉強会）／模試・テストで実力確認 |
| ③ 詳細 | ＜実施内容および日程＞ | 日程・時間・会場。講座が複数あるとき（講習＋正月特訓＋模試など）は表にする |
| ④ 条件 | ＜受講料＞（税込）・＜申込＞ | 一般生向けなら一般生の受講料。塾生の扱い（「塾生にはRED・ネクスタの生徒を含む」など）は要項の注記どおり |
| ⑤ CTA | ＜連絡先＞ | 締めのコピー例：「この冬が、春の自信になる。」 |

- 学年で講習が分かれる（中1・2／中3）ときは、チラシも分ける。1枚に混ぜると日程・料金を読み違える
- 講習会は「夢・志実現プログラム」の何弾目かが要項の実施概要に書かれていることがある。載せるならサブコピーに

**記入例（日程・会場まで。料金は要項の＜受講料＞を見て入れる）**：2026 中３冬期講習会（`40_要項/2026/2026-12_冬期_中等部_中3.md`）

| 項目 | 原稿 |
|---|---|
| 大見出し | 「2026 中３冬期講習会」 |
| 対象ラベル | 「中学3年生（塾生・一般生）」 |
| ③ 中3冬期講習会 | 全8日程　2026年12月26日（土）・12月27日（日）・12月28日（月）・12月29日（火）・2027年1月4日（月）・1月5日（火）・1月6日（水）・1月7日（木）　9:45〜15:30　佐世保駅前校・日野校・日宇校・大野校　50分×5教科授業 |
| ③ 正月特訓 | 2027年1月2日（土）　9:30〜18:00　佐世保駅前校（内容は要項で「未定」→ 内容は載せない） |
| ③ 長崎県一斉模試 | 2027年1月9日（土）　10:00〜15:20　4校舎　志望校判定付き |
| 載せなかった情報 | 正月特訓の内容（要項で未定） |

### 2-2. 無料講座（定期テスト対策・TOP10講座・チャレンジ会など）

元の要項：`_TEMPLATE_無料講座.md` の形。実例：`50_制作実例.md` の「1. 中等部 定期テスト対策」。

| チラシのエリア | 要項の欄 | 書き方 |
|---|---|---|
| ① バッジ | ＜受講料＞ | 「参加無料」。教材費もかからない場合だけ「教材費もかかりません」を④に |
| ① 対象ラベル | ＜対象＞ | 一般生も参加できるなら「塾生以外も参加OK」 |
| ① メインコピー | ＜実施概要＞ | 「何を勉強して、なぜ点数につながるか」。例：「定期テストで、目標点を達成しよう！」 |
| ② 特長 | ＜実施内容および日程＞の内容 | POINT 3つ。例：予想問題に挑戦／解説授業で「わかる」に変える／学校ワーク・試験範囲を仕上げ |
| ③ 詳細 | ＜実施内容および日程＞ | 校舎ごとに日程が違うときは「校舎別日程」の表（左列に校舎名と電話番号） |
| ④ 条件 | ＜申込＞・＜その他＞ | 持ち物、申込開始日と期限（例：各実施日の2日前まで） |

- 無料講座は「入会につなげる入口」。締めのコピーで次の行動（申込・相談）を1つだけ示す
- 「無料」を最大の見出しにしない。大見出しは講座名、無料はバッジで示す（`10_デザインルール.md` 1-1）

### 2-3. 模試・テスト（本番レベル模試・特待生選抜テスト・県一斉模試など）

| チラシのエリア | 要項の欄 | 書き方 |
|---|---|---|
| ① 大見出し＋日付 | 講座名・日程 | 日付を大きく（例：「11.22 SUN」）。曜日は要項で確認 |
| ② 特長 | ＜実施概要＞ | 「なぜこの模試を受けるのか」を問いかけの帯見出し＋01〜04。例：本番と同じ形式／志望校判定／学習アドバイス |
| ③ 詳細 | ＜実施内容および日程＞ | 実施日・時間・会場・科目 |
| ④ 条件 | ＜受講料＞・＜申込＞ | 受験料。特待生選抜テストは、特典（授業料の免除など）を要項の文言どおりに。条件（対象月・冬期の扱い）を省かない |

- 配色は `10_デザインルール.md` 2-2（県立中受検対策系は濃紺・白・金色・赤）
- 実績（成績UP・合格者数）を載せるときは、数字の出所と時点を原稿に書く。生徒の実名は載せない

### 2-4. 紹介・キャンペーン（友人紹介、体験パック、入会キャンペーン）

元の要項：`2026-05_2026体験パック.md`・`2026-05_5・6月入会キャンペーン.md` など。紹介制度は要項ではなく制度の資料が元になる〔要確認：紹介制度の正式な資料の置き場所〕。

| チラシのエリア | 元の情報 | 書き方 |
|---|---|---|
| ① 大見出し | 制度名・キャンペーン名 | 正式名称 |
| ① メインコピー | ― | 友達・兄弟姉妹と一緒に学ぶ良さ。例：「友達と一緒なら、続けられる。」 |
| ② 特長 | 体験の内容 | 体験でわかること・できることを3つ |
| ③ 詳細 | 期間・対象 | 体験期間、対象学年、対象校舎 |
| ④ 条件 | 特典・条件 | 特典は要項・制度の文言どおり。適用条件（期間・対象・回数）を必ず一緒に載せる |
| ⑤ CTA | ― | 紹介につながるコピーを**1つだけ**大きく（例：「友達を誘って、体験しよう」） |

- 特典の金額を最大の見出しにしない（割引の上乗せで訴求しない。`10_デザインルール.md` 1-1）
- 紹介は「お願いは一度きりにせず続ける」が会社の方針（COMPANY.md「募集に対する考え方」）。チラシは在籍生・保護者に渡す前提で、紹介する側の言葉で書く

## 3. 原稿の確認

原稿ができたら、`40_チェックリスト.md` の「1. 生成前」の「原稿」「メッセージ」を確認し、
「制作側で作ったコピー」と「載せなかった情報」を担当者（要項の `owner`）に見てもらう。
確認が済んだら、`20_新規制作プロンプト.md` の基本テンプレートに差し込む。
