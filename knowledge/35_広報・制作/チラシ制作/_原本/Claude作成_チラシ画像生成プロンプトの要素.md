# チラシ画像生成プロンプトの要素（智翔館）

作成日：2026年10月5日
用途：ChatGPTの画像生成で、智翔館のチラシ・ポスター・サイネージを作るときのプロンプトの型。
出典：2026年10月2日〜5日のChatGPTでの制作履歴（紹介制度チラシ、本番レベル模試チラシ、RED定期テスト対策チラシ）と、同じ型で作った中等部「定期テスト対策」チラシ（2026年10月5日）。

## 1. 作業の流れ

1. 要項（講座要項テンプレートの該当タブ）から、チラシに載せる事実を抜き出す
2. 下記「2. 新規制作プロンプトの構成」に沿ってプロンプトを組む
3. ChatGPTの新しいチャットに貼り付けて画像を生成する
4. 生成画像を拡大し、文言・日付・時間・電話番号を原稿と1つずつ照合する
5. 直す箇所があれば「5. 修正依頼の型」で同じ会話に指示する
6. ロゴとQRコードは、生成後に別ツールで実物を重ねる

## 2. 新規制作プロンプトの構成

冒頭に # で3行のタイトルを置き、以降は ==== の区切り線と【 】の見出しでセクションを分ける。

```
# 智翔館 （部門名）
# 「（講座名・制度名）」
# A4縦チラシ 新規制作プロンプト
```

| 順 | セクション | 書く内容 |
|---|---|---|
| 1 | 【サイズ】 | A4縦、210mm × 297mm、アスペクト比 約1：1.414、印刷用高解像度（300dpi相当）、使い道（配布・掲示など） |
| 2 | 【このチラシの目的】 | 対象は誰か（学年、塾生／一般生、保護者）、見た人にどう動いてほしいか |
| 3 | 【全体コンセプト】 | # 「メインコピー」 を1つ。与えたい印象を3語ほど。「実際の学習塾が制作した配布物の完成度を目指す」 |
| 4 | 【配色】 | 基本カラーとアクセントカラー。アクセントを使う場所を限定する。余白の指示 |
| 5 | 【レイアウト｜最重要】 | 紙面を上から①〜⑤のエリアに分ける。エリアごとに ━━ 区切りで、見出し・掲載文言・見せ方を書く |
| 6 | 【情報の優先順位】 | 視線の順番を 1 → 2 → 3 … と「↓」でつないで書く |
| 7 | 【文字サイズ】 | 紙面最大にするもの、2番目に目立たせるもの、中サイズ、小さめ、を指定 |
| 8 | 【写真・人物の雰囲気】 | 人物の条件、場所、光、表情。避けたい不自然さ |
| 9 | 【文字品質】 | 一字一句正確に、誤字・変形文字・疑似文字は禁止、滲みやぼやけのないゴシック体 |
| 10 | 【デザイン上の禁止事項】 | 使わない表現を箇条書き |
| 11 | 【完成イメージ】 | 「数メートル離れた場所からでも〇〇と〇〇の2点が分かる」の形で締める |

## 3. 定番の指定（毎回入れるもの）

### 配色

- 基本：白、智翔館をイメージする濃紺、明るいブルー
- アクセント：黄色（重要ワード、バッジ、マーカー風下線）、赤（日付、強調語）を少量
- 白い余白を十分に取り、清潔感を保つ
- 県立中の受検対策系は、濃紺・白・金色・赤の組み合わせ（本番レベル模試チラシ）

### 文字

- 掲載する文言は「　」で囲んで指定する
- 数字・日付・時間・料金は「以下を一字一句正確に使用」と書いてから並べる
- 金額はカンマ付きで書く（「5,500円」）
- 「このプロンプトに書かれていない文言・数字・住所・ロゴ・QRコードは追加しない」

### ロゴとQRコード

- ロゴは生成しない。左上に、後から配置するための明るい余白を確保する
- QRコードは生成しない。白い正方形の空白スペースを確保し、「WEBからのお申し込みはこちら」などの案内文を添える

### 写真・人物

- 制服姿の日本の中学生（または小学生）1人が、明るい教室で勉強している
- 自然光、清潔感のある教室、リアルな日本の教育現場
- 笑顔を作りすぎない自然な表情
- 人物は生徒1人のみ。講師・大人は入れない（過去の修正で、スーツ姿の男性を消す指示が繰り返し出ているため）
- 不自然な顔や手指は避ける
- 写真は細かく並べず、メイン1点

### 禁止事項

- 過剰なグラデーション
- 大量のドロップシャドウ
- ネオンカラー
- 3Dアイコン
- 過剰な角丸
- 不要な装飾
- 不自然な光彩、文字のグロー
- 情報が紙面全体に散らばるレイアウト

## 4. レイアウトの定番パターン

上から順に読めば内容が分かる5エリア構成にする。

| エリア | 内容 | 過去の例 |
|---|---|---|
| ① ヒーロー（紙面上部 約30％） | ロゴ余白、対象ラベル、大見出し、バッジ、サブコピー、右側に写真 | 「定期テスト対策」＋「参加無料」バッジ／「本番レベル模試」＋「11.1 SUN」 |
| ② 特長 | 帯見出し＋番号付きカード3〜4枚（アイコン付き） | 「3つのPOINT」／「なぜ『本番レベル』なのか？」01〜04 |
| ③ 詳細情報 | 表またはカード。日付は赤の太字 | 校舎別日程（4校舎の表）／実施日・会場・内容・対象／1日の流れ |
| ④ 条件・実績 | 受講料、持ち物、申込期間、または成績UP実績・合格体験記 | 「無料（教材費もかかりません）」／「前回定期テスト 成績UP実績」 |
| ⑤ 最下部CTA | 濃紺の帯。左に締めのコピー、中央に電話番号、右にQR用の白枠 | 「0120-41-1976」＋「WEBからのお申し込みはこちら」 |

## 5. 修正依頼の型

同じ会話で、変える箇所だけを番号付きで指示する。

```
このチラシ画像を、次の◯点だけ修正してください。
指定箇所以外（レイアウト・配色・フォント・文字・数字・電話番号・住所・写真・ロゴ・QR用の白枠）は
一切変更せず、サイズと縦横比も元画像と同じにしてください。
①（場所）の（現在の内容）を、（変更後の内容）にする。
②「（現在の文言）」を削除し、「（新しい文言）」を大きく読みやすい太字で入れる。
　文言は一字一句このとおりにしてください。
③ …
```

要点：

- 冒頭で「◯点だけ」と件数を言い切る
- 変えないものを（　）内に列挙する。QR用の白枠は「位置も大きさもそのまま必ず残す」と念を押す
- 修正箇所は、場所（右上の写真、赤い帯の左端など）と現在の文言を引用して特定する
- 数字を含む箇所の近くを直すときは「他の実績の数字は絶対に変えない」と添える
- 大きな差し替え（ヒーロー写真の変更、情報の追加）は、新規制作と同じ【 】見出し形式で「編集方針」「修正①②③」「変更しないもの」「完成イメージ」を書く

## 6. 生成後の確認項目

- 見出し・コピーの誤字、変形文字
- 日付と曜日、時間、電話番号、料金（原稿と1つずつ照合）
- 校舎名、学校名、学年
- QR用の白枠が空白のまま残っているか
- ロゴ用の余白があるか
- アイコンや写真の乱れ（余計な図形、手指）
- 解像度（過去の出力は 1414×2000px または 1055×1491px。A4印刷には 1055×1491px だと粗い）

## 7. 実例：中等部「定期テスト対策」チラシ（2026年10月5日）

要項「無料講座_要項テンプレート（記入用）」のタブ「2026秋 中等部テスト対策」から作成。ChatGPTの会話名は「チラシ制作依頼」。

| 要素 | 指定した内容 |
|---|---|
| 目的 | 中学1・2・3年生と保護者。塾生以外の一般生にも参加してもらう |
| コンセプト | 「定期テストで、目標点を達成しよう！」 |
| ① ヒーロー | ラベル「中学1・2・3年生対象　塾生以外も参加OK」／大見出し「定期テスト対策」／黄色の丸バッジ「参加無料」／サブコピー「2学期の評定アップへ。目標点を達成しよう！」／右に制服の生徒1人の写真 |
| ② 特長 | 帯見出し「1日で仕上げる 3つのPOINT」／01「英語・数学の予想問題に挑戦」／02「解説授業で『わかる』に変える」／03「学校ワーク・試験範囲を仕上げ」 |
| ③ 詳細情報 | 帯見出し「校舎別日程」。左列に校舎名と電話番号、右に対象・日付・時間の4校舎の表 |
| ④ 条件 | 受講料「無料（教材費もかかりません）」／持ち物「筆記用具／教科書・学校ワークなど試験範囲のもの」／申込「10月13日（火）受付開始　各実施日の2日前まで」 |
| ⑤ CTA | 「次のテストは、智翔館で準備しよう。」／「お申し込み・お問い合わせ」「0120-41-1976」／QR用の白枠「WEBからのお申し込みはこちら」 |
| 優先順位 | 定期テスト対策・参加無料 → 3つのPOINT → 自分の校舎の日程 → 持ち物・申込期間 → 電話・QR |

補足：

- 「1日で仕上げる 3つのPOINT」、POINTの3文言、「教材費もかかりません」、「次のテストは、智翔館で準備しよう。」は、要項の内容をもとに制作側で作ったコピー
- 受付時間は、要項の記載（9:30〜22:00）と全部門共通の時間（月〜土 13:00〜21:30）が食い違うため載せていない
- 出力は 1055×1491px。文言・日付・電話番号はすべて原稿どおりだった。POINT 02のアイコンに小さな黄色い丸の乱れが1つある
