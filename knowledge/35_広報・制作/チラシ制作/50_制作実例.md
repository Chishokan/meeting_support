# チラシ・ポスター 制作実例

似た企画を作るときは、ここの実例を見本にしてプロンプトを組む（アプリで自動化するときも、近い実例を AI に見せると型がぶれにくい）。
新しく作ったら、末尾の「記録の書式」で追記する。

## 1. 中等部「定期テスト対策」チラシ（2026年10月5日）

- **元にした要項**：「無料講座_要項テンプレート（記入用）」のタブ「2026秋 中等部テスト対策」
- **ChatGPT の会話名**：「チラシ制作依頼」
- **使った型**：`20_新規制作プロンプト.md` の基本テンプレート＋「4-1. 定期テスト対策」

| 要素 | 指定した内容 |
|---|---|
| 目的 | 中学1・2・3年生と保護者。塾生以外の一般生にも参加してもらう |
| コンセプト | 「定期テストで、目標点を達成しよう！」 |
| ① ヒーロー | ラベル「中学1・2・3年生対象　塾生以外も参加OK」／大見出し「定期テスト対策」／黄色の丸バッジ「参加無料」／サブコピー「2学期の評定アップへ。目標点を達成しよう！」／右に制服の生徒1人の写真 |
| ② 特長 | 帯見出し「1日で仕上げる 3つのPOINT」／01「英語・数学の予想問題に挑戦」／02「解説授業で『わかる』に変える」／03「学校ワーク・試験範囲を仕上げ」 |
| ③ 詳細情報 | 帯見出し「校舎別日程」。左列に校舎名と電話番号、右に対象・日付・時間の4校舎の表 |
| ④ 条件 | 受講料「無料（教材費もかかりません）」／持ち物「筆記用具／教科書・学校ワークなど試験範囲のもの」／申込「10月13日（火）受付開始　各実施日の2日前まで」 |
| ⑤ CTA | 「次のテストは、智翔館で準備しよう。」／「お申し込み・お問い合わせ」「0120-41-1976」／QR用の白枠「WEBからのお申し込みはこちら」 |
| 優先順位 | 定期テスト対策・参加無料 → 3つのPOINT → 自分の校舎の日程 → 持ち物・申込期間 → 電話・QR |

**制作側で作ったコピー**（要項の内容をもとに作成）：「1日で仕上げる 3つのPOINT」、POINT の3文言、「教材費もかかりません」、「次のテストは、智翔館で準備しよう。」

**載せなかった情報**：受付時間。要項の記載（9:30〜22:00）と全部門共通の時間（月〜土 13:00〜21:30）が食い違うため

**結果**：

- 出力 1055 × 1491px（A4 印刷には粗い。`40_チェックリスト.md` の「3. 解像度」）
- 文言・日付・電話番号はすべて原稿どおりだった
- POINT 02 のアイコンに、小さな黄色い丸の乱れが1つあった

## 2. 本番レベル模試チラシ（県立中受検対策・2026年10月）

- **ChatGPT の会話名**：「チラシ修正依頼」
- **指定の特徴**：配色は濃紺・白・金色・赤。ヒーローは「本番レベル模試」＋日付「11.1 SUN」。② 特長は「なぜ『本番レベル』なのか？」の帯見出しに 01〜04
- **修正**：ヒーローの写真差し替え、受験料の追加（`30_修正・派生プロンプト.md` の「2. 大きな差し替え」の型）
- 指定文言の全文と結果の記録は未整理

## 3. RED 定期テスト対策チラシ（2026年10月）

- **ChatGPT の会話名**：「チラシ画像修正依頼」（3件）
- **修正**：「次の3点だけ修正」の型で部分修正（`30_修正・派生プロンプト.md` の「1. 部分修正」）
- **学び**：スーツ姿の男性（講師）を消す指示が繰り返し出た → 人物は生徒1人に限定するルールにした（`10_デザインルール.md`）
- 指定文言の全文と結果の記録は未整理

## 4. 紹介制度チラシ（リニューアル・2026年10月）

- **ChatGPT の会話名**：「チラシデザインプロンプト作成」（プロンプトを ChatGPT に書かせた会話。11セクション構成の原型）、「チラシ制作プロンプト」（そのプロンプトで画像を生成した会話）
- **評価**：「いいデザインです」と評価し、ChatGPT のメモリにも記憶させた
