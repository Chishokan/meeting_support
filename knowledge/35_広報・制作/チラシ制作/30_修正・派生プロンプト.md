# チラシ・ポスター 修正・派生プロンプト

## 0. 使い分け

| やりたいこと | 使う型 | 会話 |
|---|---|---|
| 数か所だけ直す | 1. 部分修正 | 同じ会話 |
| ヒーロー写真の変更、情報の追加など大きく直す | 2. 大きな差し替え | 同じ会話 |
| 写真だけ替える | 3. 写真差し替え | 同じ会話 |
| 文字だけ替える | 4. 文字だけの修正 | 同じ会話 |
| 同じ内容で見た目を変える | 5. 別パターン | 新しい会話に元画像を添付 |
| 横長のサイネージにする | 6. 16:9 サイネージ変換 | 新しい会話に元画像を添付 |
| 情報が多すぎる | 7. 情報削減（追記） | 同じ会話 |
| AI っぽさが目立つ | 8. AI っぽさを減らす（追記） | 同じ会話 |

共通の原則：

- 既存画像を直すときは「**新規制作ではない**」「**指定箇所以外は変更しない**」を必ず書く
- 変えないものを列挙する。とくに **QR 用の白枠は「位置も大きさもそのまま必ず残す」** と念を押す
- 修正箇所は「場所（右上の写真、赤い帯の左端など）」と「現在の文言」を引用して特定する
- 数字を含む箇所の近くを直すときは「**他の数字は絶対に変えない**」と添える

## 1. 部分修正（「◯点だけ修正」の型）

実制作（RED 定期テスト対策チラシの部分修正）で使い、意図どおりに直った型。

```text
このチラシ画像を、次の{{件数}}点だけ修正してください。
これは新規制作ではありません。
指定箇所以外（レイアウト・配色・フォント・文字・数字・電話番号・住所・写真・ロゴ・QR用の白枠）は
一切変更せず、サイズと縦横比も元画像と同じにしてください。
QR用の白枠は、位置も大きさもそのまま必ず残してください。

①{{場所}}の{{現在の内容}}を、{{変更後の内容}}にする。
②「{{現在の文言}}」を削除し、「{{新しい文言}}」を大きく読みやすい太字で入れる。
　文言は一字一句このとおりにしてください。
③{{…}}

{{数字の近くを直す場合：修正箇所以外の実績の数字は絶対に変えないでください。}}
```

要点：

- 冒頭で「◯点だけ」と件数を言い切る
- 1回の指示に詰め込みすぎない。直らなかった箇所は、次の指示で件数を減らして出し直す

## 2. 大きな差し替え（ヒーロー写真の変更、情報の追加など）

新規制作と同じ `【 】` 見出し形式で書く。実制作（本番レベル模試チラシのヒーロー差し替え、受験料の追加）で使った型。

```text
# 智翔館 {{部門名}}
# 「{{講座名}}」
# 既存チラシの修正プロンプト

添付（直前）のチラシ画像をベースとして使用する。
今回の作業は、新しいデザインをゼロから制作することではない。
現在のデザインを可能な限り維持したうえで、指定箇所のみ修正する。

====================
【編集方針】
====================
修正箇所だけを自然に置き換え、既存デザインの余白・文字サイズ・色・配置ルールに合わせる。
修正した部分だけが不自然に目立たないようにする。
ただし、重要情報は既存デザインの範囲内で十分に読みやすくする。

====================
【修正①】
====================
{{場所・現在の内容・変更後の内容}}

====================
【修正②】
====================
{{…}}

====================
【変更しないもの】
====================
・全体レイアウト、配色、背景、フォントの雰囲気、文字サイズのメリハリ
・修正箇所以外の写真、ロゴ用の余白
・掲載済みの文字、数字、日付、時間、料金、電話番号、住所
・QR用の白枠（位置も大きさもそのまま）
・キャンバスサイズ、縦横比

====================
【禁止】
====================
新しいコピー・装飾・アイコンを追加しない。人物を増やさない。
ロゴやQRコードを生成しない。

====================
【完成イメージ】
====================
{{例）元のチラシのまま、ヒーローの写真だけが差し替わり、受験料が読みやすく加わったもの}}
```

## 3. 写真差し替え

```text
このチラシ画像をそのまま使用し、指定した写真部分だけを変更してください。
これは新規制作ではありません。
レイアウト・配色・フォント・文字・数字・電話番号・住所・ロゴ用の余白・QR用の白枠・他の写真は一切変更しないでください。

【変更箇所】
位置：{{例）右上の写真}}
現在：{{現在の写真内容}}
変更後：{{新しい写真内容}}

【新しい写真の条件】
日本の学習塾の明るい教室。
制服姿の日本の中学生1人のみ（講師や大人は入れない）。
自然な姿勢で、カメラ目線ではなく、問題集またはノートに集中している。
顔、手、指、目、筆記具を自然に描写する。
広告モデルのような不自然な笑顔は避ける。
既存写真と同程度の明るさ・色温度に合わせる。
```

## 4. 文字だけの修正

```text
このチラシ画像をそのまま使用してください。これは新規制作ではありません。
今回変更するのは、指定された文字のみです。

【変更前】
「{{変更前テキスト}}」

【変更後】
「{{変更後テキスト}}」
文言は一字一句このとおりにしてください。

文字の変更でレイアウトが大きく崩れないよう、必要な場合のみ、
該当テキストの文字サイズや幅を最小限調整してください。
それ以外の文字、数字、写真、色、位置、ロゴ用の余白、QR用の白枠、背景は変更しないでください。
```

## 5. 別パターン（同じ内容で見た目を変える）

校舎掲示を貼り替えるときなど、「新しいポスターに替わった」と一目で分かるようにしたい場合。

```text
添付画像は、掲載情報とブランドイメージの参考として使用する。
今回は既存デザインの微修正ではなく、新しいチラシを制作する。
同じ情報を使いながら、「新しいポスターに差し替わった」と校舎掲示で一目で分かる程度にレイアウトを変える。

【変更する要素】
写真の配置、メインタイトルの位置、情報ブロックの配置、日付の見せ方、強調エリア、余白、見出しデザイン。
既存画像に帯やカードを足しただけの「軽微な変更」に見せず、構図そのものを再設計する。

【維持する要素】
掲載内容、日付、時間、料金、学校名、校舎名、電話番号、ブランドカラー、智翔館らしい信頼感。
ロゴ用の余白とQR用の白枠は必ず確保する（ロゴとQRコードは生成しない）。

派手すぎる広告デザインにはしない。
```

## 6. A4チラシ → 16:9 サイネージ変換

```text
添付のA4縦チラシを参考にして、横長16:9のデジタルサイネージへ再設計する。
A4チラシを単純に横へ引き伸ばさない。

【サイズ】
16:9 横長、1920 × 1080px相当。

【目的】
離れた場所から3秒程度見ただけで、何のイベントか・対象・いつ開催するか・最大のメリットが分かること。

【情報量】
A4版の30〜50%程度まで減らす。すべての情報を載せようとしない。

【優先して掲載】
1. イベント名　2. メインコピー　3. 日程　4. 対象　5. 最大のメリット　6. 会場　7. 申込QRコード用の白い空白スペース

【載せないもの】
長い説明文、注意事項、細かな補足、詳細なタイムテーブル、長い問い合わせ説明。

【デザイン】
余白を大きく、文字を大きくする。1画面の情報ブロックは3〜5個程度。
遠くからでも読める文字サイズ。白と濃紺を中心にした、信頼感のある智翔館のデザイン。
日本語は元のチラシの文言を一字一句変えずに使い、新しい数字や文言を足さない。
ロゴとQRコードは生成せず、後から置く余白だけ確保する。
```

## 7. 情報削減（追記用）

```text
現在のデザインは情報量が多いため、掲載情報を約半分まで減らしてください。
「説明する」ことよりも「一瞬で理解できる」ことを優先します。
残す情報は、イベント名・何をするイベントか・対象・日程・最大のメリットを中心とします。
長い文章は削除し、短い見出しに変えてください。
文字を小さくして情報を詰め込む方法は使わないでください。
残す文言・数字は一字一句変えないでください。
```

## 8. AI っぽさを減らす（追記用）

```text
全体を、日本の学習塾が実際に制作会社へ依頼して作成した教育系広報物のようなデザインにしてください。
AI生成画像特有の、派手なグラデーション、光の筋、発光エフェクト、意味不明な装飾、過剰なアイコン、
不自然な立体文字、カードUIの大量配置、過度にカラフルな配色は使わないでください。
フラットで整理された日本のDTPデザインを意識し、余白・整列・文字サイズ・情報の優先順位で見せてください。
文言・数字・レイアウトの情報の並びは変えないでください。
```
