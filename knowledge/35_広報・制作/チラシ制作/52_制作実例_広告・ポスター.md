# 制作実例（広告・ポスター・掲示物）

## この文書の使い方

- `51_制作実例_2026秋.md` と同じ案件（全国統一・高専・冬期講習）は、51 に無い情報（修正の経緯、ポスター・サイネージの作り分け、プロンプトの型）だけを書いた。基本情報は 51 を見る。

- 職員・依頼者・講師の名前は「担当」「依頼者」「講師」と書いた。

## 1. 全国統一高校生テスト 校舎外ポスター（51の3の追加）

| 項目 | 内容 |
|---|---|
| 目的 | 校舎前を通る高校生・保護者（塾生以外を含む）に、無料招待の全国模試を知らせ、QRから申し込んでもらう |
| 元資料 | 東進の配布チラシの写真4枚（チャットで共有。ファイルとしては未保存） |
| 実施日 | README・v2プロンプトとも「11月1日（日）」「11.1」。51 の「11.10」は画像の読み取り違いと思われる〔要確認：51の記載を直すか〕 |
| v1 | 智翔館の定番（濃紺・赤い帯・濃紺CTA帯）→「高専攻略講座の校舎外ポスターと構成・配色が似すぎ」で不採用 |
| v2（採用） | 安藤さんの指示「東進の緑を入れる／問い合わせ先は智翔館／東進の名前を入れる」で東進チラシ寄りに一新 |
| v2の配色 | 白地＋深い緑（#00796B付近）が主役。大見出しだけ赤、日付の数字は黒。濃紺・青・水色は使わない。黄色は1か所まで |
| v2の構成 | 最上部1行「東進模試は学力を伸ばし合格するための模試です。」（「合格するため」だけ赤）／左42%：赤の縦書き大見出し「全国統一高校生テスト」＋縦書きキャッチ＋角印風「無料招待」／右58%：高校生3人の写真→黒の巨大な「11.1」＋赤丸「日」→緑リボン「全国一斉実施」→対象の札4つ（高3・高2・高1・高0生）／中段：特長3行（緑の丸数字、細い緑線で区切る。カードにしない）→申込締切の枠→高0生の注記／最下部：緑の帯（問い合わせ 智翔館・電話・QR枠・小さく「主催：東進」） |
| プロンプトの工夫 | 冒頭に「過去の会話やメモリにある塾チラシのデザイン（濃紺の帯、赤い帯、黄色の丸バッジ、右上に生徒1人の写真）は参照しない」と書いた。禁止事項にも定番部品を列挙 |
| QR | 飛び先は東進の公式案内ページ（全学年統一部門・高2・高1部門の申込ボタンがある）。外部サイトのため utm は付けない。A4換算で約18.6mm角。合成後に機械で読み取りURL一致、スマホは未確認 |
| 残った点 | ロゴ用の余白を指定したがほぼ確保されなかった。会場、電話番号（共通番号でよいか）、東進衛星予備校ロゴと名称の使用ルール、特長1の注記「※全学年統一部門の場合」の要否〔要確認〕 |
| 場所 | `02_制作/20261009_全国統一高校生テストポスター_校舎外_生成プロンプト_v1.md`・`_v2.md`。納品は `05_広告制作/20261009_全国統一高校生テスト_納品データ/`（02・05・06） |

学び
- 他社主催の企画は、主催者のブランド色に寄せると定番デザインとの「似すぎ」を避けられる。問い合わせ先と「主催：◯◯」の両方を明記する。
- 定番部品を使わせたくないときは、使わない部品を名前で列挙し、過去の会話・メモリを参照しないと書く。

## 2. 高専攻略講座 ポスター・サイネージ（51の4の追加）

| 項目 | 内容 |
|---|---|
| 作り方 | 承認済みのチラシ2ページと同じ ChatGPT の会話に続けて貼る。A4チラシを横に引き伸ばさない |
| サイネージ（16:9） | 目的「校舎入口で3秒見て、何の講座か・対象・いつ始まるかが分かる」。左60%：ラベル・大見出し・サブコピー・黄色丸バッジ「12月6日（日）スタート」・アイコン付き3項目／右40%：中学生1人の写真／最下部の細い濃紺帯：会場・申込締切（塾生／一般生）・QR枠。載せないもの：カレンダー、受講料表、持ち物、長い説明文 |
| サイネージの文言調整 | 画面で読めるよう、POINT 02 から「智翔館」を省いて短くした |
| ポスター共通案 | 表面の情報を約半分に絞った版（ヒーロー55%・POINT 25%・CTA帯20%）→不採用（ダウンロードされず） |
| ポスター校舎内（塾生向け） | ヒーロー／赤い帯「11月30日（月）までのセット受講申込で 高専入試過去問題集をプレゼント」／12月・1月のカレンダー／塾生の受講料3枠／「塾生はGROWアプリからお申し込み 11月30日（月）まで」／QR枠「塾生以外の方のお申し込みはこちら」 |
| ポスター校舎外（一般生向け） | ヒーロー／赤い帯「塾生以外も受講OK！」／開始日・全7日程・会場／「過去問解説会＋対策授業（全6回）」／「お申し込みは12月4日（金）まで」／電話／QR枠 |
| 写真の性別 | 校舎内は性別を指定せず男子生徒になった。校舎外は女子生徒を指定。→ 写真の人物は毎回指定する |
| 解像度 | 生成は1054×1492px。A2で約64dpi、A1で約45dpi。近くで見る校舎内は粗さが見える |
| QR | LPスラッグ確定後、utm（flyer／poster-in／poster-out／signage、medium=qr、campaign=kk26）を付けた4種を作成。一覧CSV付き。チラシのQRはA4で約17mm角（目安18mmにわずかに届かない） |
| LPメイン画像 | 同じ会話で16:9（1672×941px）を生成。QR枠・電話・ロゴ余白なしで指定 |
| 工程表 | 10/4 依頼 → 10/8 初稿 → 10/9 担当チェック依頼（〜10/14）→ 10/16 チラシ完成 → 10/23 ポスター・サイネージ完成 → 10/28 QR → 10/30 データ納品 → 11/5 LP公開・送信テスト → 11/6 申込開始 |
| 制作側の文言 | 「塾生はGROWアプリからお申し込み」「塾生以外の方のお申し込みはこちら」「お申し込みは12月4日（金）まで」「塾生の受講料（税込・教材費込み）」も確認対象に追加 |
| 場所 | `02_制作/20261008_高専攻略講座広報物_サイネージポスター生成プロンプト_v1.md`（末尾に10/9の追記）、`01_原稿/20261008_高専攻略講座広報物_工程表と確認文面_v1.md` |

学び
- 校舎内ポスターは塾生向け（特典・カレンダー・塾生の申込方法）、校舎外は一般生向け（「塾生以外も」・締切・電話）と、読む人で載せる情報を分ける。
- 会話内の画像の順番（チラシ表→裏→ポスター共通案→サイネージ→校舎内→校舎外）を README に控えると、あとで探せる。

## 3. 冬期講習 ポスターA1・サイネージ・色変更（51の8の追加）

ポスターA1（3講座とも同じ型。各講座のチラシと同じ会話で生成）

| エリア | 割合 | 中身 |
|---|---|---|
| ① 見出しの帯 | 約20% | 左上にロゴ用の明るい余白。横幅いっぱいの濃紺帯、右上に白い細線の雪の結晶を2つだけ。帯内に白の小見出し（講座ごとのリード）＋紙面最大の大見出し。右端に赤の横長リボン（角は直角）「超早割／11月30日（月）まで」 |
| ② 写真タイル | 約26〜30% | チラシ表面と同じ構成の四角い写真3枚。大人は入れない（県中は私服の小学生） |
| ③ キャッチと期間 | 約14〜28% | 赤ラベル（対象）＋青ラベル（塾生以外も受講OK）／黄色マーカーのキャッチ（紙面で2番目）／赤の期間／プログラム名を青の「→」でつないだ1行／会場 |
| ④ 2つのコース（県中のみ） | 約18% | カード2枚（小6・小5）。説明文なし |
| ⑤ CTA帯 | 約14〜16% | チラシと同じ濃紺帯で文字を大きく：ロゴ枠・「一般生のお申込みはWEBから」・申込締切（黄）・電話（大きく黄）・受付時間・QR枠 |

- 載せないもの：日程の詳細、受講料・割引の表、小さな説明文。
- 完成イメージに「数メートル離れた場所から『講座名』『キャッチ』『期間』『早割』が読み取れる」と書く。
- 制作側の文言は「プログラム名を矢印でつないだ1行」だけ（名前は要項どおり）。

サイネージ16:9（3講座とも同じ型）
- 上部80%を左右2分割：右45%に写真1枚＋写真の左下に赤リボン、左55%は白地にラベル→濃紺帯（小見出し＋画面最大の大見出し）→キャッチ→期間→会場。
- 下部20%：濃紺帯に申込締切と電話を横並び、受付時間、右端にQR枠。
- 文言はポスターで使ったものだけ。

メインカラーの変更（10/29、案B＋県中①）
```
添付した画像（この会話で作った「（画像名）」）を元に、配色だけを次のとおり変更した画像を1枚作ってください。レイアウト・文字・写真・サイズは一切変更しない。
変更：濃紺（ネイビー）で塗られている部分をすべて「（色名） #（HEX）」に置き換える。
　対象：大見出しの帯、帯見出し、最下部の申込の帯、濃紺のラベルや四角、カレンダーの濃紺のマスと凡例の四角、表の見出しの濃紺。
　濃紺の文字（白地の上の見出しや本文）は、そのまま濃紺で残す。
変更しないもの：赤のリボンと赤のラベル、黄色のマーカー・黄色の文字、明るいブルーのラベルや帯、白、写真、すべての文字の内容・大きさ・位置。
文字は一字一句変えない。日付・金額・電話番号は絶対に変えない。
```
- 1枚ずつ、各講座の会話で画像を添付し直して送る（中1・2＝チラシ表裏・ポスター・サイネージの4枚、県中＝6枚）。
- 「塗り」と「文字の色」を分けて指定したのがポイント。

要項とLPの食い違い（10/28報告）
- 承認済みLPのキャッチは流用したが、金額・日程はLPと要項で5件食い違っていた（おはよう勉強会の一般生料金・日程、実力判定テストの一般生料金、県中の塾生申込期限、県中入試チャレンジ会の有無）→ チラシは要項どおりに作り、差を報告。
- LPにあった合格者の成績変化、「◯年以上指導」の実績、保護者・生徒の声は facts で確かめられないため使わなかった。
- 要項で「未定」の内容（正月特訓の中身）は説明を書かず、LPの承認済みコピー1行だけ使った。
- 別講座（高専攻略講座）は裏面に小さく案内だけ載せる（10/16決定）。

## 5. REDバス広告（自立学習RED 西海大島教室）

BOXティッシュの作り方（docs/04-design.md から要点）
- Canvaの過去デザインを複製して型（展開図、ロックされた最背面の要素）だけ残す。元デザインは触らない。
- 面ごとに作って確認をもらう（天面 → 裏面 → 側面）。
- 取り出し口（天面中央、面の上から約41〜73mm）に文字・顔・QRを置かない。裏面の左右は糊しろ。側面の短辺は約3mmの塗り足し。仕上がり線から3mm以内に文字を置かない。
- ChatGPTの出力は最大1536×1024px。165mm幅で約230dpiで、入稿基準（350dpi）に届かない。
- 「写真風の小学生」は ChatGPT のポリシーで断られる → イラスト調を指定。
- 細長い側面用の帯は「3:2の中央に帯を1本、上下は白」と指定して切り出す。4項目は横一列より2列×2段の方が文字を大きくできる。
- 電話番号・料金・時間は画像に描かせず Canva のテキストで打つ（あとで直せる）。
- 安藤さんが Canva で直接直した箇所は、編集前に現状を読み、戻さない。

好み（安藤さんの判断）
- 過去デザインの踏襲より一新。写真1枚＋コピー1本＋余白で、イメージで伝える。
- 天面は対象を限定しない。小学生向けの詳細は裏面・天面下半分へ。
- 営業色を強くしない。成績アップ率・生徒数・料金比較などの数字は使わない。
- 既存チラシの要素は作り直すより切り出して使う。
- 地域への否定的な表現は避ける。教室名は「RED西海大島教室」。

数字を掲示するときの決まり（掲示原稿 Part 2）
- 「93%」は比較表に入れず見出しで単独に使う。参加していない人も7月→8月で9割が上がっている（8月は全体が上がった回）ため、並べると誤解を生む。
- 「おは勉に参加したから偏差値が◯上がった」とは書かない。参加者はもともと偏差値が高かった。
- 注釈（対象の模試、母数、期間、「7月と8月は別の模試」）は省略しない。
- 「◯点アップ」は使わない（得点が出やすい回だったため）。
- 聞かれたときの答え方も原稿に用意する（「出るだけで上がるとは言えません。ただ、同じくらいの成績の生徒どうしで比べても…」）。
- 生徒別の突合表は個人情報のため `07_名簿成績出席` に置き、掲示には集計値だけを使う。
