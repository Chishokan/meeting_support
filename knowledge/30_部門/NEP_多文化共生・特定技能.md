# 多文化共生・特定技能 定着支援の展開計画

## 前提

- 出典：「特定技能 定着支援 展開・営業計画 v2」（2026/08/29作成、対象期間 2026/09〜2027/03）。元資料はスライド「特定技能留学生支援アプリ（TOMONI 仮称）」（2026/08/02）。
- 読み手：社内の意思決定者（社長・共同経営者）。9月の動き出しを決めるための計画。
- 第36期のNEP「③ 多文化共生支援」の柱にあたる（`30_部門/NEP_第36期計画.md`）。10/27の外国人材受入協議会での発表は `35_広報・制作/スライド制作/20_制作実例.md` の6。
- 11月4日時点で、計画の実施結果は記録されていない〔要確認：9〜10月の各施策の実施状況〕。

## 中心の判断

- アプリの完成を待たない。いま動いている JOT試験（会場運営）＋日本語eラーニング＋生活支援チャットで有償実績を作り、その運用データを要件にしてアプリを作る。
- 売り物を「義務的支援の省力化」（登録支援機関が月額で請け負っている領域で価格勝負になる）ではなく「定着（辞めない）」に寄せる。
- 智翔館の強み：試験会場・教材・指導ノウハウ・地域の信用の4つを持つ。

## 事業の骨格：2本のラインと継ぎ目

| | ライン A 留学生 | ライン B 就労者 |
|---|---|---|
| 在籍 | 日本語学校（在留資格「留学」） | 受入企業（在留資格「特定技能」） |
| 試験 | JOT（日本語オンラインテスト）。留学の要件（JT4以上）として運用中 | JFT-Basic または JLPT N4以上 |
| 接点 | 智翔館が試験会場 | eラーニング教材でトライアル実施済（1社・9名） |
| 課題・出口 | 進学・就職 | 企業の課題は「定着」と「戦力化」 |

- 継ぎ目：留学生が特定技能人材になるとき、必ず N4／JFT-Basic の壁を通る。学校は進路実績、企業は日本語ができる人材、派遣・支援機関は送り出せる人を求めており、その間に立って壁を越えさせる教育を出せるのが智翔館の位置。
- 〔要確認〕JOT・JFT-Basic・JLPT の在留資格ごとの適用関係（根拠がチャットの回答のため、出入国在留管理庁の一次情報で裏取りが必要）。

## 手元のデータ

| データ | 時期 | 件数 | わかること |
|---|---|---|---|
| 留学生アンケート（多言語、翻訳整理版あり） | 2026/06/16〜06/23 | 82名 | 日本語力・進路・困りごと。回答言語 ネパール語57・日本語16・ミャンマー語6・シンハラ語3 |
| 就労者トライアル後のヒアリング | 2026/07/24〜07/26 | 9名 | 教材の評価・継続意向・つまずき |
| 生活支援チャットの実ログ | 2026/06/11〜07/15 | — | 実際の相談内容・言語 |

### 留学生82名の日本語力

| N1 | N3 | N4 | N5 | 未受験 |
|---|---|---|---|---|
| 1 | 8 | 27 | 20 | 26 |

- 特定技能の日本語要件（N4以上相当）を満たす36名（44%）、満たさない46名（56%）。1校だけで N4合格を目標にした学習需要が46名分ある。

### 困りごと・進路

| 内容 | 件数の目安 |
|---|---|
| 漢字が難しい | 20名前後（最多） |
| 職場の日本語（指示・方言・同僚の会話）が分からない | 11名前後 |
| 授業への不満 | 3名 |
| 職場でのいじめ・孤立の訴え | 1名（営業より対応が先） |

- 進路は3層：進学志望（入学金・学費と手続きの不安）、就職志望（そのまま特定技能の候補者）、未定・迷い（いちばん厚く、進路を一緒に描ける相手がいない）。
- 「日本人の友達が欲しい」「日本人と話したい」が複数ある（交流イベントの需要）。

### 就労者トライアル（9名）

| 項目 | 結果 |
|---|---|
| 内容の面白さ・説明の分かりやすさ・有用性 | 9/9 |
| アプリの使いやすさ | 8/9 |
| 継続意向 | 7/9 |

| つまずき | 対策（そのまま製品要件・営業トークになる） |
|---|---|
| 自分の番号でログインできない | 導入初日にスタッフが訪問して全員分のログインを完了させる。訪問をサービスに含める |
| 家にインターネットがない | 企業が業務時間内に週1回の学習枠を設けることを導入条件にする（これ自体が最大の定着施策） |
| 仕事の後は疲れる、週2〜3回がよい | 標準を「週2回×15分」にし、頑張らせない設計と明言する |

### 生活支援チャットから

- 佐世保市・西海市の生活情報（ごみの分別・粗大ごみ、夜間休日の医療、在留カード更新の窓口）が整備済み。
- 給料・人間関係・進学費用の相談が実際に来ている（学習アプリではなく駆け込み寺として使われ始めている）。
- ベトナム語・ミャンマー語・ネパール語に加えトルコ語の質問もある。対応言語は「来たら返せる」形にする。
- 「JOTはどこで受けられますか」に智翔館会場を答えられていなかった（すぐ直す穴）。

## 商品の核：試験の日本語と職場の日本語は別物

- N1保持者でも「同僚の話が聞き取れない」、N3〜N4層では「上司の指示が理解できない」「方言が理解できない」「客と話すのが不安」。
- 企業にとって「N4合格者を採用したのに現場で使えない」の落差が、お金を払う理由になる。
- 売り文句：「長崎・佐世保の現場で実際に飛び交う言葉を教えられるのは、ここだけです」。AWS構成やAI活用より前に出す。
- 「学校別の定期テスト対策を作ってきた地方塾」の実績が、「企業別の現場日本語を作れる」ことの証明になる。

## 商材の階段

| Step | 商材 | 状態 | 中身 |
|---|---|---|---|
| 00 無料 | 多言語アンケートによる現状診断 | 実績あり | 母語で回答 → 翻訳 → 集計 → レポート返却 |
| 01 低単価 | JOT試験の団体受験 | 運用中 | 会場を持っていること自体が接点。留学生ラインの入口 |
| 02 月額 | 日本語eラーニング | トライアル完了 | N4／JFT-Basic 合格という到達点とセットで売る |
| 03 高単価 | TOMONI 定着支援パッケージ | 要件がそろいつつある | 学習進捗の可視化＋生活支援＋相談窓口＋月次の伴走レポート |

## 展開先（2026/08/29時点）

| 区分 | 相手 | 位置づけ | やること |
|---|---|---|---|
| A | 日本語学校（調査実施先） | 最優先・事業の中心 | 82名の集計レポートを返し、進路支援を一緒にやる提案。N4／JOT対策講座、進路ガイダンス、eラーニングの校内導入〔要確認：学校名と関係の深さ〕 |
| B | トライアル実施企業（グローバルクレスト） | 最優先・有償1号 | トライアル報告会で3つの課題と対策をセットで出し、有償プラン（eラーニング＋JOT団体受験＋導入日の訪問＋月1回の事業所内学習会）を提案 |
| C | サンホーム江上 | 最優先・面で広げる | 「外国人材が定着しない」課題が明確。関連団体の定例会への参加打診を受ける。匿名の困りごとレポートと参加各社への無料アンケートを持ち込む |
| D | SocioFuture長崎（外国人材の派遣） | 唯一のチャネル | 紹介を協業として形にする。派遣側の営業がそのまま使える提案書を渡す |
| E | 大島造船所 | 信用づくり | 就労者は数名。売上ではなく造船分野の事例を取る（ほぼ実費導入）。西海市の生活情報入りチャットを見せる。構内協力会社へのつなぎが本命 |
| F | 長崎自動車 | 規模が最大 | 全社一括ではなく1事業所・10名程度のパイロットから〔要確認：対象部門と窓口〕 |
| G | 登録支援機関（未接触） | 実績ができてから | 県内の機関を公表リストから洗い出し、受入企業数の多い上位5社をリスト化 |

企業以外の切り口（1回で複数社・複数人に届く場を優先）

| 切り口 | 着手 |
|---|---|
| 日本語学校経由で在校生にまとめて届ける | すぐ |
| 業界団体・協力会・商工会議所の定例会 | 軽い |
| JOT受験者にその場で学習と進路を案内 | 軽い |

## スケジュール

9〜12月で「実績をつくる」、1〜3月で「刈り取る」。

| 時期 | やること |
|---|---|
| 9月第1週 | いじめ・孤立の訴えへの対応ルートと担当を決める。調査データの restricted 扱いを確定 |
| 9月上旬 | 日本語学校へ集計レポートを返す／トライアル企業へ報告＋有償提案／定例会参加の返答 |
| 9月中 | 営業ツール4点（A4一枚の提案書・留学生82名の匿名レポート・トライアル結果・料金表）。チャットにJOT会場を追加 |
| 9月下旬 | 造船所へ提案 |
| 10月 | 自動車会社へパイロット提案（派遣会社同席）、関連団体の定例会に参加、JOT団体受験の受け皿 |
| 11月 | 派遣会社と協業条件を合意、登録支援機関の上位5社へ、2〜3校目の日本語学校・専門学校へ打診 |
| 12月 | 導入企業の成果を数値化（学習実施率・受験者数・3か月継続率）、自治体の公募を調査 |
| 2027年1月 | TOMONIのスコープ確定（ログイン・ネット環境・学習頻度・職場語と方言・相談窓口） |
| 1〜2月 | 新年度の提案（既存5社＋チャネル経由＋学校） |
| 2月 | 正式な料金表と提案書を確定 |
| 3月 | 次年度の体制（営業・コンテンツ更新・多言語チェックの担当）を決める |

- 最重要の期限：4月入社の受入判断と日本語学校の進路決定は1〜2月に固まる。2027年2月までに実績・料金・資料がそろわなければ次は1年後。

## 取扱注意

- 留学生調査の原本は個人名を含む。restricted 相当で扱い、社外資料には集計値と匿名化した記述だけを載せる。
- いじめ・孤立の訴えは営業データとして扱う前に対応する。

## 要確認（提案書・見積を出す前に必要）

1. 調査を実施した日本語学校の名称と関係の深さ
2. いじめ・孤立の訴えへの確認ルートと担当
3. JOT・JFT-Basic・JLPT の在留資格ごとの適用関係（一次情報）
4. JOTの次回実施日・受験料・会場としての収益構造
5. eラーニングの仕入れ条件（原価・最低契約人数・期間）と自社の販売価格（元資料の月額案は未確定）
6. 定例会の団体名・参加社数・時期・登壇枠
7. 生活支援チャットの運用主体・利用者数・「スタッフに相談」の応答者
8. トライアルで使った教材・コースと企業側の評価
9. 自動車会社の対象部門（運転職／整備職）と窓口
10. 派遣会社との取り決め（紹介手数料の有無）
11. 造船所の就労者の人数・分野・在留資格（特定技能か技能実習か）
12. TOMONIの開発体制と概算費用
13. 佐世保市・西海市の多文化共生／外国人材受入支援の補助・委託事業の有無
