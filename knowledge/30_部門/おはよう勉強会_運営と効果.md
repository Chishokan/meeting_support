# おはよう勉強会 運営ルール・集計方法・効果の見せ方

実施概要・累計・月別・成績との関係・夏の合同開催の結果は `30_部門/振り返り/2026_おはよう勉強会.md` にある。この文書は「どう数えるか・どう回すか・どう見せるか」だけを書く。

## 1. 参加の数え方（2026/10/29 社長報告で統一）

| 項目 | ルール |
|---|---|
| 元データ | リフレクションのGoogleフォーム回答（25年度リフレクション／2026年度の回答／夏休み用の3タブ） |
| 朝だけを数える | 提出時刻が5〜8時台のものだけ。10月から同じフォームに夜の学習会（20〜21時台、10月は159件）が入っているため除外 |
| 参加の単位 | 朝に提出した日を1日。同じ日に2回出しても1日（1人日＝約1時間） |
| 実人数 | 氏名の空白だけをそろえて数える（表記ゆれは寄せない）ため、やや多めに出る |
| 夏の数字 | 名寄せ済みの確定集計と、東彼杵町への実施報告書の値を使う |
| 集中度 | 生徒が毎回入力する0〜100の自己申告 |
| 起点 | 2025年7月（平日朝の通年実施の開始）。前身の夏休み開催（2022年7月〜）は含めない |

- 通常期の日次GAS（下記）は「夜の回答も参加に含める」設定。社長報告の数え方（朝のみ）と違うため、資料に使うときはどちらの数え方かを書く。

## 3. 通常期の日次自動集計（2026/09/14〜）

| 項目 | 内容 |
|---|---|
| 目的 | 校舎責任者・担当講師が参加状況を把握し、声かけに使う |
| 仕組み | Google Apps Script＋スプレッドシート。出力は1ファイル固定・毎朝8時台に上書き |
| 置き場所 | Drive `07_名簿成績出席`（生徒氏名を含むため） |
| KPI | 集計の手作業ゼロ／毎朝8時台に前日までの結果が見られる |

出力シート

| シート | 内容 |
|---|---|
| サマリー | 期間・実施日数・のべ人日・実人数・平均集中度、最新実施日の参加数（前回比）、校舎×日付の参加人数（実人数・皆勤・平均集中度） |
| 出欠名簿 | 全員の出欠を○で表示。各生徒の最新参加日のセルが黄色。毎回値と色を消して書き直す（手で付けた色は翌朝消える） |
| 個票_〇〇校 | 所属ごとの回答一覧（新しい日付が上）。回答に新しい所属が出たら自動で個票シートを追加 |
| _名寄せ | A列＝回答の氏名、B列＝統一する氏名。人が編集する（スクリプトは上書きしない） |
| _ログ | 実行日時・回答件数・除外件数・実施日数・実人数・実行者・新しく作った個票 |

集計ルール

- 対象：2026/09/14以降の回答。所属「一般」は除外（除外件数はサマリーに表示）。
- 実施日：回答が1件以上ある日だけを日付列にする。
- 所属：各生徒のいちばん新しい回答の所属で判定（所属を変えた生徒は過去の回答も新しい所属へ移る）。夏期版の「初回で固定」とは違う。
- 所属の並び：佐世保駅前校／日野校／大野校／日宇校／県中対策。「県立中対策」は「県中対策」として集計。
- 氏名：全角・半角の空白を除いて同一人物とみなす。それ以外の表記ゆれは `_名寄せ` に登録。
- 同じ日の複数回答は1日。夜の回答も参加に含める。
- 設定（開始日・除外校舎・更新時刻・色）はコード冒頭の `CONFIG` で変更。

よくあるつまずき

| 症状 | 対処 |
|---|---|
| 同じ生徒が2行に分かれる | `_名寄せ` に「表記ゆれ → 統一氏名」を追加し、メニュー「おは勉集計 → 今すぐ更新」 |
| 更新されない・権限エラー | トリガー設定者が元シート（別アカウント所有）の閲覧権限を失った。共有を依頼して自動更新を設定し直す |
| 元シートが見つからない | 元ファイルのシート名変更。`CONFIG` のシート名を直す |
| 夜の回答が当日反映されない | 更新は毎朝8時台のみ。急ぐときは「今すぐ更新」 |
| コードを直した | Apps Scriptに全文を貼り直して保存（トリガーの再設定は不要） |

- 〔要確認〕毎日のトリガーが作成されているか（2026/09/14時点で要確認と記載）。

## 4. 夏期の所属別集計（他塾・自治体と合同のとき）

- 夏期は参加者の所属欄が日によって変わる人がいるため、所属は初出時の申告で固定する。
- 2026年夏まで、所属別レポートを手作業で毎回作り直し、日付違いのファイルが27件重複していた。GAS化で「出力1ファイルを毎回上書き・名前に日付を入れない」を必須にした（2026/08/24 引き継ぎ書）。
- 名寄せ表は専用シートに持たせ、コードに直書きしない。シート名・列位置はコード冒頭の定数に集める。出力先の共有範囲を毎回確認する（生徒氏名を含む）。
- 春休みのフォームには所属欄がなく、外部塾生が氏名欄に塾名を書いていた。これが名寄せが必要になった原因。次回の合同開催では所属欄を必須にする。
- 実人数は集計の仕方で大きく変わる（2026年夏：空白違いを別人扱い238名、名寄せ後204名、さらに除外処理後201名）。対外資料の正の決め方は `30_部門/地域連携・外部実施.md`。

## 5. 効果を資料に載せるときの注意（必ず守る）

- 8月模試（中3）で参加者と非参加者を比べると、参加者の平均偏差値54.7・非参加49.4、偏差値55以上59%・30%、公立第1志望A・B判定90%・77%。ただし参加者は参加前から偏差値が約5高い。「おは勉で偏差値が5上がった」とは書かない。
- 7月→8月で偏差値が上がった参加者93%は、非参加者も91%上がっている（8月は全体が上がる回）。比較表に入れず単独で使う。
- 平均点の差は参考（8月は塾全体でも平均+42点）。
- 7月偏差値45〜50の層では、参加者13名全員が偏差値アップ（伸び+7.5、非参加+4.4）。
- 2025年8月模試：参加者の5教科平均299.1点、智翔館塾生277.9点、受験者全体252.4点。参加者の対象・人数は資料に記載がない〔要確認〕。もともと成績が上の生徒が多く参加している影響は除けていない。
- 10月の県一斉模試（10/18）での同じ比較は未集計（10/29時点）。
- 保護者の声は2025年11月・日野校28世帯分しかない（2026年は未実施）。「家で声かけする負担が減った」18%、友人に勧めたいか（0〜10）平均7.1。課題として出た声：部活・夜練との両立と睡眠不足、登校日はその後が慌ただしい、起きられない日の声かけ。
- 生徒の声を載せるときは学年と時期だけを書く（氏名なし）。
- 資料のフッターに「社外秘｜時点（集計条件）」を入れる。

## 6. 報告の型（2026/10 社長報告）

- 依頼：開始からの状況・夏休みの開催報告・生徒保護者の声をスライド2枚に。最終版は3枚（表紙に職員向けの説明と報告の内容を追加）。
- 並び順：①開始からの状況 → ②生徒の声 → ③保護者の声 → ④通知表 → ⑤成績アップ → ⑥夏休みの実施報告。
- 残った判断：前年比−48%をスライドに載せるか〔要確認〕。
- スライドの作りは `35_広報・制作/スライド制作/21_制作実例_追記.md`。
