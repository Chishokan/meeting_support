# 地域連携・外部実施の型

2026年夏休みのおはよう勉強会（7/27〜8/28）を他塾・自治体と合同で開いたときの「報告の型」と「数値の決め方」。全体の結果は `30_部門/振り返り/2026_おはよう勉強会.md` にある。

- 参加塾（連携学習塾）は各塾との取り決めで名称と個別の実績を公表しない。このナレッジでも塾名を書かない。
- 位置づけ：おはよう勉強会（他塾・自治体）対応フローの⑧最終報告。

事業全体報告書（塾別送付版）の章立て

1. 事業概要 2. 全体の参加状況 3. 日別 4. 参加日数と学年 5. 自己評価と学習内容 6. 貴塾の参加状況 7. リフレクション抜粋 8. 全体所感 9. 集計上の注記 10. 連絡先

- リフレクションの引用は「学年・日付・自己評価点」で表記。用語は「ふりかえり」ではなく「リフレクション」に統一。
- 報告書はPythonの生成スクリプトで作り、担当者がWordで手直しした点はスクリプトに取り込んで再生成する。

## 2. 数値の正の決め方

同じ事業でも集計の条件で数値が変わる。受け取る側が突き合わせるので、送付物どうしの不一致は許されない。

| 条件 | 実人数 | のべ | 平均自己評価 | 使う場面 |
|---|---|---|---|---|
| 元データのサマリー表示（名寄せ前） | 238名 | 1,569件 | 88.3 | 使わない（社内の参考） |
| 名寄せ後（除外処理なし） | 204名 | 1,569件 | 88.3 | 東彼杵事例版・協賛版の初版（9/2）で使用。のちに201名へ統一 |
| 名寄せ＋除外（集計モジュール） | 201名 | 1,554件 | 88.5 | 参加塾向け・全体レポート・協賛版v4以降の正 |
| 東彼杵町（町設定の20日間） | 19名 | 163件 | 89.6 | 町への報告 |
| 東彼杵町（全22日間） | 20名 | 166件 | — | 全体レポートの東彼杵の行（注記で差に触れた） |

- 正は参加塾案件の集計モジュール（201名・1,554件・88.5点・皆勤7名）。他の報告書を作り直すときはこのモジュールを使って数値をそろえる。
- 〔要確認〕集計モジュールにも名寄せ漏れが1件あり（東彼杵町の同一生徒が表記違いで2名扱い）。正しくは全体200名。修正するとすべての送付物の数値が変わるため、修正するかは判断待ち（2026/09/11時点）。
- 既存の振り返りに出てくる「224名」（9/3簡易レポート、期間7/28〜8/28）も別条件の値。

### 集計期間

- 全体は7/27〜8/28の実施22日（8/11・8/13〜16は実施なし）。
- 東彼杵町は町の開催日20日間（7/27〜31・8/3〜7・8/17〜21・8/24〜28）。智翔館の単独開催8/10・8/12は除く。

### 名寄せ・除外

- 名寄せは学年・学校名が一致する表記ゆれだけを統合する。学年・学校が違う同姓は統合しない。
- 全角・半角・空白、括弧書きのローマ字併記を除いて照合する。
- 塾の先生ご自身の参加（14件）は生徒数・のべ件数から分けて注記する。
- 氏名欄に学習内容が入った誤入力（1件）は人数から除外し、報告書に注記する。
- 学年・学校名は、その生徒が最も多く申告した表記を採用する。学校名の表記は1つに統一する（例：町内中学校の4通りの書き方を正式名称に統一）。
- 学習内容の分類は、1回の記載に複数科目があれば最初の科目で計上。科目名がない回だけ「その他・自主学習」。速報版と確定版で分類ルールを変えたため順位が入れ替わった。ルールは最初に決めて固定する。

## 3. 匿名化・掲載のルール

- 連携塾の名称は出さず「連携学習塾（町外・9団体）」の区分表記にする。塾別送付版でも、宛先の塾名だけを第6章で明示する。
- 全体レポートは団体名・学校名・生徒氏名を一切書かない。所属は匿名記号。
- 協賛事業者向けには、個人情報を含む別紙（参加者別一覧）を添付しない。
- 実人数1名だけの区分は平均点から個人が特定されうるため「その他」に合算する。
- 協賛メリットの履行実績（ロゴ掲載・協賛金の使途など）は別途報告とし、この報告書には載せない。
- 社名の掲載は、実物を確認した結果、どの媒体もロゴではなく社名のテキスト掲載で、全協賛先が全媒体に載っていた。報告書には実物の画像を「掲載実例」として載せた。
- 〔要確認〕協賛事業者の正式名称の一覧（町への報告書と実物の掲載一覧で1社の差があった）。確定するまで協賛一覧は載せない。

## 4. 東彼杵町の結果（補足、確定値）

振り返りファイルにない数値だけ。

| 指標 | 値 |
|---|---|
| 1日平均 | 8.2名 |
| 1人あたり平均参加日数 | 8.5日（中央値8日・最多18日・皆勤0名） |
| 10日以上参加 | 8名（42.1%） |
| 平均自己評価 | 89.6点（全所属の同期間88.2点を上回る） |
| 終盤の参加 | 8/27・8/28は各2名。町内の小中学校の2学期開始（8/26）と定期テスト期間が重なったため。全所属でも8/27は期間中最少の38件 |

全体（22日間、名寄せ後204名ベース）の補足

- 学習内容（1,569件）：算数・数学387／国語293／英語259／社会195／理科173／作文46／その他216。
- 自己評価：前期86.3（848件）→ お盆期89.9（99件）→ 後期90.6（622件）。最終日8/28は95.6点で期間中最高。
- 参加区分：連携学習塾121名・東彼杵町19名・当社在籍62名・その他2名（9/12実施報告の117・20・62・2とは条件が違う）。
- 塾別送付版を出した5塾では、前半→後半の自己評価がすべて上がった（+1.0〜+15.0。+15.0は13区分中で最大）。

## 5. 次回に向けた課題

| 課題 | 打ち手・確認事項 |
|---|---|
| 東彼杵町は募集100名に対し19名 | 学校を通じた周知。2学期開始後の時間帯（30分参加・7時台の回など） |
| 町側の申込者数が手元にない | 町教委が保有。参加率の算出に必要〔要確認〕 |
| 修了証の発行基準（参加日数の閾値） | 未確定〔要確認〕 |
| 各塾のご担当者のメールアドレスが未取得 | 申込の段階で送付先を取っておく |
| 単発参加の団体・学校の扱い（各1名） | 個人申込の可能性。報告書の対象にするか事前に決める |
| 正式名称の確認 | 参加団体・協賛事業者の正式名称を申込時に確定させる |
| 所属欄の表記ゆれ | 申込・リフレクションのフォームで所属を選択式にする |
