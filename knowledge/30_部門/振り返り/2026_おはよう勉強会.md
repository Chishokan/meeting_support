# おはよう勉強会の振り返り

## 概要

| 項目 | 内容 |
|---|---|
| 時間 | 平日の朝 6:00〜7:00（5:55入室）。2025年7月から通年で実施 |
| 方法 | Zoom で自宅から参加（カメラON、チャットで出席確認） |
| 参加条件 | 「自分の力で起きること」 |
| やること | 学習内容は生徒が自分で決める。開始前に目標をチャットで送り、終了後にリフレクション（できたこと・集中度・感想）を提出。先生が承認・コメント |
| ねらい | 学習習慣と勉強体力をつけ、自分で学べる生徒に育てる |
| 対象 | 智翔館の小中学生。夏休みなどは他塾・自治体と合同で開催 |
| 運営（夏） | メイン進行1名・サブ1名（入室管理、出席確認、リフレクション回収） |

- 開始時刻：2025年7月〜2026年8月の簡易レポート（2026/09/03作成）は「朝6時30分開始」と記載。2026年夏の実施報告と10/29報告スライドは6:00〜7:00。〔要確認：通年運用の開始時刻が途中で変わったか〕
- 10/31研修会でチャレンジ発表②として報告（太田暁）。表彰の有無は〔要確認〕。

### 東彼杵町との共催（初）

- 町内23事業者の協賛により町内の参加は無料。
- 町内参加19名（小8・中11）、10日以上参加8名、集中度87.9→92.2（8/31提出の町への実施報告書）。
- 課題：募集100名に対し参加19名。学校経由の周知と時間帯の見直しが必要。

## うまくいったこと

- 夏の1日平均が前年の約2.5倍。他塾・自治体との合同開催で規模が広がった。
- 続けるほど集中度が上がる（夏の前期86.5→後期91.1、2学期は95.2）。
- 20回以上参加した生徒は全員が通知表を維持以上。
- 日野校で、参加予定を前に映して生徒に自分事として捉えさせ、全員で声をかけた結果、自学者・参加者が増えた（9月月次報告）。

## うまくいかなかったことと原因

| 事象 | 原因・考察 |
|---|---|
| 2学期ののべ参加が前年比−48%（中3は97→48名） | 日野校66→35名、大野校29→9名の減少が大きい。〔要確認：原因の分析。声かけの実施率が把握できていないとの指摘あり（9/30協議）〕 |
| 夏の参加が1〜4日の層が最多（84名） | 初回参加から継続への接続ができていない |
| 東彼杵町は募集100名に対し19名 | 学校経由の周知不足、時間帯 |
| 2026年の保護者アンケート未実施 | 成果の根拠が2025年11月の日野校28世帯分のみ |
