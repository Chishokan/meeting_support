# 2026年 夏期講習の振り返り

## 概要

- 対象：小中等部5（日野・県中対策・佐世保駅前・日宇・大野）、RED個別7（日野・佐々・西海大島・大野・京町・ネクスタ・広田）、高等部2（佐世保駅前・大野）の14校舎・教室。
- 出典：夏期報告19件（2026/09/02〜09/07投稿）、数値入力スプレッドシート、中等部の夏期講習アンケート。2026/09/10の全体会議で扱った。

## うまくいったこと

- RED個別は申込116%・生徒数121%で全体を支えた。京町190%・大野150%。
- 継続率の高い校舎：日野校86%（昨年の継続5→12）、ネクスタ100%、広田80%（昨年76%）。
- 高等部は申込が昨年の1.7倍（11→19）、継続も6→11。8月模試の一般生72名。
- 県中対策の6年夏期合宿で史上初の全員目標達成（300問暗記）。オンラインクラスは最大17名で史上最大。
- 学校の宿題：小中等部はほぼ完了（日野校100%、駅前校90〜95%、大野校95〜100%、日宇校・県中は完了）。

## うまくいかなかったことと原因

| 事象 | 原因（報告から読み取れること） |
|---|---|
| 小中等部は5校舎すべて目標未達（申込68／95） | 募集施策が電話がけに寄っている（県中「リスト生への電話がけのみで、他の施策が必要」）。日野校は授業にフルで入り電話の時間がない。駅前校は門配の雨天振替が未計画、生徒の友人紹介の申込率が低い |
| 継続率に3倍の開き（日野86% ↔ 日宇27%・大野29%） | 駅前校・大野校は継続の事前計画ができていなかった（実践度合い10%）。両校とも責任者が兼務。日宇校は継続面談が申込11に対し3件 |
| 生徒数の減少：大野校72%・県中84% | 大野校は継続2名。県中は小6の非継続（習いごと等で非継続がほぼ決まっていた7名） |
| 高等部の募集（63%） | 計画の遅さと役割分担・指示不足、校門配布の急な実施、ロゴティッシュを生かせなかった |
| 人員体制が4部門で詰まっている | 高等部はスタッフ2名減で一人運営日、1階受付が無人。RED大野教室も1階が無人。京町教室は本部に日程を合わせた結果の講師不足。ネクスタは引き締め役が必要。日野校は中1の昼間対応が担当者不足で実施できず |
| 広田教室の成績目標の取り組みがない（0%） | 事前に取り決めを決めていなかった |
| 学校の宿題が「未把握」 | RED日野・佐々・広田、高等部駅前校で把握の運用がない |
| 通知表回収が未完了 | 高等部駅前校あと38名、RED佐々5・日野4・西海大島4・京町1、小中大野1（9月初時点） |

## 中等部の夏期講習アンケート（集計値、2026/09/01集計）

回答：中1・中2 69名、中3 80名。

| 教科 | 中1・中2 平均 | 中3 平均 |
|---|---|---|
| 国語 | 78.7（60点未満14.9%） | 85.0 |
| 英語 | 85.3 | 89.8 |
| 数学 | 88.9 | 94.0 |
| 社会 | 86.8（特訓会） | 87.8（60点未満8.8%） |
| 理科 | 88.7（特訓会） | 88.6 |
| 5教科平均 | 85.6 | 89.0 |
| 目標達成率 平均 | 84.7（80%未満 26.1%） | 87.6（80%未満 11.2%） |

主な発見

- 中1・中2の国語だけが構造的に低い。原因は講習会の設計（国語は14回中4回、理社は特訓会のみ。中3は5教科×14回）で、指導力ではないとの分析。
- 中1・中2の校舎間差15.3ポイント（大野91.4、駅前89.0、日野84.3、日宇76.1）。日宇校は国語61.6、英語75.5、理科78.5と全項目最下位。中3の主要3校舎の差は1.6ポイント以内。
- 中3の配信授業への不満6名は全員日野校（31名中19%）。配信そのものより通信環境・受信側の運用の問題。
- 中3の大野校の社会に低評価層（60点未満7名のうち5名）。
- 中3は満足度と達成感の相関が弱い（r=0.272）。授業満足度で安心せず、模試結果と突き合わせる必要。
- 中3の志望校未記入23名（28.8%）。設問が「志望校、将来の夢・志」の一括のため設問の改訂も必要。
- 2学期への要望：中1・中2「演習量・小テストを増やす」9件、中3「演習・小テスト・宿題を増やす」6件、「習熟度別・苦手対応」6件、「対面授業を増やす」5件、「質問の時間」4件。「減らしてほしい」は0件。

## 次回（冬期）に向けた運営上の注意

- 日程は講師の稼働状況に合わせて組む（京町教室の反省）。
- 門配の雨天時振替を天気予報をもとに事前に組む（駅前校・大野校）。
- 提案面談は模試結果を踏まえて再度行う。コマ決めは早い段階で8割まで仕上げ、保護者への訂正連絡を減らす（ネクスタ）。
- 配信授業は中継先の先生と事前打ち合わせ、席割り表の事前入手（配信担当の振り返り）。休み時間のスマホは入口で預かる等の工夫。
- 報告様式：必須入力項目、通知表回収の単位（％か残り人数か）、未集計時の書き方を統一する。
- 冬期アンケートは追跡のため氏名必須（同一生徒の前後比較）。
