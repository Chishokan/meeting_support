# 教務運営のルールと手順

Drive `chishokan/library/14_教務運営/`（2023・2024・2025・2026）の資料から、授業運営・教務のルールを要約した。
- 生徒名簿・成績・出席の個票は開いていない（1件、ファイル名から判断できず開いたものは内容を使っていない。末尾「外した資料」）。
- ログインURL・ID・パスワード・ZoomのIDは書かない。必要な人は校舎責任者かシステム担当に聞く。
- 対象部門が資料に書かれていないものは〔要確認〕とした。

## 1. 面談予約システム（保護者面談の予約）

Google のスプレッドシートとWebアプリで作った予約システム。保護者が予約画面から面談を予約し、職員は管理画面で枠と予約を管理する。智翔館とNEP部門で別の管理画面がある。

### できること

- 予約枠の登録・編集・削除
- 保護者の予約の確認、日時変更、キャンセル
- 予約ごとの職員メモ（担当者・準備物・申し送り）
- 校舎の切り替え（上部の校舎セレクタ。最後に選んだ校舎を覚える）

### 使い方の要点

| 場面 | 操作 |
|---|---|
| 枠をまとめて登録 | 「枠の管理」→「期間指定で選択式追加」で開始日・終了日→「表示する」→使う枠をクリック（全選択／平日のみ／土日のみも可）→「選択した枠を追加」 |
| 単発の枠 | 「個別に1件追加」で日付・時刻・ラベル |
| 枠を隠す | 「登録済みの枠」で「非公開」にする（保護者画面から消える） |
| 2人体制の時間 | 「定員」のスイッチで1名⇄2名（V3で追加）。2名にすると2家族まで予約できる。新しく追加した枠は必ず定員1名から |
| 予約を探す | 「予約一覧」で期間（本日／今週／今月／これから／全期間）、状態、お子様名・保護者名・メールで検索 |
| 職員メモ | 予約カードの黄色の欄に書いて「保存」（欄から離れても自動保存）。保護者の画面には出ない |
| 日時変更・キャンセル | 予約カードの「詳細」から |

- 枠の標準時間帯：平日（月〜金）13:00〜21:30、土日 10:00〜18:30。いずれも30分刻み18枠。
- 当日1時間以内の枠は保護者画面に出ない。
- 予約済みの枠は削除できない。先に予約をキャンセルしてから枠を消す。定員2名で2件入っている枠は1名に戻せない。

### 保護者からの連絡

- 保護者は予約画面で変更・キャンセルができない（「変更・キャンセルは校舎へお電話」と案内している）。電話を受けた職員が管理画面で直す。
- **キャンセル・日時変更をしても保護者への自動通知はない。** 必ず電話などで連絡する。

### 守ること

- 管理画面のURL・ID・パスワードを保護者に教えない。
- 予約データ（保護者名・お子様名・メールアドレス・職員メモ）は個人情報。
- スプレッドシートを直接編集できるが、できるだけ画面から操作する。
- 〔要確認〕職員用マニュアルのPDFに管理画面のURLとログイン情報が平文で書かれている。共有範囲の確認とパスワード変更を推奨。

## 2. 時間割の確認と代講

出典：時間割マニュアル〜新人講師用〜。

- 時間割は「生徒の席の準備ができている」という**基本サービス**（お客様に提供する最低限のサービス）を守り、授業を滞りなく行うための計画表。

### 確認すること

| いつ | やること |
|---|---|
| 新しい時間割がLINEで届いたとき | 月全体の自分の授業を確認し、LINEで「確認しました」と返す。入れない日があればすぐ時間割担当者に連絡 |
| 希望休を出した日 | 自分の欄に授業が入っていないか確認 |
| シフトの前日 | 出勤時間のミスを防ぐため、もう一度確認 |
| 授業の前 | その生徒の教科を確認 |

- 時間割ファイルは週ごとのタブに分かれている。必ず該当の週・日付を見る。最新版を見る（変更されていることがある）。
- 遅刻するときは「何時に着くか」を連絡する。

### 代講の探し方（時間割の確定後に入れなくなったとき）

体調不良・身内の不幸などのときは、自分で代講を探す。

1. セルが水色で空きがある先生
2. セルが灰色で空きがある先生
3. 希望休の先生（必ず先生全員に確認する）

見つかったら全体LINEに「○日の○限の授業を○○先生に代講していただきます」と送る。時間割担当者が時間割を直して再送するので、その後も変更を確認する。

### シフトの考え方

- 貢献度の高い先生が優先して授業を持つ。貢献度が高い先生＝生徒の成績を上げている、研修に積極的に参加している、代講に入ってくれる、校舎の改善に努めている。

## 3. 自習対応

出典：自習対応マニュアル。

| 項目 | ルール |
|---|---|
| 始める前 | 「科目」と「自学内容」を決めてから自習させる |
| 時間 | 授業がある17:30〜21:50。平日のみ（土日祝は不可） |
| 飲食 | 休み時間のみ。自習中は飲食物を机に置かせない |
| 外出 | 「どこへ行くか」「何時に帰ってくるか」を確認する |
| 携帯電話 | 自習を始める前にボックスに入れさせる |
| 記録 | 自習時間と自習内容を記録用紙に書かせる（事務机にある） |

### 判断に迷ったとき

- 自分で判断できないことは、すぐ社員の先生か「ユースの先生」〔要確認：呼び方の意味〕に報告する。
- 例：勤務時間外に生徒から質問され、20分解説した。
  - 社員がいる → 報告して指示を仰ぐ。
  - 社員がいない → 社員に電話して指示を仰ぐ（優先）。出なければ、対応した時間と内容をその日のうちに LINE WORKS などで事後報告。
- 授業以外で勉強の仕方を指導することが生徒のためになる場合も、社員に報告する。

## 4. 個別指導の授業の進め方

出典：指導マニュアル 通常用、1対2の進行。テキストの構成（Key Words・Point!・Warm Up・Try・Exercise・クリアテスト）に沿った進め方〔要確認：使っているテキスト名と対象部門〕。

### 4-1. 通常の授業（1コマ45分の配分）

| 英語 | 時間 | 数学 | 時間 |
|---|---|---|---|
| コミュニケーション（会話、宿題確認、学校の進度、クリアテスト） | 10分 | コミュニケーション（会話、学校の進度、宿題確認＝丸つけ・赤×まで、クリアテスト） | 10分 |
| Key Words（先生が発音→生徒が1語2回。単語→意味を口頭テスト） | 5分 | Point!（短く速く説明。☺マークで赤字を言わせる。できたらほめる） | 5分 |
| Point!（同上） | 5分 | Warm Up（先生が書きながら解いて見せる。「よくあるまちがい」も説明） | 10分 |
| Warm Up（答えは生徒に言わせ、語句選択以外は紙に書いて見せる） | 5分 | Try（間違えた番号に×→解説） | 20分 |
| Try（間違えた番号に×→解説） | 15分 | — | — |
| Key phrases（先生が読む→①②③で区切って生徒が読む→もう一度） | 5分 | — | — |

宿題
- 英語：Try の×直し、Exercise（丸つけ・番号に×まで）、Key Words の日本語→英語書き、Key Phrases の黒字→赤字書き。
- 数学：Try の×直し、Exercise（丸つけ・番号に×まで）。

### 4-2. 1対2の進め方（例：英語と数学）

2人の生徒の作業を交互に進め、片方が解いている間にもう片方を説明する。

| 順 | 英語 | 数学 |
|---|---|---|
| 1〜2 | コミュニケーション → Key words | コミュニケーション → CT（クリアテスト） |
| 3〜4 | Key words テスト → CT | CT丸付け → Point → Warm up → Try |
| 5〜6 | CT丸付け → Point → Warm up → Try | Try解説 → Point → Warm up → Try |
| 7〜8 | Try解説 → Key phrases → Key words | Try解説 → 宿題 |
| 9 | Key words テスト → 宿題 | — |

苦手な生徒には
- Warm up(1) → Try① → Warm up(2) → Try② のように小分けにする。
- 爆弾マークの高難度問題はとばす。
- 宿題（Exercise）は正答率が比較的高い部分から出し、極端に低い所はあまり出さない。

### 4-3. テスト前の仕上げ（英語・数学とも同じ流れ）

| 残り回数 | やること |
|---|---|
| 残り3回 | 通常授業＋通常の宿題。追加宿題：テスト範囲のクリアテスト（直接書き込む）、テスト範囲の Key words Test の暗記（英語は赤シートでチェック） |
| 残り2回 | ①テスト範囲全部の Key words テスト ②クリアテストで2問以上間違えた単元を Point・Warm up からやり直し、Try を解かせる ③Try の×を解説 ④宿題：Key words Test の暗記、やり直した単元の Try の×直しと Exercise |
| 残り1回 | ①Key words テスト（2回目） ②クリアテストで2問以上間違えた単元の再指導 ③テスト範囲全部の×直し |
| テスト後 | 次の授業日にテストの問題・解答を持ってくるよう伝える |

- REDの「仕上がった率」（テスト前の予習とチェックテストの完了率）・「増コマ」は `00_index/GLOSSARY.md`。

## 5. オンライン授業（Zoom）の進め方

出典：オンライン授業マニュアル（4/22版→5/14改定→9/03改定。ファイル名は「0904改定」）。教室の生徒とオンラインの生徒が同時に受ける授業を想定。

| タイミング | やること |
|---|---|
| 前日まで | 翌日実際に使う教室・PCで接続テスト。新規生の接続テスト（できれば実際の教室・PCで）。新規生がテキストを持っているか確認し、ない生徒には授業範囲のコピーを渡す。ミーティングには自分の氏名で参加するよう伝える。当日の遅刻・欠席を確認 |
| 開始10分前 | Zoomを立ち上げてミーティング開始。参加の承認（随時）、出欠確認、出席簿記入 |
| 開始5分前 | テキストの準備確認（カメラに映してもらう）。学校の進度確認。宿題確認（教室の生徒は直接、オンライン生は順に声をかけて画面で）。音声確認、先生の画面をスポットライトに固定 |
| 授業開始 | あいさつ。生徒全員ミュート（人数や雰囲気でミュートなしも可）。今日の進度予定をホワイトボードに |
| 宿題解説 | 事前に確認した間違いの多い箇所を解説→理解できたか挙手。この時点で欠席連絡担当に出席簿を渡し、欠席者に電話 |
| 導入 | 分からない生徒に挙手させ、ミュートを外して聞き取り→全体に補足説明 |
| 演習 | 質問はカメラに向かって挙手→ミュートを外して聞き、ヒントか飛ばす指示。終わった生徒は挙手してテキストを画面でチェック。全問正解なら次の指示、間違いはやり直し |
| 解説 | ホワイトボードに解答。〇×と正解の記入を指示。「〇問中〇問正解」を挙手させ、声をかける |
| 次回の宿題 | ホワイトボードに書く。進行表に記入 |
| 終了 | 続けて授業がある生徒は接続したまま一括ミュート。ない生徒はあいさつして退室。クラス分けしている場合は次回の時間帯とIDを確認。最後は先生がミーティングを終了 |

- **時間配分が重要**：無料アカウントでは開始40分でいったん切れる。演習の途中で切れるように組む（例：演習10分なら切れる5分前に開始、残り5分で再入室対応）。切れる10分前・5分前に告知し、切れたらすぐ入り直させて入室を許可する。
- 〔要確認〕今も無料アカウントで運用しているか。

## 6. 中等部の紹介特典制度

出典：中等部 紹介特典制度 運用マニュアル（修正版、2026年度フォルダ）。紹介を重視する方針（`10_理念・方針/COMPANY.md`「募集に対する考え方」）を具体化した制度。

### 制度の中身

| 項目 | 内容 |
|---|---|
| 特典 | 中等部の塾生が友人・知人を紹介し、対象の申込があれば、紹介者に Amazonギフトカード3,000円分 |
| 対象になる申込 | ①紹介された生徒の新規入塾 ②紹介された生徒の講習会申込 |
| 紹介者（塾生） | 紹介が成立するたびに何度でも受け取れる（1名紹介ごとに3,000円分） |
| 紹介された外部生 | **1名につき1回だけ**。講習会・入塾を問わず、一度特典の対象になったら以後は対象外 |

対象外の例
- 春期講習を紹介で申込→その後入塾：特典は1回だけ。
- 春期講習を紹介で申込（入塾せず）→夏期講習も紹介で申込：2回目は対象外。
- 夏期講習を紹介で申込→冬期講習を別の塾生から紹介：その外部生は対象済みなので対象外。

### 職員の手順

| STEP | やること | 期限 |
|---|---|---|
| 1 | 職員が塾生に紹介を依頼する | — |
| 2 | 申込時に紹介者名を入れてもらう（入塾＝入会フォーム、講習会＝講習会申込フォーム） | — |
| 3 | 職員が「紹介特典カード管理フォーム」に入力：紹介してくれた塾生名、紹介された生徒名、紹介特典カードのコード番号。**同じ外部生が過去に対象になっていないか確認** | STEP2から3日以内 |
| 4 | 職員が塾生に紹介カードを渡す | — |
| 5 | 保護者がカードのQRを読み取り、必要事項を入力 | カード配布から1か月以内 |

- QR入力の期限を過ぎたら入力は無効。保護者に自動メールで期限切れを知らせる。特別な事情があるときは、校舎責任者とNEPが相談して対応する。
- 注意：STEP2〜3は必ず3日以内。カードのコード番号の入力ミスを防ぐ。同じ外部生への重複付与に注意。
- 〔要確認〕講習会要項にある「塾生紹介割」（例：中3冬期講習で一般生は早割と同じ金額）との関係（併用できるか）。
- 〔要確認〕RED個別・県中・高等部に同様の制度があるか。

## 7. 検定（英検・漢検）2026年度の日程

出典：2026年度検定日程（2026/3/5更新）。智翔館で受検する場合の日程。

| 回 | 検定 | 申込締切 | 1次 | 2次 |
|---|---|---|---|---|
| 第1回 | 英検 | 4/17（金） | 5/24（日） | 7/12（日） |
| 第1回 | 漢検 | 5/8（金） | 6/27（土） | — |
| 第2回 | 英検 | 8/25（火） | 10/4（日） | 11/15（日） |
| 第2回 | 漢検 | 9/10（木） | 10/24（土） | — |
| 第3回 | 英検 | 12/1（火） | 1/24（日） | 3/7（日） |
| 第3回 | 漢検 | 実施なし | — | — |
