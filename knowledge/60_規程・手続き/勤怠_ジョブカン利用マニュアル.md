# ジョブカン利用マニュアル（勤怠・シフト・入社手続き）

2024年11月15日改訂版を、2026年11月13日に取り込んだ。その後の変更（諸変更届の LINE WORKS での申請への切り替えなど）は総務に確認する。就業規則での遅刻・早退・欠勤の決まりは `60_規程・手続き/就業規則/00_使い方.md` から。

> 出典：智翔館「ジョブカン利用マニュアル」（PDF・デジタル原本から取り込み）
> 責任者：智翔館総務 直江(英)／作成 2021.4.10／改訂 2021.9.17・2022.4.15・2024.11.15
> 対象：智翔館スタッフ（社員・職員）

智翔館では勤怠管理に「ジョブカン」を使用します。本マニュアルは勤怠（打刻・遅刻早退・欠勤・シフト・諸変更届）と入社時の情報提出（マイナンバー・扶養控除等申告書）の手順をまとめたものです。

---

## ★ よく使う重要ルール（先に確認）
- **シフト申請の締切**：翌月のシフトは『**前月20日までに申請**』。**25日にジョブカンへ反映・確定**されます。
- **打刻修正（打刻漏れ）の申請期限**：**発生日の翌日中**。期限を過ぎると修正できません。
- **遅刻・早退・欠勤の連絡先**：確定した時点で**ラインワークス（LINE WORKS）で【総務 直江】へ報告**。同時に教室運営に入る同僚・関係者にも連絡。
- **諸変更届**（住所・家族・通勤方法など変更時）：速やかに記入し【総務 直江】へ。

## 1. 勤怠

### ① ジョブカン登録・アプリインストール
- 入社時にジョブカンの登録・設定・アプリインストールを行います。
- スタッフ登録完了と同時に、共通IDの招待メールが届きます（件名「〇〇さん専用のモバイルマイページログインURL・パスワード」、送信元 noreply@donuts.ne.jp）。
- メール記載のURLからパスワードを設定してください。**URLの有効期限は送信日時から7日間**。
- パスワードは他人に教えず、セキュリティ確保のため各自で再設定してください。
- ログインページURL：`https://ssl.jobcan.jp/login/mb-employee`（モバイルマイページは全利用者で共通）。

**アプリインストール（Android）**
1. モバイルマイページにアクセスしログイン。トップでなければ上部「ジョブカン」の文字をタップしてトップへ。
2. ブラウザの「…」メニューを開く、または「ホーム画面にJOBCANを追加」のポップアップをタップ。
3. メニューから「アプリをインストール」を選択 → 「インストール」をタップ。
4. 完了後、ホーム画面にアプリアイコンが表示されます。

**アプリインストール（iPhone）**
- モバイルマイページにログイン後、マイページをホーム画面に追加することでアプリ化できます（2023年2月以前に追加済みでも、改めて操作が必要）。
1. モバイルマイページにアクセスしログイン。
2. ブラウザの共有ボタンをタップ。
3. 共有メニューから「ホーム画面に追加」を選択。
4. ホーム画面にアプリアイコンが表示されます。
- ※ホーム画面への追加は、ログインページではなく必ず**ログイン後のマイページ画面**で行うこと。
- ※**ログイン後30分間操作が無いと自動ログアウト**します。

### ② 出勤 ③ 退勤
1. ジョブカンで打刻することで出退勤を管理します。
2. 出勤・退勤は**校舎の出勤用PCでIDを入力**して行います。
3. **校舎移動の際は、移動の都度、出勤・退勤**を行ってください。
4. 出張・外勤の際は**GPS打刻**。その場合は**管理者の承認**で出勤となります。
- 出退勤用PCは生徒の登下校用PCと共用の校舎もあるため、使ったら元に戻すこと。

### ④ 打刻漏れ
- 打刻漏れが発生した場合は、自分の携帯から申請します。
  - 操作：ジョブカンにログイン ＞ トップ画面 ＞「打刻漏れ・打刻間違い」＞ 該当の打刻詳細 ＞「修正」
- 手順：
  1. 「修正」＞ 時刻を入力 ＞ **校舎を選ぶ**（必ず該当する **【打刻】●●●校** を選択。それ以外を選ぶと承認してもエラーになる）＞ 打刻漏れの旨を記入。
  2. **備考欄に必ず申請理由を入力**。理由が無いと却下となり再申請が必要。
- 時刻入力の補足：前日付にする場合は先頭に「*」を付ける（例：9時5分＝0905、深夜2時13分＝2613）。変更しない場合は何も入力しない。
- **ポイント**：打刻漏れがあると登録アドレスに通知メールが届きます。すぐ対応を（後回しにすると忘れます）。
- **申請期限は発生日の翌日中**。期限を守って申請すること。

### ⑤ 遅刻・早退ルール
- 体調不良や事故渋滞などで予期せず遅刻・早退・欠勤するときのルール。
- **ポイント**：遅刻・早退は校舎・チーム全体に影響します。日頃の体調管理に留意し、ルールだけでなくマナーを大切に。

**遅刻**
- 遅刻が確定した時点で、ラインワークス（メール）で連絡。同時に教室運営に入る同僚・関係者にも連絡。**【総務 直江】へラインワークスで報告**。
- 出勤後、ジョブカンを打刻し、携帯マイページより：
  1. 遅刻早退のアイコンが出ている日をタップ。
  2. 右下の「遅刻理由を申請」から理由を入力。
  3. 理由を入力し確認ボタン → 内容確認後に申請ボタンをクリック。
  4. 申請完了後、申請ボタンが【申請中】になります。
  5. 詳細画面に進むと申請の取り下げも可能。

**早退**
- 体調不良等でやむを得ず早退するときは**上長の了解**をもらってから早退。**【総務 直江】へラインワークスで報告**。
- 携帯マイページより、遅刻早退アイコンの出ている日をタップ → 右下「早退理由を申請」から理由入力。

### ⑥ 欠勤ルール
- やむを得ない事情で欠勤する場合は、**上長と相談の上**で欠勤してください。欠勤が出ないよう体調管理に留意。
- 欠勤の場合は打刻をしないため、ジョブカンにはそのまま「欠」と表示されます。
- 欠勤が決まったら**【総務 直江】へラインワークスで報告**。

### ⑦ シフト確認
- ジョブカンの画面（シフト）から自分のシフトを確認できます。シフトが変則的な場合はよく確認の上、勤務してください。
- **ポイント**：シフトが実態と違う場合は、**シフト管理者に事前に相談し訂正**を。事前でないとシフトが組めず勤怠がおかしくなります。

### ⑧ シフト申請・変更申請について
- **智翔館では翌月のシフトを『前月20日までに申請、25日にジョブカンへ反映・確定』としています。**

**シフトを申請する**
1. モバイルマイページ上部のアイコンから【シフト】を選択（確定シフトの確認画面へ）。
2. 画面上部の【シフト申請】を選択（カレンダーが黄色い背景＝シフト申請画面）。
3. 申請画面の見方：
   - 申請済み・承認前の日には赤字「申請中」。
   - 確定済みの日は「申請中」が消えシフト開始時刻を表示。
   - 募集がかかっている日は「募」。
   - 申請したい日のマスを選択すると申請画面に。
4. 申請情報の入力：
   - プルダウンから申請したいシフトを選択（登録済みのシフトパターン・時刻指定シフト・休みシフト）。時刻指定を選ぶと開始・終了時刻の入力欄が出る。
   - 記載事項があれば備考に入力（管理者が確認可）。
   - 【申請】ボタンで申請完了。
   - 同じシフトを複数日まとめて申請したい場合は、下部カレンダーで複数日を選択（選択中はピンク背景）。
- 申請したシフトは**管理者から承認されるまで確定しません**。

**シフト募集がある場合**
- 募集があるとトップ画面に赤字で件数が表示。件数 → 募集理由 → シフト申請画面に移動し、希望日を選択して申請。

**申請を取り下げる（取り消す）**
- 管理者の承認前であれば取り下げ可能。ただし取り下げた申請は削除され、後から確認できません。
  1. シフト申請画面で、取り消したい「申請中」の日を選択。
  2. 取り消したい申請のチェックボックスにチェック →「申請を取り消す」をクリック（**確認画面は出ないので注意**）。
- ※管理者が既に承認している場合は「確認」と表示され、マイページから取り消せません。

**申請を一括削除する**
1. シフト申請画面カレンダー右下の【申請を一括削除】を選択。
2. カレンダーから取り消したい日を選択し【削除】。
3. 確認画面でチェックの入った申請が削除される（残したいものはチェックを外す）→【削除】で完了。

### ⑨ 諸変更届
- 勤怠は支給給与に関わり、税金の管理も給与支給時に会社を通して行うため、家族や居住に変更があった場合は**会社へ届け出る義務**があります。速やかに諸変更届を記入してください。
- **諸変更届が必要な事例（代表例）**：結婚・離婚／子の出生・家族の死去／扶養家族の増減／転居／通勤方法の変更／携帯番号。
- 「諸変更届」を出すべきか迷った場合は**【総務 直江】**まで相談。
- 提出先・記入例：所定の「諸変更届」用紙（所属名・氏名・押印、変更事項〔住所・姓名・携帯番号・その他〕、変更前／変更後、社長・総務・担当責任者印欄）。
- ※今後、LINE WORKS上での申請に変更を検討中（決まり次第お知らせ）。

## 2. 入社時の情報提出について

### ① マイナンバー登録（ジョブカン）
- 智翔館ではジョブカンを使ってマイナンバー提出を行います。
1. ジョブカンに登録したメールアドレスに案内メールが届きます（**アクセス有効期限あり**。期限切れの場合は再送するので連絡を）。
2. メール内URLにアクセス → 共通IDユーザ登録（①姓 ②名 を入力、パスワードを設定して登録）。
   - パスワードポリシー：8文字以上200文字以内、文字種制限なし、有効期限なし。
3. ログイン情報（メールアドレス/スタッフコードとパスワード）でログイン → アカウント情報画面に遷移すれば第一段階完了。
4. 後日、マイナンバー入力依頼のメールが届くので、指示に従いURLをタップ。
5. マイナンバー入力画面で、マイナンバーの入力と確認書類のアップロード（番号確認書類・身元確認書類）を行い完了。

### ② 給与所得者の扶養控除等(異動)申告書の提出
- マイナンバー提出と同時に、扶養控除等(異動)申告書も提出します。
- 管理者からデータ配信もしくは用紙配布があるので、記入例に従って入力・記入し提出してください。
- 会社（給与の支払者）：株式会社智翔館（所在地：長崎県佐世保市椎木町336番地1）。
- ※申告書の詳細な記入方法は配布される記入例を参照。
