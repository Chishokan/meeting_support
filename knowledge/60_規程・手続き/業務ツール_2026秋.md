## 時間割エディタ

| 画面 | できること |
|---|---|
| 編集（表） | 1行1コマ（校舎・曜日・クラス・開始・終了・科目・担当・形態・週）を直接編集。絞り込み・検索 |
| グリッド編集 | 縦＝時刻／横＝クラスの紙面で、ドラッグでコマを作る・動かす・長さを変える（5分単位） |
| 講師マスタ | 講師名・担当科目・担当校舎。担当コマ数・週あたり時間・重複コマ数を表示 |
| 出力・印刷 | 校舎を選んでA4 1枚に自動縮小（62%を下回ると用紙の向き変更などを案内）。印刷／PDF、TSVコピー、CSV。プレビューと印刷結果が1対1 |
| AI編集 | 「大野校の中2をABの2クラスに分けて」のような日本語の指示から変更案を作る。差分と影響（重複が何件→何件）を確認し、「適用」を押したときだけ保存 |

チェック機能

- 担当の重複（赤）：同じ講師が同じ曜日の重なる時間帯に複数コマ（校舎をまたいでも検出）。
- クラスの時間重複（黄）、時刻エラー（黄）、講師マスタとの不一致（黄）。
- 週区分が「第1・3」と「第2・4」のコマ同士は重複と見なさない。
- 元データ（「2026年度通常時間割」の2026年10月〜シート）にあった担当の重複4件・クラスの時間重複1件・学年表記が不明なクラス1件をそのまま持ち込んでいる。教務で確認して直す〔要確認〕。
- データはスプレッドシートに保存。接続が切れてもブラウザに一時退避され、復旧後に書き戻される。

## 社会一問一答アプリ

- 元データ：担当者が作った「2026年2学期定期用の一問一答データ」（スプレッドシート）。原本は変更しない。
- 誤答（選択肢）の作り方は元の作り方に合わせる：同じ節の答えを回す、語尾をそろえる、閉じた3つ組は3択。
- 〔要確認〕記号（✐・★）の意味、誤答が足りない問題の扱い、範囲の欠け（地理・歴史の一部の節）が意図どおりか。

## RED公式LINE定期配信

| 担当 | 役割 |
|---|---|
| 安藤 | 定期配信の仕組み（スプレッドシート＋GAS）のみ |
| 他担当 | 配信テンプレート・年間配信予定・本文 |
| 教室長 | 本文の確認・変更・承認 |

- 流れ：配信予定をシートに入れる → 予定日の7日前にAIが配信テーマ・イベントから文案を作る → 教室長が確認・承認 → 決めた日時に、対象（学年・学校の組み合わせ）の保護者へ送る。
- 保護者は友だち追加後、生徒IDで紐づける。名簿は教室の生徒数ファイルから毎朝自動更新（氏名で照合、IDは自動付与・書き換え可）。
- KPI：予定どおりの配信率／誤配信0件／月200通以内（フリープラン）。
- 文案から見出し語（【本日の結論】など）を外す方針に変更（2026/10/29）。
- 注意：コードを直したら、ウェブアプリの「新バージョン」としてデプロイし直す必要がある（旧バージョンのまま動いてエラーになった例あり、2026/10/30）。本番は検証が終わるまで自動配信のトリガーを設定しない。
- 使い方のレクチャー資料あり（2026/10/27 レクチャー用）。
