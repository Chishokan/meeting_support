# 【各校版】中学TOP１０スタートアップ講座 実施要項

**【新中学１年生 保護者様向け】中学TOP１０スタートアップ講座 実施要項**

  

保護者の皆様へ

  

新中学１年生を対象とした特別講座「中学TOP10スタートアップ講座」を開講いたします。中学校での学習は、小学校とは大きく異なります。特に英語と数学は、最初の段階でつまずくとその後の学習に大きく影響します。

  

本講座では、中学１学期内容の先取り学習と全７回のプログラムを通じて基礎を徹底し、お子様が進学先の**TOP１０**を実現できるよう、万全のスタートダッシュをサポートいたします。自信を持って中学校生活を迎えるためにも、ぜひ本講座へのご参加をご検討ください。

  

|  |  |
| :-: | :-: |
| \*\*項目\*\* | \*\*内容\*\* |
| \*\*実施目的\*\* | 新中学１年生を対象とし、中学入学後における１学期内容を先取学習することで、第１回定期考査で進学先\*\*TOP１０\*\*を実現します。 |
| \*\*対象\*\* | 新中学１年生の塾生および一般生 |
| \*\*実施校舎\*\* | 智翔館 日野校 |
| \*\*実施期間\*\* | 2026年2月7日（土）～ 3月21日（土） \*\*全７回\*\* |
| \*\*授業時間\*\* | \*\*毎週土曜日 9:00～12:10\*\*  （英語・数学 各75分 ＋ 授業前後AAR 15分×2） |

  

**AAR（Anticipation Action Reflection）とは**

AARは授業で習った内容を、生徒自身が授業直後に振り返り、理解度や定着度を確認・向上させるための時間です。単なる復習ではなく、「何がわかったか」「何がわからなかったか」「次に何をすべきか」を明確にし、学習の質を高めることを目的としています。本講座では、授業の前後15分ずつ、合計30分をAARの時間に充て、学習効果の最大化を図ります。

  

**実施プログラム**

|  |  |  |  |
| :-: | :-: | :-: | :-: |
| \*\*講座\*\* | \*\*日程\*\* | \*\*英語（75分）\*\* | \*\*数学（75分）\*\* |
| \*\*第１講座\*\* | 2/7（土） | アルファベットと単語①、② | 正負の数、数直線、絶対値 |
| \*\*第２講座\*\* | 2/14（土） | 単語（ものの名前、形容詞） | かっこのついた数の加法、減法 |
| \*\*第３講座\*\* | 2/21（土） | 単語（つづりと発音） | 小数と分数の加減、３つ以上の数の加減 |

| \*\*第５講座\*\* | 3/7（土） | I am ～. You are ～. | ３つ以上の数の乗法、累乗 |
| \*\*第６講座\*\* | 3/14（土） | 英文の仕組みを理解する | 逆数、除法、乗除と累乗の混じった計算 |
