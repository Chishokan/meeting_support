# 旧要項（テンプレート整備前の自動切り出し）

2026年9月のテンプレート整備より前に、要項ドキュメントを
`scripts/import-yoko.mjs` で機械的に切り出したファイル一式（33件）。

## なぜここに移したか

同じ講座の要項が `2026/` 側（納品版）と二重に存在していたため。
内容は納品版 `knowledge/40_要項/2026/2026-*.md` に置き換わっている。
残したままだと、要項QAの画面に「未確定」として旧版の題名が並び、
担当者がどちらを見ればよいのか分からなくなる。

## AIには渡らない

`lib/knowledgeDocs.ts` は `_` で始まるファイル・フォルダを読み飛ばす。
このフォルダの中身は確定・下書きを問わず要項QAの対象外。

## 中身について

- 大半は納品版に対応するものがある（例：`12_定期テストチャレンジ会_実施要項.md`
  → `2026/2026-01_定期テストチャレンジ会.md`）。
- 次の6件は要項ではなく社内メモ・案なので、納品版に対応するものが無い：
  `09_社内共有_クーポン2月までの春期申込者` `10_お客様メール文` `17_原案`
  `28_クーポンについて` `29_利用シュミレーション` `33_PR戦略案`

削除して構わないと判断できた時点で、フォルダごと消してよい（git に履歴は残る）。
