クーポン取得・利用シミュレーションパターン1：【新中1一般生】スタートアップ講座受講から夏期講習入塾へ

|  |  |  |  |
| :-: | :-: | :-: | :-: |
| \*\*ステップ\*\* | \*\*お客様の行動（新中1一般生の保護者様）\*\* | \*\*取得・利用クーポン\*\* | \*\*業務フロー上のポイントと問題点\*\* |
| \*\*1\*\* | HPから「中学TOP10スタートアップ講座」に申し込み、受講料（各月16,500円）をコンビニ払込票で支払う。 | なし | 講習申込と同時にクーポンが発行される（後日メールにて）。 \*\*\\\[問題点\\\]\*\* 講座料金とは別のクーポンが発行されることを認識しているか。 |
| \*\*2\*\* | 講座受講後、特典として「1万円クーポン」と「英検1ヶ月無料チケット」を取得（メールで受領）。 | ①1万円クーポン、②英検1ヶ月無料チケット | ①は入塾時・夏期講習、②は英検オンライン講座で利用可能。利用期限は7月末。 |
| \*\*3\*\* | 夏期講習（例：新中1春期講習会 30,800円）を受講することを決め、入塾も検討する。 | ①1万円クーポン | \*\*\\\[問題点\\\]\*\* 外部生のため、HPからの講習申込と別に\*\*電子クーポン申請\*\*が必要となり、\*\*申請漏れの可能性\*\*がある。 |
| \*\*4\*\* | 夏期講習申込フォームの備考欄に「1万円クーポン利用希望」と入力する（\*\*案2\*\*の場合）。 | ①1万円クーポン | 請求締日（7/17）までに申請が必要。\\\*\\\*「請求書発送後の利用申請は受け付けない」\\\*\\\*ルールに注意。 |
| \*\*5\*\* | 7月末までに、クーポンを利用して入塾手続きを行い、初回の授業料から1万円が割引になる。 | ①1万円クーポン | \*\*\\\[問題点\\\]\*\* クーポン利用時の確認作業（対象者か、重複利用がないか）が煩雑になる可能性がある。 |

\-----パターン2：【中2内部生】春期講習受講後、友人を紹介し、紹介者特典クーポンを利用

|  |  |  |  |
| :-: | :-: | :-: | :-: |
| \*\*ステップ\*\* | \*\*お客様の行動（中2内部生の保護者様）\*\* | \*\*取得・利用クーポン\*\* | \*\*業務フロー上のポイントと問題点\*\* |
| \*\*1\*\* | 「新中2・3春期講習会」は通常授業のため、申し込み不要。受講料（25,300円）は口座引き落とし。 | なし | 塾生は原則受講のため申込不要。受講を辞退する場合は2/28までに申出が必要。 |
| \*\*2\*\* | 春期講習受講後、特典として「5,000円クーポン×2枚」を取得（メールで受領）。また、友人が春期講習に申し込んだため「紹介者1万円クーポン」も取得。 | ①5千円クーポン×2、②紹介者1万円クーポン | 利用期限は7月末。\*\*\\\[問題点\\\]\*\* ①の\\\*\\\*「各種イベント」の具体的内容が不明\\\*\\\*。また、紹介者の把握方法が不明確（誰が誰を紹介したか）。 |
| \*\*3\*\* | 夏期講習（例：30,000円）に申し込み、\\\*\\\*「紹介者1万円クーポン」\\\*\\\*の利用をメールで事務窓口へ連絡する。 | ②紹介者1万円クーポン | \*\*\\\[業務フロー\\\]\*\* 保護者様からのメール連絡→事務方のグロウ処理→適用メール送信、というフロー案。 |
| \*\*4\*\* | \\\*\\\*「5,000円クーポン×2枚」\\\*\\\*を特定のイベント（例：4月の実力テスト代 5,000円）の支払いに利用するため、事務窓口にメールで連絡する。 | ①5千円クーポン×2 | \*\*\\\[問題点\\\]\*\* 「各種イベント」が何かが曖昧なままだと利用申請がスムーズに進まない。また、\\\*\\\*「10,000円に統一してほしい」\\\*\\\*という意見がある。 |
| \*\*5\*\* | クーポン合計2万円分を利用できた場合、\*\*\\\[問題点\\\]\*\* 夏期講習受講料が2万円以下の場合の\\\*\\\*計算方法（おつり）\\\*\\\*が不明確。 | \\- | \\\*\\\*「おつりの返金はない旨を記載しておく」\\\*\\\*の検討事項と関連。ルールを明確に記載する必要がある。 |

\-----パターン3：【中3一般生】夏期講習の引き落とし日後にクーポン利用を申請

|  |  |  |  |
| :-: | :-: | :-: | :-: |
| \*\*ステップ\*\* | \*\*お客様の行動（中3一般生の保護者様）\*\* | \*\*取得・利用クーポン\*\* | \*\*業務フロー上のポイントと問題点\*\* |
| \*\*1\*\* | HPから「新中2・3春期講習会」に申し込み、早割料金（26,400円）をコンビニ払込票で支払う。 | なし | \*\*早割期限\*\* (2/28 または 3/1) を意識する必要がある。 |
| \*\*2\*\* | 春期講習受講後、特典として「1万円クーポン」を取得（メールで受領）。 | 1万円クーポン | 利用期限は7月末、利用可能先は入塾時・夏期講習。 |
| \*\*3\*\* | 夏期講習（例：30,000円）の受講を決めるが、クーポン申請を忘れていた。夏期講習の\*\*請求書が既に発送\*\*されている。 | 1万円クーポン | \*\*\\\[利用ルール\\\]\*\* 「請求書発送後の利用申請は受け付けない」ルールにより、クーポンは利用不可となる。 |
| \*\*4\*\* | 7月18日以降（夏期講習の引落締日7/17後）にクーポン利用を申請する。 | 1万円クーポン | \*\*\\\[問題点\\\]\*\* 7/18～7/31の申請を\*\*返金対象とするか不明\*\*。利用期限を7月末と謳っているため、クレームにつながる可能性がある。 |
| \*\*5\*\* | 塾に問い合わせた結果、「今回は特別に\*\*返金対応\*\*とする」という対応になる。 | 1万円クーポン | \*\*\\\[問題点\\\]\*\* 事務処理が煩雑化し、返金対応のルールが曖昧になる。事前に\*\*利用期限の明確化と注意喚起\*\*が必要。 |
