# クーポンについて

クーポン利用時の業務フロー

  

\<内部生\>

①保護者　クーポン利用を事務窓口（入会メール全員確認できる）へメール連絡する

  

②事務方　グロウ処理します

  

③事務方　適用した旨のメールを送信します

  

※クーポンの利用実績はグロウの請求管理で確認できる

メールクーポンに利用期限、利用ルール（遡って×申請期限は毎月17日迄、期限を超えての申請は翌月処理とするなど）、、利用の仕方、流れ、などを記載しておく

メールクーポン発行前の宮ケ中さんのチェック必要

  

\<外部生\>

⇒

案1　講習申込フォームに【クーポン利用】欄を設け、チェックを入れてもらう

案2　講習申込フォームの備考欄に利用する旨を入力してもらう

案3　講習申込フォームとは別にクーポン申込フォームを設ける

  

利用ルール

・請求書発送後のクーポン利用申請は受付ない

  
  

【問題点】

・中学準備講座受講の県中生のみの想定で業務フローを作成した。クーポンの種類増、全塾生・一般生も対象となると、管理が煩雑になるため事務一人だけでは対応できない。

　→チェックを行うフローと人員の設定　そもそもチェックするか決める

  

・クーポンは紙ではなく電子クーポンとする。不正利用が行えないように明確なルール・利用限度1回のみ・期限を過ぎたら使用できなくなる等の設定が必要。

　→併用不可（または併用可能なクーポン名）　配布された方以外不可　期限の明記をする

  

・クーポンの管理をどうするか。

⇒電子クーポンの内容次第では管理は必要ない？

\-----クーポン利用に関する業務フローと問題点

|  |  |
| :-: | :-: |
| 項目 | 内容 |
| 利用ルール（確定事項・検討事項） |   |
| クーポンの形態 | 紙クーポン：不正利用されにくい電子クーポン：受付の手間がなく、請求反映しやすい |
| 利用申請の期限 | 7月末内部生：夏期講習の引落は7/27（締日7/17）　　　　7/18～7/31申請の場合、相殺・返金処理外部生：請求書発送後の利用申請は受け付けない |
| 不正利用対策（検討） | 明確なルール、利用限度1回のみ、期限を過ぎたら使用不可などの設定が必要電子クーポンでは設定不可紙クーポンでは申請時に渡すので重複利用は防げる |
| 利用対象者（検討） | 配布された方以外は不可。 |
| 内部生利用時の業務フロー（案） |   |
| ① 保護者 | クーポン利用をWEB利用フォームで登録する。 |
| ② 事務方 | グロウ処理を行う。 |
| ③ 事務方 | 適用した旨のメールを送信する。 |
| 問題点（管理・ルール） |   |
| 管理体制 | クーポンの種類増加と対象拡大により管理が煩雑化。事務一人では対応できないため、チェックを行うフローと人員の設定が必要。 |
| 5,000円クーポンの使途 | 春期クーポン5,000円×2枚の使用できるイベントが何か不明。対象イベントの明記。 |
| 20,000円クーポンの計算 | 春期講習受講＋紹介で20,000円分利用できる場合、夏期講習受講料が20,000円以下の場合の計算方法が不明。 |
| 紹介者の把握 | 紹介者をどのように把握するのか不明。紹介者が春期講習を受講していることが原則。 |
| 外部生の利用方法 | 電子クーポンにすると、講習申込と電子クーポン申請で2度の申請が必要になり、申請漏れの可能性がある。⇒HPの講習申込フォームに利用の有無の欄を追加 |
| 一般生の入会時利用方法 | 電子クーポンの場合、入塾面談時に目の前で利用してもらい、画面確認できたら入会フォームに入力してもらう。 |
