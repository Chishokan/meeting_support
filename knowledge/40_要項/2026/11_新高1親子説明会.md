# 新高1親子説明会

2026年2月吉日

高校合格者（新高校１年生）保護者の皆様へ

  

智翔館東進衛星予備校

  

**「高校合格者 大学進学親子説明会」開催のお知らせ**

  

この度は、高校合格おめでとうございます。

  

さて、下記により高校合格者（新高校１年生）とその保護者の皆様を対象とした特別説明会「大学進学親子説明会」を実施いたします。高校での学習は、大学入試を最終目標として、中学校とは比較にならないほどのスピードと内容で進みます。

  

本説明会では、大学入試の最新動向と、新高校1年生が早期に取り組むべき学習の「核」を解説し、スムーズで確実な高校生活のスタートと、将来の大学合格に向けた盤石な土台作りをサポートいたします。

  

ご多忙中とは存じますが、ぜひ親子でご参加いただきたくご案内を申し上げます。

  

記

**対象**

公立・私立高校に合格された新高校１年生の塾生および一般生とその保護者様

  

**実施日程・会場**

**3月6日（金）19:30～21:00　智翔館 大野校**

**3月7日（土）19:00～20:30　智翔館佐世保駅前校**

  

**内容**

|  |
| :-: |
| \*\*最新の大学入試動向と合格への戦略\*\*    &#10;新課程入試のポイント解説  ・高校での学習と成績の重要性 |
| \*\*高校先取り学習の内容と高1スタートダッシュの重要性\*\*    &#10;新高校１年生がやるべきこと（学習法、生活習慣）  ・保護者様への情報提供とサポートのポイント |
| \*\*卒業生の成功事例\*\*中学・高校の努力で大逆転を成し遂げた先輩のリアルな事例をご紹介 |
| \*\*先取り高校数学担当：「松井浩二先生特別公開授業」を同時開催！\*\*松井先生が高校数学と大学受験成功の秘訣を熱く語ります |

**参加費　無料**

**申込方法　** 一般生の方：智翔館ホームページよりお申し込みください。

（塾生の方は別途ご案内いたします）

  

ご不明な点は、智翔館本部または佐世保駅前校までお問い合わせください。
