# 方針チェック観点（第36期）

スライド資料、業務計画、チラシなどの社内資料が、智翔館の理念と今期の方針に沿っているかを確かめるための観点。
職員が自分で確かめるときにも、AIが資料にアドバイスするときにも使う。

元になった資料：
- `10_理念・方針/経営指針書_2026.md`（理念・行動指針・全社共通テーマ・10年ビジョン）
- `10_理念・方針/経営計画発表会_社長方針_2026.md`（第36期の事業・販促・働く環境・財務改善計画）
- `10_理念・方針/COMPANY.md`（やってほしいこと・やってほしくないこと）

元の資料が更新されたら、ここも合わせて直す。

## 1. 理念に沿っているか

| 観点 | 確かめること |
|---|---|
| 経営理念 | 「長崎から世界、社会に羽ばたく自立型人間を育成することで、地域社会と世界の未来に貢献する」につながる内容か。自立型人間＝指示を待たず、自分の意思で考え、判断し、行動できる人 |
| 行動指針 | 成長の場・感動の場・人生を豊かにするお手伝い、のどれかを提供する内容になっているか |
| 教育理念・指導理念 | 「志あるところに道は拓ける」「輝いていないように見える児童生徒は、輝き方を知らないだけである」と矛盾しないか（生徒を成績だけで決めつける表現になっていないか） |
| 目指す姿 | 「夢・志・コンサルタント」として、お客様の人生を豊かにするお手伝いをする姿勢が出ているか |

## 2. 全社共通テーマ（4項目）に沿っているか

| テーマ | 確かめること |
|---|---|
| ① 生徒・保護者への興味関心 | 生徒・保護者の状況や不安から出発しているか。商品の説明より先に、相手の困りごとを書いているか |
| ② 仲間を頼る信頼する | 一人や一部門で抱え込んでいないか。応援・他部門・NEPへの依頼を選択肢に入れているか |
| ③ 報連想で生徒のために知恵を借りる | 誰に・いつ報告・相談するかが書かれているか（「報連想」は社長指定の表記。直さない） |
| ④ スピードとチームプレイ | 期限が具体的か。役割分担が書かれているか |

## 3. 第36期の方針に沿っているか

| 計画の視点 | 確かめること |
|---|---|
| 事業 | 「学習習慣」と「勉強体力」をつける継続サービスにつながっているか。中学継続・高校継続・兄弟姉妹生・友人紹介生・春期継続生・新年度入会生（合計で前年比2倍が目標）のどれを増やす施策か |
| 部門の選択と集中 | 高評価・高付加価値部門に資源を寄せているか。日本語能力検定・日本語学習支援の強化に関係するか |
| 販促 | NEPの総合マーケティング支援（HP、CM、サイネージ、ポスター、チラシ、SNS）を使っているか。紹介（SYS・HYS・BS）を重視し、割引の上乗せに頼っていないか |
| 働く環境 | 有給取得（入社3年以内は100％、全社員10日以上）や休業日の計画を妨げない段取りか。AIの活用や「やる事・やらない事」の整理で、作業を減らせているか |
| 財務改善 | 固定費・変動費（家賃、光熱費、印刷コピー代、広告費、教材、保険料）を増やす内容になっていないか。増える場合は理由と効果が書かれているか |
| 第35期から継続 | 部門別の採算が見える形になっているか（月次決算でチェックできるか） |

## 4. 書き方のルールを守っているか

- 計画は「いつまでに・何を・どのくらい」まで具体的か
- 数値は目標比・昨年比で示しているか。データが無い項目は「未集計」と書いているか（推測で埋めていないか）
- 協議事項は、経緯・論点・自分の意見がそろっていて、決定で閉じられる形か
- 生徒や家族の実名が無いか（イニシャルにする。職員は実名可）
- 学校や他塾を批判・比較していないか
- 業績の数字（売上・利益）を、社外に出る資料に載せていないか

## 5. AIがアドバイスするときの書き方

- 結論を先に書く（「方針に沿っています／◯点、見直すとよい点があります」）
- 見直す点は、上の観点の番号と、資料のどこ（スライド番号・見出し）かを添える
- 直し方の例を1つ示す。書き直しを押しつけず、本人が選べるようにする
- 方針資料に書かれていないことを、方針として断定しない。〔要確認〕の箇所は「確認が必要」と伝える
- 出典（このファイルと、元になった資料）を添える
