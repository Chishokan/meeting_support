# 15_地域・市場 の使い方

## このフォルダの目的

講習・募集・校舎運営の計画を相談するとき、社内方針（他のフォルダ）と、佐世保市の地域の事実（このフォルダ）を組み合わせて答えるための資料である。

## ファイル一覧

| ファイル | 中身 | 開く場面の例 |
|---|---|---|
| 佐世保の学校と校区.md | 校舎別の対象中学校・小学校と生徒数、門配の部数ルール、市全体の学校数、受験できる県内の中学校一覧 | 「日野校の門配はどの学校に何部？」「駅前校の対象中学は？」「佐世保から通える私立中は？」 |

| 競合と市場.md | 問合せの学年・流入経路、オンラインの地域別需要、社内のポジショニング、中学受験の併願、業界動向 | 「広告をどこに出す？」「県立中対策の打ち出し方は？」「保護者は何で塾を比べる？」 |

## 答えるときの約束

1. **時点を必ず添える。** どのファイルも「いつの情報か」を書いている。回答でも「2024年の学校基本調査では」「2026年度の行事予定では」のように時点を言う。
2. **社内資料と Web 情報を区別する。** 【Web】と書いた箇所は、外部サイトから補った情報で、公式文書で確定していないものがある。
3. **〔要確認〕の箇所は断定しない。** 「資料では〜だが、要確認とされている」と伝え、確認先（県教委、市オープンデータ、校舎長など）を示す。
4. **学校の日程は年度で変わる。** 前年の日付をそのまま今年に使わない。
5. **他塾・学校を評価しない。** 事実と社内の見立てを区別して、中立に伝える。
6. **個人情報は扱わない。** このフォルダには生徒・保護者の個人情報はない。問合せや成績の個票が必要な質問は、担当部門の管理資料に回す。

## 情報の鮮度（2026-11-04 時点）

| 情報 | 時点 | 次に更新する時期 |
|---|---|---|
| 小中学生数 | 学校基本調査 2024年（令和6年度） | 令和7年度の値が公表されたら |
| 校舎別対象校の生徒数 | 門配状況シート（2026-07 更新、元の時点は不明） | 新年度の門配計画を立てるとき |
| 公立高校入試日程 | 令和8年度は確定済み、令和9年度は Web 検索の要約 | 県教委の令和9年度実施要領が出たら |
| 各中学校の定期テスト・行事 | 2026年度（2026-09 時点の行動計画） | 各校の行事予定が更新されたら・3学期前 |
| 問合せ傾向 | 2026年5〜9月（記録は9/2まで） | 下期の集計が出たら |
| オンラインの地域別需要 | 2026-07 時点の173件 | 次回の分析時 |
| 外国人市民数 | 2026年3月末 | 市の次回公表時 |

- 佐世保市内の競合塾の一覧。
- 佐世保市内の公立高校の一覧・募集定員・志願倍率。
- 令和9年度の公立高校入試・県立中入試の公式日程。
