# 佐世保の学校と校区（校舎別の対象校）

## このページの使い方

- 校舎の募集計画・門配計画・講習の告知先を考えるときに、「その校舎がどの学校の生徒を対象にしているか」を確認するために使う。
- 生徒数は門配の部数（ボトム＝最低配布数）を決めるための社内記載値である。公的統計ではない。最新の学校別人数は佐世保市オープンデータで確認する（下記「最新値の取り方」）。
- 正式な「通学区域（校区）」の境界は本ページにはない。〔要確認：佐世保市教育委員会の通学区域一覧を入手していない〕

## 2. 門配の部数ルール（社内基準）

出典：「門配状況」シート注記、「門配計画_AIモジュール」（drive:1hEUMHhMTkB7fzsTqJxncUln9aNLn9zjn8ThZ6yFTpvs）。

| 区分 | 月間の最低配布数（ボトム） |
|---|---|
| 平常月・中学校 | 全生徒数の20% |
| 平常月・小学校 | 生徒数の30%（小2〜6の人数を使う欄あり） |
| 募集期 | 50%以上（シート上は中学校60%・小学校60%の欄もある） |
| 開校月（大野の例） | 大野中50%、中里中40%、柚木中40%、大野小50% |

- 門配は「配って終わり」にしない。配布後の導線（問合せ→体験→入塾）と、問合せ・体験のヒット目標を必ず決める（門配計画_AIモジュールの方針）。
- 配布は各学校のルール・マナーの範囲で行う。

## 5. 最新値の取り方（更新時の手順）

出典：「佐世保市_児童生徒数.md」の記載。

1. 学校別の児童・生徒数は、佐世保市オープンデータ（BODIK、CC BY）のデータセット「学校基本調査（佐世保市）」「学校教育（学校基本調査を除く）」にある「学校別児童数（小学校）」「学校別生徒数（中学校）」（年度別 XLSX）から取る。
2. 学校の所在地は佐世保市「公共施設案内マップ（小学校／中学校）」で確認する。
3. 通学区域別の推計は「佐世保市学校再編計画」PDF にある（基準は令和3年度）。
4. 取り込むときは、出典・年度・URL をセットで記録する。数値には必ず出典年を書く。
