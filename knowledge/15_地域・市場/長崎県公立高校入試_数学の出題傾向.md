# 長崎県公立高校入試 数学の出題傾向（令和7・8年度）

入試対策の教材・模試を作るとき、入試の相談に答えるときに開く。
**予備校・受験情報サイトの分析をもとにしている（2026年11月13日に調べた）。** 県の公式の配点表・問題は、県教育委員会の公表資料で確かめること。
入試の日程・制度の全体は `15_地域・市場/入試・テスト日程_2026.md` を見る。

## 1. 令和7年度（2025年2月実施）からの変更

| 項目 | 内容 | 出典 |
|---|---|---|
| 問題の種類 | 数学と英語は、県が作る **A問題（基礎・標準中心）** と **B問題（思考力・判断力・文章力を問う設問が多い、難しめ）** の2種類。受検生が選ぶのではなく、**各高校がどちらかを指定**する | 共栄出版、英進館、edu-netz |
| 採用校 | **佐世保の三高（佐世保北・佐世保西・佐世保南）はB問題**（社内確認：システム担当経由で確かめた。2026-11-13）。長崎市の主要5校もすべてB問題（英進館）。主に進学校がB、実業系がA | 社内確認、英進館、edu-netz |
| 大問の数 | **6題 → 5題**。立体図形だけの大問が独立しなくなった（令和7年度） | 英進館、進研ゼミ |
| 試験範囲 | 入試が2月になり、**「標本調査」（中3）が範囲外** | 進研ゼミ、英進館 |
| 記述・作図 | 記述・作図の配点の割合が増えた | 英進館 |
| 探究的な問題 | 学力検査の問題の **2割程度を探究的な問題** にする方針（県） | 県教育委員会の公表資料〔要確認：原文〕 |

〔要確認〕三高以外の佐世保の高校（実業系・私立との併願先など）が、A問題とB問題のどちらを指定しているか。

## 2. 大問ごとの出題と配点の目安

令和7年度の配点（edu-netz の分析）。令和8年度は「大きな変更なし」とされ、令和8年度B問題の解説でも5題の構成。

| 大問 | 主な出題 | 配点（A／B） |
|---|---|---|
| 1 | 小問集合（10題前後）。各単元の基本〜標準。**作図は頻出** | 30／30 |
| 2 | データの活用（資料の整理）・確率・**式の証明（記述）**・方程式の文章題 | 18／17 |
| 3 | 関数（2乗に比例する関数と直線、面積、動点など） | 15／16 |
| 4 | 図形（令和7年度は平面図形、令和8年度は空間図形）。後半は面積比・長さの比など難しめ | 16／16 |
| 5 | **規則性・総合（会話文）**。身近な事がらを数学で説明する思考力の問題。問1・問2は取り組みやすい | 21／21 |

- 配点・大問の中身は年によって動く。〔要確認：県公表の正式な配点〕
- 図形の証明は、合同・相似以外の証明が出る年や、穴埋めの年がある（令和5年度は穴埋め）。円周角を使った相似のパターンは押さえる
- 社内の模試「炎の最終章」（令和7年度版）は、**大問6題（空間図形の大問が独立）の旧来の形**。本番に合わせるなら5題の形にそろえる余地がある〔要確認：数学科の方針〕

## 3. 得点の水準

- 令和7年度の数学B問題の県平均は **50.9点**（英進館が県の成績資料から引用）。数学・理科は得点率50％台前半と低め
- 参考：全国学力・学習状況調査（中3 数学）の県の平均正答率は、令和7年度 46％（全国 48.3％）、令和5年度 48％（全国 51.0％）（県の公表資料）。入試とは別の調査

## 4. 対策と教材づくりの要点

- **小問集合で落とさない**：計算・因数分解・方程式・関数の基本・作図を、短い時間で正確に。大問1だけで30点ある
- **記述（式の証明・方程式の過程）と作図**：配点が増えている。「答えだけでなく、答えを求める過程がわかるように」書く練習
- **会話文・資料を読む問題**：大問5の規則性・総合、大問2の資料の整理。会話の中のヒントを使って規則を見つけ、文字式で表す（最後は n の式）
- **図形の後半**：面積比・長さの比、円周角を使った相似
- **標本調査は入試に出ない**（授業・定期テストでは扱う）
- 教材を作るときは、志望校が **A・Bどちらを指定しているか** で難しさを分ける。**三高（佐世保北・西・南）志望はB問題レベル**。B問題向けは、初めて見る状況で条件を整理し、規則や関係を自分で見つける問題を入れる
