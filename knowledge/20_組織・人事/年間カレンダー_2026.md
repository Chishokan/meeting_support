# 年間カレンダー 2026

確定済みの要項（`40_要項/2026/`）の日程を、月ごとに並べたもの。**業務計画の「いつまでに」を決める土台**として使う。
細かい時間・会場・料金は、各行の要項ファイルを開いて確認する（ここには載せない）。

- 期は5月始まり・4月締め（第36期＝2026年5月〜2027年4月）。この表は暦年（1月〜12月）で並べている
- 要項が「下書き」のもの（2026-04 県立中受検対策オンラインセミナー、週1回受講コース）は載せていない
- 2026年1〜8月の要項は「申込開始日」が未記入のものが多い。申込開始の目安は、記入のある秋以降の要項から読み取れる範囲で「4. 準備の目安」に書いた
- 学校の定期テスト日程・行事は入っていない〔要確認：中学校ごとの定期テスト日程の資料（地域情報）と合わせて見る〕

## 3. 年間の流れ（中等部の例）

要項の実施概要にある「夢・志実現プログラム」の並び。

1. 高校入試フォーラム（3月）
2. 春期講習会（3月末〜4月）
3. 夏期講習会（7月末〜8月）＝第3弾「定着・実践力養成編」
4. 秋講座「高校入試合格必達プログラム」（9月〜12月）：サイトク前期 → 県一斉模試 → サイトク後期 → 本番レベル模試・LAST LAP BELL セミナー
5. 冬期講習会（12月末〜1月）→ 正月特訓 → 県一斉模試 → サイトク → 最終予行会 → 入試
