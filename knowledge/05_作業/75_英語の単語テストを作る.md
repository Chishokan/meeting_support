# 英語の単語テストを作る

問題と答えは、教材から書き写した元データ（`37_教材制作/英語/00_使い方.md` の「入っている範囲」）から、道具 `create_english_word_quiz` が選ぶ。
**AI は単語も意味も書かない。** 範囲と出し方を決めて道具を呼ぶだけにする。

## 1. 決めること（作る前に必ず1回聞く）

「単語テストを作って」と頼まれたら、**下の4つを必ず聞く**（安藤さんの決め・2026-11-24）。頼みごとに書いてある項目も省かず、書いてあるとおりを答えの欄に入れて、確かめてもらう形にする。
1回の返事でまとめて答えられる形にし、選択肢は「この前提で作る」と、迷いそうな項目の別の答え（1〜2個）にする。答えをもらったあとは聞き直さない。この回は質問だけを書き、**選択肢で回答を終える**。

| | 必ず聞くこと | 既定の答え |
|---|---|---|
| 1 | 範囲：教材の Unit のどこから作るか（学年・Unit・区分〔Part1、Part2、Let's Talk1 など。いくつでも〕）、または基礎単語（曜日・月・数字・不規則動詞 など） | 頼みごとのとおり。区分が無ければ Unit のすべて |
| 2 | 絞り込み：なし／☆（よく出る）の語だけ　※基礎単語なら、学年の目安（小学校・中1・中2）・品詞でも絞れる | なし |
| 3 | 問題数（1枚に単語40問・KWT12問・不規則動詞20問まで） | 範囲のすべて（40問をこえるときは40問） |
| 4 | 出題形式：英語 → 日本語／日本語 → 英語／混合　※不規則動詞の変化なら、過去形・過去分詞／過去形だけ／意味から3つとも | 日本語 → 英語 |

4つのほかは、聞かずに既定で作り、回答の「置いた前提」に書く：出す元（Key Words の単語。「KWT」「穴埋め」と頼まれたら巻末の Key Words TEST）、並び（教材の順）、版（1版）。

- 範囲の名前は、`00_使い方.md` の「入っている範囲」の区分の名前で選んでもらう。**入っていない学年・Unit は作れない**ことを伝え、入っている範囲を見せる
- **教材の範囲ではなく「曜日」「月」「数字」「不規則動詞」「中1の名詞」のような頼みごと**のときは、基礎単語の一覧から作る（`00_使い方.md` の「3. 基本単語の元データ」）
- 「1枚に収めて」と言われたら、問題の数を1枚に入る数以下にする
- **「助動詞の確認テスト」「助動詞テスト」と頼まれたら**、助動詞の確認テスト（`00_使い方.md` の「助動詞の確認テスト」、全25問・1枚）から作る。
  4つのうち選べるのは範囲だけ（全部／can・must・may・will・should・had better・会話の表現）。絞り込み・問題数・出題形式は元のテストのまま（意味と語を書く）なので、
  4つの欄にはそのことを書いて確かめてもらう（例：「2. 絞り込み：なし（元のテストのまま）」）

聞くときの形：

````
作る前に4点を確認させてください。そのままでよければ「この前提で作る」を押してください（一部だけ答えても大丈夫です）。

1. 範囲：中1 Unit4 の Part1・Part2（または、曜日・月・不規則動詞などの基礎単語）　→ 既定：頼みごとのとおり
2. 絞り込み：なし／☆の語だけ　→ 既定：なし
3. 問題数：何問にしますか（1枚に40問まで）　→ 既定：範囲のすべて（40問）
4. 出題形式：英語 → 日本語／日本語 → 英語／混合　→ 既定：日本語 → 英語

```選択肢
この前提で作る
☆の語だけにして作る
混合で作る
```
````

## 2. 作る

決まったら `create_english_word_quiz` を呼ぶ（grade・unit・sections・source・star_only・direction・count・order・versions）。
- 範囲の名前が違うと、道具が作らずに入っている範囲を返す。その一覧から合うものを選び直して呼ぶ（それでも決まらなければ職員に聞く）
- 「Part1 と Part2 で別々に」のように2組まで1回の回答で作れる
- 基本単語：source＝basic と categories（例：["曜日", "月"]）・levels・pos・direction・count。不規則動詞の変化：source＝verbs と levels・verb_ask（past-pp／past／all）・count。grade・unit は渡さない
- 助動詞の確認テスト：source＝modals と modal_groups（例：["会話"]。省くと全25問）。ほかは渡さない

## 3. 出力の形

````
（1行で：学年・Unit・区分・出す元・問題の数・枚数）

（道具の結果に出た URL：テスト／答え入り）

## 確認してほしいこと
- 置いた前提：（聞かずに決めたこと：出す元・並び・版 など）
- 先生に見てほしい点：1枚に収まっているか、答えの書き方（教材の表記のまま）
````

- 問題の全文は回答に書かない（Word にある）。保存に失敗したときだけ、道具の結果に出た問題と答えを書く
- **道具を呼ばずに URL を書かない**
