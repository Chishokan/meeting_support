# 英語の単語テストを作る

問題と答えは、教材から書き写した元データ（`37_教材制作/英語/00_使い方.md` の「入っている範囲」）から、道具 `create_english_word_quiz` が選ぶ。
**AI は単語も意味も書かない。** 範囲と出し方を決めて道具を呼ぶだけにする。

## 1. 決めること（作る前に1回だけ聞く）

頼みごとに書かれていないものを、下の表から**優先順に最大3つ**、既定の答えを付けて聞く。1回の返事でまとめて答えられる形にし、選択肢は「この前提で作る」と、迷いそうな項目の別の答え（1〜2個）にする。
条件が書いてあるとき、「おまかせ」「すぐ作って」と言われたときは、聞かずに作る。答えをもらったあとは聞き直さない。この回は質問だけを書き、**選択肢で回答を終える**。

| 優先 | 聞くこと | 既定の答え |
|---|---|---|
| 1 | 範囲：学年・Unit・区分（Part1、Part2、Let's Talk1 など。いくつでも選べる） | 頼みごとのとおり。区分が無ければ Unit のすべて |
| 2 | 出す元：Key Words の単語／巻末の Key Words TEST（文の穴埋め） | Key Words の単語 |
| 3 | 絞り込み：☆（よく出る）の語だけ／すべて | すべて |
| 4 | 問い方：日本語 → 英語／英語 → 日本語／半分ずつ | 日本語 → 英語 |
| 5 | 問題の数・並び・版：何問か（1枚に単語40問・KWT12問まで）、教材の順かばらばらか、A版・B版を作るか | 範囲のすべて・教材の順・1版 |

- 範囲の名前は、`00_使い方.md` の「入っている範囲」の区分の名前で選んでもらう。**入っていない学年・Unit は作れない**ことを伝え、入っている範囲を見せる
- 「1枚に収めて」と言われたら、問題の数を1枚に入る数（単語40問・KWT12問）以下にする

聞くときの形：

````
作る前に3点だけ確認させてください。そのままでよければ「この前提で作る」を押してください（一部だけ答えても大丈夫です）。

1. 範囲：中1 Unit4 の Part1・Part2　→ 既定：頼みごとのとおり
2. 出す元：Key Words の単語／巻末の Key Words TEST（文の穴埋め）　→ 既定：Key Words の単語
3. 絞り込み：☆の語だけ／すべて　→ 既定：すべて

```選択肢
この前提で作る
☆の語だけにして作る
Key Words TEST で作る
```
````

## 2. 作る

決まったら `create_english_word_quiz` を呼ぶ（grade・unit・sections・source・star_only・direction・count・order・versions）。
- 範囲の名前が違うと、道具が作らずに入っている範囲を返す。その一覧から合うものを選び直して呼ぶ（それでも決まらなければ職員に聞く）
- 「Part1 と Part2 で別々に」のように2組まで1回の回答で作れる

## 3. 出力の形

````
（1行で：学年・Unit・区分・出す元・問題の数・枚数）

（道具の結果に出た URL：テスト／答え入り）

## 確認してほしいこと
- 置いた前提：（聞かずに決めたこと：絞り込み・問い方・並び など）
- 先生に見てほしい点：1枚に収まっているか、答えの書き方（教材の表記のまま）
````

- 問題の全文は回答に書かない（Word にある）。保存に失敗したときだけ、道具の結果に出た問題と答えを書く
- **道具を呼ばずに URL を書かない**
