# できたチラシを直す

## 手順

1. **何を直すかを確かめる**：直す場所（例：右上の写真、赤い帯の左端）、今の文言、直した後の文言。チラシの画像が添付されていれば見て特定する
   - 分からないところだけ、1〜2個に絞って聞く
2. **型を選ぶ**：`30_修正・派生プロンプト.md` の「0. 使い分け」の表から型を選び、同じ会話で貼るのか、新しい会話に元画像を添付するのかを決める
3. **数字を直すとき**は、確定した要項（`40_要項/`）を `read_file` で読み、要項どおりかを確かめる。要項に無い数字は書かない
4. **プロンプトを作る**：選んだ型に沿って書く。共通の原則（指定箇所以外は変えない、QRの白枠を残す、ほかの数字は変えない）を必ず入れる

```
（1行で：使う型と、同じ会話か新しい会話か）

## 修正プロンプト
（コード枠 ``` の中に全文）

出典: （読んだ資料）
```
