# 広報物の確定版のデータをさがす

先生が求めているのは、生徒に配る・校舎に貼る**確定版**。確定版だけを出す。

## 手順

1. `list_drive_folder` に `05_広告制作` を渡して、**今の状態で**開く（前に見た一覧は使い回さない）
2. 講座名に合う `YYYYMMDD_講座名_納品データ` フォルダを開く。同じ講座が複数あれば日付が新しいもの。どれか迷ったら、候補の講座名を選択肢で聞いて止まる
3. その中の `00_確定版（配布・掲示用）` フォルダを開き、中のファイルを案内する
   - 古い形のまま残っている納品データでは、`06_QR入り` フォルダの中のファイル（ファイル名に「ロゴQR入り」）
4. 確定版が見つからないときは「確定版が見つかりませんでした」と伝え、広報担当（安藤純平）への確認を案内する。**素材のリンクは、代わりであっても出さない**

## 出さないもの

先生が「素材」「元データ」「WEB用の画像」「QRだけ」とはっきり頼んだときだけ出す。

- `01_チラシ`・`02_ポスター`・`03_サイネージ`（ロゴ・QRが入る前の版）
- `10_WEB掲載用`（旧 `04_WEB画像`）、`_制作素材`（旧 `05_QRコード` など）、名前が `_` で始まるフォルダ
- 納品メモ、プロンプト・原稿の .md、「旧」「old」が付いたもの

## 出力の形

```
（講座名）の確定版です。
- チラシ：ファイル名（https://drive.google.com/open?id=ファイルのid）
- ポスター：…
- サイネージ：…
```

フォルダの構成や素材の説明はしない。
