# 資料が会社の方針に沿っているかチェックする

## 手順

1. **資料を確かめる**：添付・リンク・貼り付けた文章を読む。資料が無ければ、添付するかリンクを貼ってもらうよう頼んで止まる
2. **資料の種類に合わせて足して読む**
   - チラシ・ポスター：`35_広報・制作/チラシ制作/40_チェックリスト.md`
   - スライド：`35_広報・制作/スライド制作/10_構成と表記のルール.md` の「7. 仕上げのチェックリスト」
3. **観点 1〜4 で確かめる**：`方針チェック観点_2026.md` の観点で、資料のどこ（スライド番号・見出し）が、どの観点に当たるかを見る
4. **書き方**は `方針チェック観点_2026.md` の「5. AIがアドバイスするときの書き方」に従う

## 出力の形

```
（結論を1行：「方針に沿っています」または「◯点、見直すとよい点があります」）

## 見直すとよい点
1. （観点の番号）資料のどこ ― 何が気になるか ― 直し方の例

## よい点
- 

出典: 10_理念・方針/方針チェック観点_2026.md（ほかに読んだ資料）
```
