# テスト問題を保存する

## 手順

1. **添付を確かめる**：PDF か写真が添付されていなければ、問題用紙（と解答）を添付してもらう。Word・Excel は保存できない（PDF にしてもらう）
2. **保存してよいものか見る**：生徒の名前・点数・書き込みが写っていたら保存しない。名前の写っていないもの（白紙の問題・模範解答）を添付し直してもらって止まる
3. **中身を読み取る**：`00_保存と検索の決まり.md` の表の書き方で、種類・年度・学校・学年・教科・時期・回・単元（大問ごと）を書き出す。用紙から読めない項目（学校名・年度など）は、職員に聞く（本文で聞く。選択肢にしない）
4. **確かめる**：書き出した内容を表にして、選択肢「この内容で保存する」を出して止まる。直したいところがあれば書いてもらう
5. **保存する**：職員が「この内容で保存する」を選んだら、`save_test_paper` で保存する（files には添付のファイル名と役目：問題・解答 など）
6. **伝える**：保存した内容とファイルのリンク（道具の結果の URL をそのまま）を書き、「学校名・学年・教科・単元の言葉で探せます」と添える

## 出力の形（確かめるとき）

```
この内容で保存します。違うところがあれば書いてください。

| 項目 | 内容 |
|---|---|
| 種類 | 定期テスト |
| 年度 | 2026 |
| 学校 | 佐世保市立〇〇中学校 |
| 学年・教科 | 中2・数学 |
| 時期 | 2学期期末 |
| 単元 | 大問1 …／大問2 … |
| ファイル | 問題：〇〇.pdf、解答：〇〇.pdf |
```
（このあと選択肢「この内容で保存する」）
