# 業務計画書・報告書を作る

## 手順

1. **何の計画か**：テーマ・期間・対象（校舎・学年）。言われていなければ、質問者の部門・校舎で進め、「確認してほしいこと」に書く
2. **材料を読む**：索引から、質問者の部門の第36期計画（`30_部門/`）、関係する振り返り（`30_部門/振り返り/`）、関係する要項（`40_要項/`）を `read_file` で読む。合わせて4本まで
3. **下書きを作る**：次の構成で書く
   - 目的（今期の方針・全社共通テーマとのつながり。方針の言葉は資料のとおりに）
   - 現状（数字は出典と時点つき）
   - 目標（**数字・期限・担当は本人に決めてもらう**。資料に無ければ〔要確認〕）
   - 施策（誰が・いつまでに・何を・どう数えるか）
   - 日程（年間カレンダー・要項の日付だけを使う）
4. **方針チェック**：`方針チェック観点_2026.md` の観点 1〜4 で下書きを確かめ、見直した点があれば短く書く
5. 「文書にして」「Google ドキュメントで」と言われたら `create_google_doc` で作る（題名は「テーマ（校舎）」）

## 出力の形

```
（1〜2行で：何の計画を、どの資料をもとに作ったか）

## 計画書（下書き）
（上の構成）

## 確認してほしいこと
- 置いた前提：
- 資料に無く空けた項目：（目標の数字・担当など）
- 制作側で作った言い回し：

出典: （読んだ資料）
```
