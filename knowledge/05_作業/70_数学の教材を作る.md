# 数学の教材を作る

この作業では、**計算の道具（code_execution：Python）** が使える。答えはすべてこれで確かめる。
1枚に5〜10問が並ぶ小テストは、作業「数学の小テストを作る」（`71_数学の小テストを作る.md`）で作る。

## 最初に聞くこと（作る前に1回だけ）

教材を作って出すまでには時間がかかる。作り直しを減らすため、**頼まれた最初の回では作らず、決まっていないことを聞く**。

- 頼みごとに書かれていないものを、下の表から**優先順に最大4つ**聞く。書かれているものは聞かない
- それぞれに**既定の答え**を付け、職員が1回の返事でまとめて答えられる形にする（「2はA問題で」のように一部だけ答えてもよい、と書く）
- 職員が条件をすべて書いているとき、「おまかせ」「すぐ作って」「この前提で作る」と言ったときは、聞かずに作る。2回目以降（答えをもらったあと）は聞き直さない
- この回は質問だけを書く。問題の案・計算・「確認してほしいこと」は書かない

| 優先 | 聞くこと | 既定の答え |
|---|---|---|
| 1 | 使い方：授業で解説する／宿題・家庭学習／テスト・模試（時間は何分か） | 授業で解説する |
| 2 | 範囲：どこまで習っているか（例：関数なら「1次関数まで」「y＝ax² まで」、図形なら「相似まで」「三平方まで」） | 中3の入試範囲すべて |
| 3 | 難しさ：A問題レベル（基礎・標準）／B問題レベル（三高・思考力）／易しい問いから順に混ぜる | B問題レベル |
| 4 | 量：題数と、1題あたりの小問の数 | 3題・1題3〜4問 |
| 5 | 入れたいもの・避けたいもの：特定の型（動点、面積の最大、規則性、会話文）、使ったことがある題材 | 指定なし |
| 6 | 出し方：まずチャットで確認する／すぐ Word のファイルにする（模試の形にするか） | まずチャットで確認する |

聞くときの形：

````
作る前に、作り直しを減らすために4点だけ確認させてください。そのままでよければ「この前提で作る」を押してください（一部だけ答えても大丈夫です）。

1. 使い方：授業で解説する／宿題／テスト・模試（何分）　→ 既定：授業で解説する
2. 範囲：どこまで習っていますか　→ 既定：中3の入試範囲すべて
3. 難しさ：A問題レベル／B問題レベル／混ぜる　→ 既定：B問題レベル
4. 量：3題・1題3〜4問でよいですか

```選択肢
この前提で作る
難しさをA問題レベルにして作る
宿題用にして作る
```
````

選択肢は「この前提で作る」と、いちばん迷いそうな項目の別の答え（1〜2個）にする。

## 手順

1. **決める**（「最初に聞くこと」で答えてもらったことに合わせる。答えが無い項目は既定で進め、「確認してほしいこと」に書く）
   - 学年・単元：言われたとおり。単元が無ければ、入試の大問構成（`長崎県公立高校入試_数学の出題傾向.md`）から選ぶ
   - 目的：入試対策（既定）／定期テスト対策／宿題
   - 難しさ：B問題レベル（既定。思考力・条件整理・規則性）／A問題レベル（基礎・標準）
   - 問題数：3題（既定）。小問は1題につき2〜4問で、易しい → 難しいの順
   - 種類：思考力の問題（既定）／入試形式の模試／単元プリント。形は `10_形式と表記.md`
   - 範囲：入試対策では標本調査を出さない
2. **作る**：問題 → 解答 → 解説の順で下書きする。図形・関数の問題には ```図 の枠で図を付ける（`30_図の書き方.md`）。図の座標は計算の道具で求めてから書く
3. **計算で確かめる**（必ず）：`code_execution` で
   - すべての小問の答えを、分数のまま（`fractions.Fraction`）計算し直す
   - 場合の数・確率・「すべて求めよ」は総当たりで数える
   - 文字式は、x にいくつか値を入れて図から直接求めた値と比べる
   - 答えが条件の範囲の中にあるか（解が無い・範囲外なら、問題の数値を直して作り直す）
   - 図の点の座標が、問題の条件（長さ・比・角・交点）と合っているか
   - 解答と食い違ったら、**問題か解答を直してから** 出す（直したことを「確認してほしいこと」に書く）
4. **チェックリスト**：`20_確かめ.md` を1つずつ確かめる（図表が答えを見せていないか、丸めの指示、言葉の統一、重なり）。**問題文を最初から読み直し**、崩れた文（単位が混ざる、途中で切れる）が無いか、解説の途中の数値（変域・時間・座標）が解答と合っているかも見る
5. **出す**：下の形で回答に書く
   - 「ファイルにして」「データで出力して」「Word で」「印刷できる形で」と言われたら、`create_math_material` で仕上がりの書式（`40_仕上がりの書式.md`）の Word を作る。「問題」と「解答・解説」の2つのファイルになる
     - 番号（□1・（１）・問１）はアプリが付けるので、文に書かない。数式は `$ … $`（分数 `\frac{1}{2}`、根号 `\sqrt{3}`、累乗 `x^2`）
     - 小問集合の大問は `numbering: kakko`、ふつうの大問は `toi`。図と表は `side`（大問全体にかかるものは大問の side、小問だけのものは小問の side）
     - 「模試の形で」「表紙を付けて」と言われたときだけ `booklet: true`（表紙と「問題」の扉が付く）
     - 作ったら、2つのURLと、図の位置と改ページを Word で確かめてほしいことを「確認してほしいこと」に書く
   - 「Google ドキュメントで」と言われたときだけ `create_google_doc` で作る（問題のあとに `[改ページ]` を入れて、解答・解説を次のページにする）
