# 数学の教材 出す前の確かめ

AIが作った問題は、**5問中3問の答えが間違っていた例がある**（`50_作成実例.md`）。次の項目を1つずつ確かめる。

## 1. 計算で確かめる（必ず）

- [ ] **すべての小問の答えを、別の方法でもう一度計算する。** 智翔館AIは計算の道具（Python）で、分数のまま正確に計算し、場合の数・確率は総当たりで数える
- [ ] 「すべて求めよ」「何通りか」「何個か」は、**総当たりで漏れも重なりもないか** を確かめる
- [ ] 文字式（面積を x で表す など）は、x にいくつか値を入れて、図から直接求めた値と合うか確かめる

## 2. 問題として成り立つか

- [ ] **答えが1つに決まる**（または「すべて」に当たるものがはっきりしている）
- [ ] **答えが条件の範囲の中にある**（例：0 < x < 10 のとき、方程式の解が範囲内にあるか。無ければ問題を作り直す）
- [ ] 図が実際に描ける（長さ・角度が矛盾しない）。数値が現実的（人数・金額・速さ）
- [ ] 個数・人数は整数、0個を認めるかどうかを書く（「どちらも1個以上」など）

## 3. 問題文と資料

- [ ] **図・表・会話文が、答えを先に見せていない**（例：グラフに答えの百分率が書いてある）
- [ ] 割合・百分率の丸め方を書いた（「小数第2位を四捨五入して」）
- [ ] 資料・図・問題文で、同じものを同じ言葉で呼んでいる（「具体的に決まっている」と「具体的に決定」を混ぜない）
- [ ] 同じ計算をさせる小問が重なっていない。小問は易しい → 難しいの順
- [ ] 学年の範囲の中。**入試対策では標本調査を出さない**（令和7年度から範囲外）

## 4. 解答・解説

- [ ] **解答表と解説の答えが一致している**（AIは解説で誤りに気づいても解答表を直さないことがある）
- [ ] 解説は「なぜその式になるか」を書き、途中の式を省かない
- [ ] 証明は `10_形式と表記.md` の書き方（根拠を1行ずつ、条件の言い方）
- [ ] 答えの形（最も簡単な形、√・π はそのまま、単位）

## 5. そのほか

- [ ] 過去の入試問題・市販教材を写していない
- [ ] 実在の生徒の名前・成績を使っていない。学校名は架空にする
- [ ] 「確認してほしいこと」に、置いた前提（学年・難しさ）、確かめで直した点、先生に見てほしい点を書いた
