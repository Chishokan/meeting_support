# 数学の小テストの書式

数学科の見本（大問１特訓教材「志望校合格にむけて ベーシック」No.1〜53）に合わせた書式。智翔館AIの道具 `create_math_quiz` は、この書式の Word を「小テスト」と「答え入り」の2つ作る（番号・書体・配置はアプリが付ける）。

## 1. 1枚の形

| 場所 | 中身 |
|---|---|
| 用紙 | B5 縦 |
| 上 | 「志望校合格にむけて　ベーシック　No.1」（手書き風の書体。Word では UD デジタル 教科書体）。その下の右に「氏名」の枠 |
| 問題 | 「□(1)」「□(2)」…と縦に並べる。□は生徒が丸付けのあとに使うチェック欄 |
| 問題の幅 | 用紙の左の6割に書く。右の4割は計算と答えを書く余白 |
| 見出し | 種類の違う問題をまとめるときは「□1　次の計算をしなさい。」のように見出しを付け、問題の番号は(1)からふり直す |
| 小問 | 問題の中の小問は「□①」「□②」 |
| 図・表 | 問題文の右（余白の側）に置く。問題文は「右の図で、…」と書く |
| 印 | 長崎県の入試でよく出る型には、枠で囲んだ「よく出る」を付けてよい（多くても1枚に1〜2問） |
| 下 | 左に「※やり直しは全て、訂正ノートに！提出期限は守ること。」、右に小さく「智翔館・東進衛星予備校」 |

- 1枚に5〜10問。計算だけなら8〜10問、文章題・図の問題が入るなら5〜6問。1枚に収まらないときは枚を分ける（No. が続く）
- 見本には、問題の右に出典の県名（〈長崎〉など）があるが、AIが作った問題には付けない
- 本文はＭＳ明朝 10.5pt、英数字は Times New Roman。数式の書き方は `40_仕上がりの書式.md` と同じ（分数・根号は縦に組む）

## 2. 答え入り

- 同じ形の紙の、右の余白に赤で「答　…」と入れた版を、別のファイルにする（丸付け・答え合わせ用）
- 解説は付けない。解説が要るときは、入試形式の教材（`40_仕上がりの書式.md`）で作る

## 3. 枚のつくり（見本の例）

- 計算の枚：見出しなしで □(1)〜□(9)（例：No.1 正負の数の加法・減法）
- 見出しで分ける枚：□1 次の計算をしなさい。（2問）□2 次の式を展開しなさい。（3問）□3 …（例：No.3）
- 文章題の枚：□(1)〜□(3)、1問が3〜4行（例：No.11 方程式の文章題）
- 図の枚：□(1)〜□(3)、それぞれの右に図（例：No.18 相似）
