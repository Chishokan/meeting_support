# 数学の図の書き方

図は ```図 の枠に JSON で書く。**チャットではその場で図になり、Google ドキュメントにすると画像で入る。**
先生は図の下の「画像を保存」で、自分のプリントにも貼れる。

## 1. 決まり

- 座標は数学の座標（右が x の正、**上が y の正**）。`range` は `[xの最小, yの最小, xの最大, yの最大]`。図形が少し余裕をもって入る範囲にする
- 点は `points` に名前と座標を書き、図形では名前で指す（`"A"`）。名前を付けない点は `[x, y]` で直接書く
- **座標は計算で求めてから書く**（交点・円周上の点・長さの比など。計算の道具が使えるときは使う）。目分量で置かない
- 長さの比・角の大きさは、問題の条件どおりにする。「図は正確とは限らない」と断る問題でも、なるべく条件に合わせる
- 文字（点の名前・`label`）は半角の英数字と ° ² √ π を中心に短く。日本語の説明は図の外（問題文）に書く
- 1つの図に1つの枠。図の番号は `caption`（例 `"図1"`）

## 2. 項目

| 項目 | 書き方 | 意味 |
|---|---|---|
| `caption` | `"図1"` | 図の下に出す見出し |
| `range` | `[0, 0, 10, 10]` | 表示する範囲（必須） |
| `size` | `8` | ドキュメントに入れるときの幅（cm、3〜16。既定 8） |
| `axes` | `true` | x軸・y軸と原点 O を描く（関数のグラフ） |
| `grid` | `true` または `2` | 方眼（数で目盛りの間隔） |
| `points` | `{"A": [0, 10], "P": [0, 6]}` | 点の名前と座標 |
| `dots` | `["P", "Q"]` | 黒い点を打つ点（辺の上の点、交点など） |
| `labels` | `{"O": "s", "B": "none"}` | 点の名前の向き（n s e w ne nw se sw、none で書かない）。省くと図の中心から外向き |
| `shapes` | 下の表 | 描く図形（書いた順に重なる） |

| 図形 | 書き方 | 意味 |
|---|---|---|
| 多角形 | `{"polygon": ["A","B","C"], "fill": true}` | 閉じた多角形。`fill` で影（灰色）、`dash` で点線 |
| 線分 | `{"segment": ["P","Q"], "dash": true}` | 2点を結ぶ |
| 直線 | `{"line": ["A","B"]}` | 2点を通り、範囲の端までのびる |
| 円 | `{"circle": "O", "r": 5}` または `{"circle": "O", "through": "A"}` | 中心と半径（または通る点） |
| 弧・おうぎ形 | `{"arc": "O", "r": 3, "from": 0, "to": 90, "fill": true}` | 角度は度で、x軸の正の向きから反時計回り。`fill` でおうぎ形の影 |
| 関数のグラフ | `{"curve": "x^2/2", "x": [-4, 4]}` | y = 式。`x` で描く範囲。使える：数・x・+ - * / ^・かっこ・sqrt()・abs()・pi。`2x`、`1/2x` も可 |
| 角の印 | `{"angle": ["A","B","C"], "label": "42°", "arcs": 2}` | 真ん中が頂点。`arcs` で弧の数（等しい角） |
| 直角の印 | `{"right": ["A","B","C"]}` | 真ん中が頂点 |
| 等しい長さの印 | `{"equal": [["A","P"],["B","Q"]], "marks": 1}` | 辺の真ん中に短い線（`marks` で本数） |
| 長さの書き込み | `{"length": ["B","C"], "label": "10cm"}` | 辺の外側に書く（`side`: left / right で向きを決める） |
| 文字 | `{"text": [5, 5], "label": "S"}` | 好きな位置に短い文字 |

## 3. 例

正方形と、影をつけた四角形（AP＝BQ＝x）：

```図
{"caption": "図1", "range": [0, 0, 10, 10], "size": 6,
 "points": {"A": [0, 10], "B": [0, 0], "C": [10, 0], "D": [10, 10], "P": [0, 6], "Q": [4, 0]},
 "dots": ["P", "Q"],
 "shapes": [
  {"polygon": ["A", "B", "C", "D"]},
  {"polygon": ["A", "P", "Q", "D"], "fill": true},
  {"equal": [["A", "P"], ["B", "Q"]]},
  {"length": ["C", "D"], "label": "10cm"},
  {"right": ["A", "B", "C"]}
 ]}
```

関数 y = x²/2 と直線、三角形OAB（A(−2, 2)、B(4, 8) は計算で求めた交点）：

```図
{"caption": "図2", "range": [-5, -1, 7, 10], "axes": true, "grid": true, "size": 7,
 "points": {"A": [-2, 2], "B": [4, 8]}, "dots": ["A", "B"],
 "shapes": [
  {"curve": "x^2/2", "x": [-4.4, 4.4]},
  {"line": ["A", "B"]},
  {"polygon": [[0, 0], "A", "B"], "fill": true}
 ]}
```

円と円周角（AC は直径、∠DBC＝42°）：

```図
{"caption": "図3", "range": [-6, -6, 6, 6], "size": 6,
 "points": {"O": [0, 0], "A": [-5, 0], "C": [5, 0], "B": [3, 4], "D": [-3, -4]},
 "dots": ["O"], "labels": {"O": "s"},
 "shapes": [
  {"circle": "O", "r": 5}, {"segment": ["A", "C"]}, {"polygon": ["A", "B", "C", "D"]},
  {"angle": ["D", "B", "C"], "label": "42°"}
 ]}
```

## 4. できないこと（当面）

- 立体の見取図（円すい・角柱など）は、底面の楕円や見えない辺の点線を `arc`・`segment`・`dash` で組み合わせれば描けるが、見た目の確認を先生にお願いする
- 写真・イラスト、手書き風の図
- 図の中の長い日本語（問題文に書く）
