# 数学の教材 形式と表記

## 1. 入試形式の模試（炎の最終章の型）

- 表紙：講座名・回数（例「炎の最終章 第1回 数学」）、受検番号欄、注意書き
- 注意書き（本番と同じ内容）
  1. 「始め」の合図があるまで、この問題冊子を開いてはいけません。
  2. 解答用紙は中にはさんであります。
  3. 「始め」の合図があったら、まず、受検番号を問題冊子および解答用紙の受検番号欄に記入しなさい。
  4. 問題は 1 〜 ◯ で、1ページから◯ページまであります。
  5. 答えは、すべて解答用紙に記入しなさい。答えは、最も簡単な形にしなさい。なお、計算の結果に √ または π をふくむときは、およその値に直さないでそのまま答えなさい。
  6. 「やめ」の合図で、鉛筆を置きなさい。
  7. 検査終了後は、問題冊子および解答用紙を机の上に置いたまま退出しなさい。
- 大問構成：**本番（令和7・8年度）は5題**。1 小問集合（10題前後・作図を含む）／2 確率・データの活用・式の証明・方程式の文章題／3 関数／4 図形（平面または空間）／5 規則性・総合（会話文）。社内の炎の最終章（令和7年度版）は旧来の6題（空間図形が独立）〔要確認：今後どちらに合わせるか〕
- 大問の番号は 1 2 …、大問の中は「問1」「問2」…、さらに細かい問いは (1) (2) …
- 解答用紙：問いごとの欄、単位（cm、cm²、cm³、°、m）を欄に印字しておく。証明・過程を書く欄は広く
- 解答は別冊（「数学（1回目）解答」）。証明は解答例を全文で書く

## 2. 単元の演習プリント（サイトクの型）

- 題：「合格必達プログラム 後期第二講座 合同の証明」のように、講座名・回・単元
- 1枚に8〜10問。基本（根拠が1つずつ見える問題）→ 応用（折り返し・正三角形・平行四辺形を組み合わせる問題）の順
- 問い方：「右の図において、…である。このとき、…であることを証明しなさい。」
- 後半（または別ページ）に【解答・解説】：問題文を再掲し、解答例を書く
- フッター：智翔館・東進衛星予備校

## 3. 問い方と答えの形

| 場面 | 言い回し |
|---|---|
| 計算 | 「〜を計算せよ。」「〜を因数分解せよ。」「2次方程式 〜 を解け。」 |
| 値を求める | 「〜を求めよ。」「〜は何cmか。」「〜の大きさは何度か。」 |
| 確率の前提 | 「ただし、それぞれのさいころの目は1から6まであり、どの目が出ることも同様に確からしいものとする。」 |
| 過程を書かせる | 「ただし、答えだけでなく、答えを求める過程がわかるように、途中の式なども書くこと。」 |
| 作図 | 「定規とコンパスを用いて作図し、その位置を点・で示せ。ただし、定規は直線や線分をひくときのみに使い、長さを測ったり角度を利用したりしてはならない。また、作図に用いた線は消さずに残しておくこと。」 |
| すべて答える | 「〜となる t の値をすべて求めよ。」 |
| 規則を式に | 「n を自然数とする。…の個数を n の式で表せ。」 |

- 答えは最も簡単な形。√・π はそのまま。分数は約分する。割合を百分率で答えさせるときは丸め方を書く（例「小数第2位を四捨五入して」）
- 単位は問いに合わせる（cm、cm²、cm³、°）。答えに単位を書かせるか、解答欄に印字するかをそろえる

## 4. 証明の書き方（解答例の型）

```
△ABE と △ACD において
仮定から          AB = AC          …①
仮定から          ∠ABE = ∠ACD      …②
共通な角であるから ∠BAE = ∠CAD      …③
①、②、③より、1組の辺とその両端の角がそれぞれ等しいから
△ABE ≡ △ACD
合同な図形では対応する辺は等しいから
BE = CD
```

- 最初に「〔仮定〕」「〔結論〕」を書く問題もある（演習の前半）
- 1行に1つの根拠。根拠の言葉をそろえる：「仮定から」「共通な辺（角）であるから」「対頂角は等しいから」「平行線の錯角（同位角）は等しいから」「円周角の定理により」「折り返した辺や角は等しいから」「平行四辺形の対辺（対角）は等しいから」
- 合同条件：3組の辺／2組の辺とその間の角／1組の辺とその両端の角／直角三角形の斜辺と1つの鋭角／直角三角形の斜辺と他の1辺 が「それぞれ等しいから」
- 相似条件：3組の辺の比／2組の辺の比とその間の角／2組の角 が「それぞれ等しいから」
- 長さ・面積を求める小問が続くときは、相似比 → 辺の長さ → 面積の順に式を残す

## 5. Google ドキュメントにするとき

- 題名・注意書き → 問題 → `[改ページ]` → 解答・解説、の順
- 図は ```図 の枠で描く（書き方は `30_図の書き方.md`）。ドキュメントには画像で入り、下に「図1」などの見出しが付く
- 表は Markdown の表で書く（ドキュメントで表になる）
- 分数は「1/5」、累乗は「x²」、根号は「√3」と書く
