# 数学の教材づくり 使い方

智翔館AIの作業「数学の教材を作る」（`05_作業/70_数学の教材を作る.md`）が最初に読む資料。先生が手で作るときの決まりとしても使う。

## 1. ファイルの構成

| ファイル | 中身 | いつ読むか |
|---|---|---|
| 00_使い方.md（このファイル） | 教材の種類、作る流れ、任せないこと | 最初に |
| 10_形式と表記.md | 入試形式の模試・単元プリントの形、問い方・答えの形・証明の書き方 | 作るとき |
| 20_確かめ.md | 出す前に必ず確かめること（計算で確かめる、答えが1つに決まる など） | 作ったあと |
| 50_作成実例.md | AIが作った問題の誤りと、その直し方の実例 | 似た問題を作るとき |
| `15_地域・市場/長崎県公立高校入試_数学の出題傾向.md` | 入試の大問構成・配点・A問題/B問題・傾向 | 入試対策の教材のとき |

## 2. 教材の種類（社内の実物から）

| 種類 | 社内の実物 | 形 |
|---|---|---|
| 入試形式の模試 | 炎の最終章 第1・2回（入試直前の2月の講座） | 本番と同じ注意書き・大問構成・解答用紙。解答は別冊 |
| 単元の演習プリント | 合格必達プログラム（中3秋）のサイトク（最重要単元特訓）後期「合同の証明」「相似の証明」 | 1単元8〜10問。後ろに【解答・解説】 |
| 思考力の問題 | （まだ無い。AIで作る想定） | 会話文・資料・規則性。入試の大問5や探究的な問題を意識 |

## 3. 作る流れ

1. **決める**：学年・単元・目的（入試対策／定期テスト対策／宿題）・難しさ（A問題／B問題レベル）・問題数・種類
2. **作る**：問題 → 解答 → 解説の順。形は `10_形式と表記.md`
3. **確かめる**：`20_確かめ.md` のとおり。**答えは必ず計算で確かめる**（AIは計算の道具で総当たり・分数の計算をする）
4. **出す**：Google ドキュメント（問題と、解答・解説はページを分ける）。図は「図の指示」として書き、先生が描く
5. **先生が確かめる**：数学科の先生が解いて確かめてから使う

## 4. AIに任せないこと

- 過去の入試問題・市販教材を写すこと（著作物。形と考え方だけを参考にする）
- 生徒の名前・成績を問題文に入れること
- 先生の確かめなしで生徒に配ること
- 図形・グラフの正確な作図（当面は「図の指示」を書き、先生が描く）〔要確認：図を画像で入れる仕組みは後日〕
