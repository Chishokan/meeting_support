# 数学の教材づくり 使い方

智翔館AIの作業「数学の教材を作る」（`05_作業/70_数学の教材を作る.md`）が最初に読む資料。先生が手で作るときの決まりとしても使う。

## 2. 教材の種類（社内の実物から）

| 種類 | 社内の実物 | 形 |
|---|---|---|
| 入試形式の模試 | 炎の最終章 第1・2回（入試直前の2月の講座） | 本番と同じ注意書き・大問構成・解答用紙。解答は別冊 |
| 単元の演習プリント | 合格必達プログラム（中3秋）のサイトク（最重要単元特訓）後期「合同の証明」「相似の証明」 | 1単元8〜10問。後ろに【解答・解説】 |
| 思考力の問題 | （まだ無い。AIで作る想定） | 会話文・資料・規則性。入試の大問5や探究的な問題を意識 |
| 小テスト | 大問１特訓教材「志望校合格にむけて ベーシック」No.1〜53 | B5・1枚5〜10問。計算練習・大問1対策。答え入りの版を別に作る（作業「数学の小テストを作る」） |

## 3. 作る流れ

1. **決める**：学年・単元・目的（入試対策／定期テスト対策／宿題）・難しさ（A問題／B問題レベル）・問題数・種類
2. **作る**：問題 → 解答 → 解説の順。形は `10_形式と表記.md`
3. **確かめる**：`20_確かめ.md` のとおり。**答えは必ず計算で確かめる**（AIは計算の道具で総当たり・分数の計算をする）
4. **出す**：Word にするときは、入試形式は `40_仕上がりの書式.md`（問題と解答・解説の2つ）、小テストは `41_小テストの書式.md`（小テストと答え入りの2つ）。図は ```図 の枠で描き（`30_図の書き方.md`）、Word には画像で入る
5. **先生が確かめる**：数学科の先生が解いて確かめてから使う

## 4. AIに任せないこと

- 過去の入試問題・市販教材を写すこと（著作物。形と考え方だけを参考にする）
- 生徒の名前・成績を問題文に入れること
- 先生の確かめなしで生徒に配ること
- 図の最終確認（AIが ```図 で描いた図が条件どおりかは、先生が見て確かめる。立体の見取図は特に）
