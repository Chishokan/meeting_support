# 数学の教材 仕上がりの書式

数学科の仕上がりデータ（長崎県統一模試 232号 数学）に合わせた書式。智翔館AIの道具 `create_math_material` は、この書式の Word を作る（番号・書体・配置はアプリが付けるので、AIは中身だけを渡す）。
先生が手で作るときも、この形にそろえる。

## 1. 用紙と文字

| 項目 | 決まり |
|---|---|
| 用紙 | B4 縦（257×364mm）、余白は上下左右 20mm |
| 本文 | ＭＳ明朝 11pt。英数字は Times New Roman |
| 文字（変数） | 小文字の文字（*x*、*y*、*a*、*n*）は太字の斜体。点の名前（A、B、P）は立体 |
| 記号 | ＋ － ＝ ＜ ＞ は全角。×、÷、√、π、∠、△、° |
| 分数・根号 | 縦に組む（Word の数式）。$\frac{1}{2}$ を「1/2」と横に書かない |

## 2. 番号の当て方

| 階層 | 形 | 例 |
|---|---|---|
| 大問 | 数字を□で囲む。大問ごとに新しいページから始める | □1　次の（１）～（10）に答えなさい。 |
| 小問（小問集合の大問） | 全角の括弧と数字（10 からは半角） | （１）（２）…（10） |
| 小問（ふつうの大問） | 太字の「問」と全角の数字 | **問１**　**問２** … |
| 問の中の細かい問い | 全角の括弧と数字 | （１）（２） |

- 大問の頭の文：小問集合は「次の（１）～（10）に答えなさい。」、ふつうの大問は「次の各問いに答えなさい。」「…。次の問いに答えなさい。」
- 番号と本文のあいだは約2文字あける。2行目からは本文の頭にそろえる
- 小問のあいだは、計算を書ける程度（2〜3行分）あける

## 3. 図と表

- 図と表は、問題文の**右の列**に置く（本文の左、図の右）
- 図の上に太字のゴシックで「**図１**」「**図２**」、表は「**表**」と付ける。図の番号は大問ごとに１から
- 大問全体にかかる図（関数のグラフ、図形の問題の図１〜図４）は、大問の右の列に上から並べる
- 小問集合の中の図は、その小問の右に置く
- 図の中の文字は半角の英数字と記号だけ（点の名前、長さ、角度）。日本語は問題文に書く

## 4. ページの下

- 真ん中にページ番号「－ 1 －」
- 右に太字で「問題は次のページも続きます。」。最後の大問のページは「これで問題は終わりです。」

## 5. 模試の形（表紙と扉）

「模試の形で」「表紙を付けて」と頼まれたときだけ付ける。単元プリント・宿題は問題のページから始める。

1. 表紙：左上に受験番号の欄（「受験番号｜　　番」）、題名（例：長崎県統一模試 233号）、「数　　学」、（５０分）、「注　　意」の枠
   - 注意の枠：放送で指示があるまで開かない／解答用紙は中にはさんである／「始め」の合図で受験番号・氏名・所属塾名を記入／問題は □1～□N／答えはすべて解答用紙に、最も簡単な形で、√ や π はそのまま（太字）／「やめ」の合図で鉛筆を置く
2. 扉：「問　　題」だけのページ
3. 大問のページ（上の決まりどおり）

〔要確認〕仕上がりデータの注意には「1ページから6ページまであります」とページの範囲があるが、AIが作る Word はページ数が決まらないため「問題は□1～□Nです。」にしている。印刷前に先生が書き足す。

## 6. 解答・解説

問題とは**別のファイル**にする（配るときに問題だけを印刷しやすいように）。

- 題名「（題名）　解答・解説」
- 大問ごとに「□1　解答」、小問の番号を付けて答え（（１）…／問１…）、そのあとに「解説」（途中の式を省かない）

## 7. まだできないこと

- 解答用紙（答えを書く欄の表）は作らない。必要なら先生が作る
- 連立方程式の { で2式をくくる形、筆算、立体の見取図の細かい線は、Word で先生が直す
- 改ページの位置（1つの大問が2ページにまたがるとき）は、Word で確かめる
