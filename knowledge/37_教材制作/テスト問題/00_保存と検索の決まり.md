# 中学校のテスト問題の保存と検索の決まり

智翔館AI のチャットに問題用紙・解答の PDF や写真を添付して「保存して」と頼むと、ドライブに保存し、あとから学校・学年・教科・単元の言葉で探せる。

## 保存先

- ファイル：Google ドライブ「15_AI利用データ / 中学校テスト問題 / 定期テスト・実力テスト・入試問題」
- 一覧：スプレッドシート「会議サポートアプリログ」の「中学校テスト問題」シート（1件1行）
- 共有の設定は変えない（フォルダの共有のまま）。学校の問題なので、リンクを知っている人への公開はしない。開けないときは「15_AI利用データ」の権限を持つ人に頼む

## 保存しないもの

- **生徒の名前・点数・書き込みのある答案**。白紙の問題用紙と、模範解答・解答用紙（白紙）だけを保存する
- 写真に生徒の名前が写っていたら保存しない。名前の写っていないものを添付し直してもらう

## 書き方（1件ごと）

| 項目 | 書き方 | 例 |
|---|---|---|
| 種類 | 定期テスト／実力テスト／入試問題 | 定期テスト |
| 年度 | 西暦の年度（4月始まり）。1〜3月のテストは前の年度 | 2026（2027年2月の学年末テストも 2026） |
| 学校 | 正式な名前。入試問題は「長崎県公立高校」や高校名 | 佐世保市立日宇中学校 |
| 学年 | 中1／中2／中3（入試問題は中3） | 中2 |
| 教科 | 国語／数学／英語／理科／社会／5教科／その他 | 数学 |
| 時期・回 | 定期テストは必ず。学期と中間・期末、学年末。実力テストは回か月。入試は一般・特別など | 2学期期末、第2回、11月、一般入試 |
| 単元・出題内容 | **大問ごと**に単元と出題の形を書く（探す手がかりになる） | 大問1 正負の数の計算／大問2 一次関数のグラフ／大問3 連立方程式の文章題 |
| メモ | 平均点・範囲・気づいたこと（任意） | 平均 58 点。範囲は教科書 p.40〜78 |

1回の保存で、問題・解答など6つまでのファイルを1件にまとめる（役目：問題／解答／問題と解答／解答用紙／その他）。

## 保存の流れ

1. 職員が問題用紙・解答を添付し、「保存して」と頼む
2. 智翔館AI が添付を読み、上の項目（種類・年度・学校・学年・教科・時期・単元）を回答に書き、選択肢「この内容で保存する」で確かめる。読めない項目は職員に聞く
3. 職員が「この内容で保存する」を押すと保存し、ファイルのリンクを返す

## 探し方

- 「日宇中の中2数学の2学期期末はある？」「一次関数が出た定期テスト」「去年の県立入試の英語」のように頼む
- 学校名は一部でよい（「日宇中」で「佐世保市立日宇中学校」も見つかる）。教科を指定すると「5教科」で保存したものも出る
- 見つからないときは、条件（学校名・年度・時期）をゆるめて探し直す。それでも無ければ「保存されていない」と伝える
- 智翔館AI は PDF・画像の中身をあとから読み直せない（ドライブの道具は文書・表・スライドだけ）。類題を作るときは、探したファイルを開いて添付し直してもらう
