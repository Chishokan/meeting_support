# knowledge/ の歩き方

智翔館の社内知識をAIが参照できる形で置く場所。
原本は Google ドライブ。ここはそれを Markdown 化した**写し**であり、
同期タスクが自動更新するため、**このフォルダを直接編集しても次回同期で上書きされる**。
内容を直したいときは Drive 側の原本を直すこと。

## 階層

| フォルダ | 中身 | 更新責任者 |
|---|---|---|
| `00_index/` | この案内・AIへの指示・索引・用語辞書 | 総務 |
| `10_理念・方針/` | 理念、社長方針、行動指針 | 総務 |
| `20_組織・人事/` | 組織図、職務分掌、年間カレンダー | 総務 |
| `30_部門/` | 部門ごとの業務マニュアル・料金・カリキュラム | 各部門長 |
| `40_イベント/` | 講習・テスト対策会などの要項と実施記録 | 各担当 |
| `50_問い合わせFAQ/` | 過去の問い合わせ回答から育てたFAQ | 総務 |
| `60_規程・手続き/` | 就業規則要約、経費精算、各種申請フロー | 総務 |
| `90_archive/` | 旧年度。参照はできるが優先度は低い | 総務 |

※ 責任者欄は Phase 0 で実名を入れる。**空欄のまま運用を始めない。**

## 命名規約

- 数字プレフィクスで並び順を固定。間に挿せるよう10刻み
- 年度が絡むものは末尾に `_2026`
- 1ファイル1トピック。目安 200〜800行。長すぎると回答が薄まる

## front matter（全ファイル必須）

```yaml
---
title: 夏期講習会 実施要項 2026
dept: 小中等部            # 全社 / 小中等部 / RED個別 / 高等部 / LEC / 英検 / 総務
owner: 安東瑞輝           # 更新責任者
updated: 2026-06-01
source: drive:1AbcDEf...  # 原本の Drive ファイルID
source_type: spreadsheet  # doc / spreadsheet / xlsx / docx / pdf / image
tags: [夏期講習, 外部生募集, 要項]
visibility: all           # all / admin_only
summary: 2026年度夏期講習の日程・料金・外部生募集条件をまとめたもの
---
```

## 入れてはいけないもの

- 給与、人事評価、健康情報
- 生徒・保護者の個人情報（氏名、連絡先、成績の個票）
- パスワード、APIキー

これらは Git の履歴から消すのが極めて困難。必要な場合は Drive 直参照に限定する。
