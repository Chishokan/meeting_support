# knowledge/ の歩き方

智翔館の社内知識をAIが参照できる形で置く場所。
ここ（Git 上の Markdown）が**AIが読む正本**。制作担当のPCの `chishokan/knowledge/`（confirmed・facts.csv）は古い写しで、正本ではない（2026-11-04 決定）。原本（Google ドライブ・Canva・pptx など）の場所は、
各ファイルの front matter の `source` に書く。

- 2026年11月時点で、Drive からの自動同期の仕組みは無い（設計書 `docs/knowledge-base-architecture.md` の Phase 3 で作る予定）。
  原本が更新されたら、このフォルダのファイルを直接直す
- 直したら、front matter の `updated` を直し、`npm run index` で `00_index/INDEX.md` を作り直して一緒にコミットする（索引は手で書かない）
- `40_要項/` だけは、要項ドキュメントから `scripts/import-yoko.mjs` で取り込む（`status: 確定` のものだけがAIに渡る）
- このフォルダはそのまま本番のアプリに同梱される。main に入れた時点で全職員のAIに反映される

## 命名規約

- 数字プレフィクスで並び順を固定。間に挿せるよう10刻み
- 年度が絡むものは末尾に `_2026`
- 1ファイル1トピック。目安 200〜800行。長すぎると回答が薄まる

## front matter（全ファイル必須）

```yaml
---
title: 夏期講習会 実施要項 2026
dept: 小中等部            # 全社 / 小中等部 / RED個別 / 高等部 / LEC / 英検 / 総務
owner: 安東瑞輝           # 更新責任者
updated: 2026-06-01
source: drive:1AbcDEf...  # 原本の Drive ファイルID
source_type: spreadsheet  # doc / spreadsheet / xlsx / docx / pptx / pdf / image
tags: [夏期講習, 外部生募集, 要項]
visibility: all           # all / admin_only
summary: 2026年度夏期講習の日程・料金・外部生募集条件をまとめたもの
---
```

## 入れてはいけないもの

- 給与、人事評価、健康情報
- 生徒・保護者の個人情報（氏名、連絡先、成績の個票）
- パスワード、APIキー

これらは Git の履歴から消すのが極めて困難。必要な場合は Drive 直参照に限定する。
